# 076 剪輯台看得到片尾：片尾卡上時間軸、片尾配樂畫在背景音樂軌

## 作者原話（minimax-ep1，2026-11-21）

- 設好這一集的片尾配樂後：「可是我刷新後沒有看到啊，是 minimax-ep1 嗎」
- 聽完原因（剪輯台不畫片尾配樂和片尾卡）：「剪輯台一定要能看到啊」

## 發生了什麼

這一集設了片尾配樂（`outro`，從 #457 起播 26.6 秒）和片尾卡（工作區的 `ending`，書封＋金句 9.9 秒）。build 都做進去了，剪輯台卻看不出來：

| 作者看的地方 | 看到的 | 實際 |
|---|---|---|
| 「背景音樂」軌 | 「沒有背景音樂」 | 這一軌只畫底樂（`bed`），片尾配樂不畫 |
| 時間軸結尾、「完成影片」長度 | 18:33 | 完成影片 18:43：片尾卡接在影片後面，rough.mp4 沒有那 9.9 秒，時間軸以 rough.mp4 為界 |
| 完成影片預覽 | 拖不到片尾卡 | 播放器播得到（合成有那幾秒），但播放頭被擋在 rough.mp4 結尾 |
| 快速試聽 | 沒有片尾配樂 | 只播底樂 |

## 做法

1. **時間軸多畫片尾卡那幾秒**（`editor/timeline.js`）：`dur`＝rough.mp4 長度＋片尾卡秒數，`vdur`＝rough.mp4 長度。縮圖、波形、片頭片尾把手照舊只到 `vdur`；那幾秒音效軌以上壓暗，主軌畫一塊黑色的「片尾卡 N 秒｜金句」。
2. **只能看**：那幾秒的 hit 是 `ending`（背景音樂軌、時間尺除外），沒有拖曳、沒有右鍵選單、分割工具不切；從影片裡拖出去的時間一律收在 `vdur`。離影片結尾 7 px 以內還是算影片的，片尾把手和最後一句字幕的邊緣才拖得到。
3. **片尾配樂畫在背景音樂軌**：橘色一條，從起播那一句到片尾卡結束，頭尾斜坡是淡入淡出。底樂有鋪到片尾卡的也一起畫到那裡（原本停在影片結尾、寫「片尾再 N 秒 →」）。沒有底樂、有片尾配樂時，那一行改寫「整支沒有鋪背景音樂，只有片尾配樂（在最後）」。
4. **時間**：播放頭、`End`、跳到結尾都到片尾卡結尾；「／總長」「完成影片 …」含片尾卡，狀態列加「含片尾卡 N 秒」；「現在」寫片尾卡的金句。
5. **快速試聽**（`editor/preview.js`）：影片播完（或片尾被裁掉、播到剪點）接著用自己的時鐘走片尾卡；畫面放示意（黑底、圖、金句照 `lib/ending.mjs` 的時間淡入、打字、淡出），片尾配樂播上一次 build 烤好的那一段，和底樂同一套對時。
6. **資料**：
   - `build --check --json` 的 `outro` 加 `outStart outEnd fadeIn fadeOut relDb auto`（`specs/contracts/check-json.md`）。`ending` 原本就有。
   - build 把做進 index.html 的片尾配樂檔、片尾卡的圖與金句記在 `work/hyperframes/.cache/ending.json`（`lib/music.mjs` `writeEndInfo`／`readEndInfo`）；`/api/state` 的 `end` 給網址和版面數字。
   - 檢查報告好了就照報告畫，還沒好先照上一次 build 的（和底樂同一個規則：`editor/model.mjs` `endingLane`、`outroLane`）。

片尾卡、片尾配樂在剪輯台都不能改（換圖、金句、曲子、起播句、音量跟 AI 說）；提示文字寫了例句。

## 沒做

- 片尾配樂的音量、起播句不能在剪輯台拖（`outro.volume`、`outro.from` 只有 plan.json 和 `build.mjs --set`）。
- 直式的片尾（052：講完接原始錄影再淡出）沒有畫成一段：它的長度不在檢查報告的 `ending` 裡。
- 「比人聲小 N dB」是照整首的響度算的。前奏比整首小聲的曲子（作者那首前奏小 9 dB），實際播出來會比印的數字小很多；這次是只取前奏另存一首來對齊剪映的比例，工具沒改。
