# 021 分類散落的素材

來源：作者 2026-11-06 想讓觀眾開新影片時「先在 projects 建資料夾，把素材都丟進去，再請 AI 分類」，提示詞是「幫我分類 @projects/EP2 裡的素材」；確認在 `AGENTS.md` 補規則。

## 定案

| 題目 | 定案 | 理由 |
|---|---|---|
| 放哪裡 | `AGENTS.md` 新一節「分類素材」，不新增 Skill | 步驟短、不用工具；每個 Agent 都會讀這份 |
| 分類依據 | 照順序：檔名有「場地照」→ 副檔名 → ffprobe 軌道 → 檔名 → 截中間一格來看 | 能用事實判斷的先判斷；只有 camera、screen 要看畫面 |
| 場地照 | 留在原地 | 工具到專案資料夾找檔名有「場地照」的圖 |
| 看不出來 | 不動，列為待確認 | 主軌分錯，後面都會接錯 |
| 允許的動作 | 只搬；講稿可改名成 `講稿.md`；不覆寫、不轉檔、不刪除 | 守住規則 1；已在 `assets/` 的不動 |
| 停點 | 不算停點，最後一行用 `→ 下一步：`，不用 ⏸ | 停點只有六個（`contracts/stop-points.md` §1） |
| 自動觸發 | 要開剪但主軌資料夾都空、專案裡有散落素材時先分類 | 不然 AI 只會請使用者把檔案放好 |

## 做了什麼

| 檔案 | 內容 |
|---|---|
| `AGENTS.md` | 路由表一列、「分類素材」一節 |
