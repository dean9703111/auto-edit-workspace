# 018 停點 ④ 改用完成影片預覽（不再給 Studio）

來源：作者 2026-11-06 說「應該不需要了吧？因為都是在剪輯畫面操作了」；確認「點一張卡說這張卡」「逐格檢查卡片」都不是流程裡要使用者做的事。

## 定案

| 題目 | 定案 | 理由 |
|---|---|---|
| 停點 ④ | 改名「④ 完成影片預覽」，給 `editor.mjs` 印的「完成影片預覽：」網址（`/?view=final`） | 剪輯台的完成影片預覽和 render 用同一版播放器，看片、對嘴都夠；少一個介面 |
| 預設畫面 | `?view=final` 直接開在完成影片預覽；還沒 build、沒有播放器時留在即時模擬並提示原因 | 即時模擬沒有資訊卡，不能拿來確認 |
| 編號 | ④、⑤ 不合併 | ④ 是看完決定要不要輸出，⑤ 是自己調完說「調好了」；合併會牽動 ⑥ 與所有文件 |
| 「這張卡」 | 請使用者說段號或秒數 | 不開 Studio 就沒有選取可讀；流程本來就用段號與修改單 |
| 逐格檢查 | 維持 AI 跑 `audit`、`snapshot --review` | 本來就不是使用者的工作 |
| 相容 | 舊專案停點紀錄的「④ Studio 預覽」照認（工具只比對開頭的 ④）；舊說法「做到 Studio」也算；build 擋下手改產生檔、排除 `data-hf-id` 的保護不動 | 舊專案可能在 Studio 存過 |
| 播放器提示 | 剪輯台不再教開 Studio；播放器出錯時提示跑 `npm install` 再重開 | 給使用者走得通的路 |

`dev/tests/docs.test.mjs` 多一項：README、PROMPTS、官網首頁、Skill 不能再提 Studio。

範例文案（`dev/tools/samples.json` 的 steps、title-list）同步改掉 Studio，重產 08、13 的預覽與情境庫圖。
