# 082 片尾金句在剪輯台改字、拖位置、拉大小（即時看得到）

## 作者原話（minimax-ep1，2026-11-22）

- 「我希望 minimax-ep1 的「片尾卡」文字是可以編輯的，大小位置也可以，能做到嗎」
- 「我希望調整時，畫面能即時更新」
- 範圍照建議：只做這一集（plan.json），只做金句文字（書封圖不能拖）
- 試用後（r30）：「為什麼逗號不見了，我覺得這塊應該要完全符合我的段落規則吧，然後應該要可以選擇段落上間距會更完善」

## 現況

金句的字只能跟 AI 說（`build.mjs --set ending.quote=…`）；位置、大小寫死在 `lib/ending.mjs` 的 `ENDING.quote`（1300、575、寬 580、字 48、行高 73），每一集都一樣。剪輯台片尾卡的屬性只有「文字動畫」下拉選單（077）。

## 做法

1. **plan.json**：`ending` 加 `x`、`y`（金句框左上角，畫布 px）、`size`（字級 24–120）。沒寫＝原本的數字。框寬、行高跟字級等比例（一行放的字數不變）。共用的數字與計算在 `editor/ending-layout.mjs`（build、剪輯台頁面都用；頁面要載，所以不 import node 的東西）。
2. **build**（`lib/ending.mjs`）：`endingParts` 照 x／y／size 排；逐行浮出、由左擦開的行距跟著變。`x`／`y`／`size` 不是數字 ✖；字級超出範圍 ⚠ 並夾住；「太長超出下緣」改成照這個位置、字級算，另外檢查超出右緣。報告行拖過才多寫「位置 (x, y)、字級 N」。`build.mjs --set ending.x／ending.y／ending.size`。
3. **剪輯台**：
   - 屬性面板（點片尾卡）：金句改成文字框（逗號、// 換段；清空＝`quote: null` 這一集不放）、字級滑桿、位置、「回到原本的位置和大小」。
   - 預覽畫面：播放頭在片尾卡、有金句時出現虛線框（框住整段打完的範圍）。拖框＝移動，拖右下角＝放大縮小（字級 2 px 一格），方向鍵微調（Shift 10 px），雙擊回原位，Esc 取消。框夾在畫面裡。拖框會把屬性換成片尾卡。
   - 存檔（`editor/server/write.mjs` `sanitizeEnding`）：收 `motion`、`quote`、`x`、`y`、`size`；只送改過的；`null`＝拿掉回到預設；和預設一樣的位置不寫。
4. **即時更新**：
   - 快速試聽：片尾卡示意照現在的字、位置、字級畫（拖的過程每一格就跟著動）。
   - 完成影片預覽：`preview.js applyEnding` 直接改播放器裡 `#end-quote` 的位置、字級。字和上次 build 的不一樣時，先把原本的字（時間軸動畫抓著的 span）收起來、放整段新的字；改回來把原本的 span 原樣放回，動畫照舊。
   - `editor/live-sound.mjs liveStrip` 拿掉 `ending.x／y／size`：只改位置、字級不用「更新預覽」；改字照樣要（文字動畫照字數排時間）。

## 分段照作者打的、框寬、段落間距（r30 試用後）

作者原話：「為什麼逗號不見了，我覺得這塊應該要完全符合我的段落規則吧，然後應該要可以選擇段落上間距會更完善」；看完第一版（不折行、間距四選一）：「我認為段落間距可以手動調整，然後如果外框固定寬度，應該要可以自動換行吧」「另外我覺得可以參考剪映我原本設定的字級跟間距」（選了：加「行距」滑桿、數字改用剪映的單位）。

- **分段**（`editor/ending-layout.mjs quoteParse`）：plan.json 的 `ending.quote` 有換行（或 `//`）＝作者自己分的段：一段一個區塊，逗號、句號照留，一段太長照框寬自動換行（`overflow-wrap: anywhere`，標點不放行首、英文字不拆開）。沒有換行的舊寫法、講稿的 `>` 引言、金句字卡照舊（逗號分段、拿掉句尾句號、`word-break: break-all`）。剪輯台文字框照畫面上的分段放。
- **框寬**：`ending.w`（px）。沒寫＝580 跟著字級等比例（和以前一樣）；寫了就固定，最窄兩個字。剪輯台：拖金句框的右邊（黃色短條）、屬性面板「框寬」滑桿；拖右下角放大字級時，拖過框寬的跟著等比例。夾在畫面裡，超出右緣 ⚠。
- **段落間距**：`ending.gap`（段與段之間空幾行，0–2，取到 0.05；預設 1＝以前的空一行）。剪輯台「段落間距」滑桿，旁邊寫 px。
- 位置、字級、框寬、段落間距都即時套用（liveStrip 拿掉 x／y／size／w／gap；完成影片預覽改 `#end-quote` 的寬與 `.el + .el` 的 margin-top）。`--set ending.w=700`、`--set ending.gap=0.5`。
- **主合成**：每段一個 `<span class="el">`（區塊），段與段之間 `margin-top: gap px`；打字機再一個字一個 `.ec`。以前打字機、淡入、直接出現用 `<br><br>`，看起來一樣（空一行＝73 px）。
- 報告、檢查報告：`quoteLines`、`quoteManual`（剪輯台不能再用逗號切段）；作者分的段報告用「／」隔開；拖過寫「框寬 N」，調過寫「段落間距 N 行」。
- **剪映的單位**（`editor/ending-layout.mjs JY`，對照 `jianying-editing/scripts/tpl_ending_quote.json`：字號 7、行間距 0.07、固定寬度 290、段與段之間一個空行）：剪輯台的滑桿寫剪映的數字，括號裡寫畫面上的 px。字號＝px × 7／48；固定寬度＝px ÷ 2；行高＝字級 ×（1.448＋行間距）（1.448＝思源黑體一行本來的高；48 ×（1.448＋0.07）＝72.9 ≈ 73，和以前一樣，其他字級最多差 1 px）。
- **行間距**：`ending.lineSpacing`（0–1，取到 0.01；預設 0.07 不寫）。剪輯台「行間距」滑桿，即時套用；`--set ending.lineSpacing=0.2`；超出 ⚠ 夾住；報告寫「行間距 N（行高 px）」。段落間距照行高算（空一行＝一個行高）。
