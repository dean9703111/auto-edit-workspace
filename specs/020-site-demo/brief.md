# 020 官網可操作示範（第一批：剪輯清單、分鏡表）

來源：作者 2026-11-06 說「官網目前都是用截圖，不如直接上真正可以模擬操作的畫面，呈現都是現有的」；同意先做剪輯清單和分鏡表，看過效果再決定要不要往下做。

## 定案

| 題目 | 定案 | 理由 |
|---|---|---|
| 介面 | `build-site.mjs` 直接複製 `shared/template/tools/editor/` 的 cuts、storyboard 頁，只把絕對路徑改成相對路徑 | 不維護第二份介面；產品改版官網跟著變 |
| 後端 | `dev/site/demo/demo-api.js` 攔 `/api/*`，在瀏覽器裡回應；修改只留在記憶體，重新整理就還原，不送任何請求 | 官網是靜態網站 |
| 邏輯 | 分鏡表的解析與修改抽成 `editor/storyboard-md.mjs`（不用 Node），服務和示範共用；剪輯清單的狀態由 `demo-core.mjs` 算，測試比對和 `cutsState` 相同 | 示範不會和真正的行為走樣 |
| 示範內容 | `dev/site/demo/cuts.md`、`storyboard.md`；`docs-visuals.mjs` 也讀這兩份 | 只有一份 |
| 入口 | 截圖上的「▶ 直接試用」按鈕，按了才載入 iframe | 不拖慢首頁；沒有 JS 時截圖照常 |
| 手機 | 維持截圖，不出現按鈕 | 介面是為桌面設計的 |
| 讓人知道是示範 | 頁面頂端固定示範列；存檔狀態寫「已存到 瀏覽器（示範）」 | 不假裝真的存檔 |
| 看背後的資料 | 示範列有「看背後的 Markdown」，內容跟著修改更新 | 這是這個產品的賣點 |
| 影片 | 內建示範講者的靜態圖、沒有聲音（81 KB），示範列寫明 | 不用作者真人素材；要有聲音得另外錄 |
| README | 維持截圖，多一個連到官網試用的連結 | GitHub 不能跑互動頁 |

範圍外：構圖、背景、剪輯台維持截圖。
