## 流程

```
0 --scaffold：切份（## 或約 2,000 字）、太小的份合併
1 分章子代理（平行，第一回合）：寫語意地圖 → --map 檢查
2 主代理（只讀合併後的地圖）：A 全片排序、貫穿主題、校正標籤 → --map-merge
3 分章子代理（第二回合）：照地圖寫大綱（模板從工具縮好的 1–3 個裡挑）→ 骨架 → 填字 → --check-draft
4 --merge-drafts → 分鏡表（停點 ③，跟現在一樣）
```

### 0. 切份（`--scaffold`）

- 有 `##` 照章節切；一份去標點超過 2,000 字，就切成差不多大的幾份（每份 ≤ 2,000 字），切點先挑最接近目標字數的 `###` 小節開頭；沒有小節才挑那附近停頓最長的地方。
- 沒有 `##`：整支照上面切。
- 不到 600 字的份併到相鄰那份（挑併起來比較小的一邊，併完 ≤ 2,000 字），一直併到夠大或沒得併；每章的章節段都留著（第二章起 id 加 b、c）。EP1 實測：開場＋影片大綱合成一份（535 字），6 份變 5 份（535、1,582、959、1,339、702 字）。
- 用字數取代秒數（`PART_MAX` 480 秒、`PART_TARGET` 300 秒）：模型要讀懂的是字，語速快慢不該改變一份的份量。2,000 字在 EP1 的語速約 6.8 分鐘。兩個數字定義在 `style.md`。

### 2. 全片校正（主代理）

`build.mjs --map-merge` 把各份地圖接成 `work/分鏡素材/語意地圖.md`（EP1 約 80–100 行），附摘要：每型幾段、A 提名照份列出、C 連續超過 3 段的地方、同一型在不同份分級不一致的地方。

主代理只讀這份（不讀字幕），做三件事，直接改各份 `map.md` 那幾行：

1. **A 名單**：全片排序，取預算內最好的；開場、結尾一定在；同一份不超過一半。
2. **貫穿主題**：寫進 `視覺語言.md` 的「貫穿全片的主題」與「配色」（取代現在的導演子代理；導演那份工作從「讀全片字幕」變成「讀地圖」，主代理自己做就夠）。
3. **標籤校正**：同樣的內容標法要一樣（例：一份標「步驟」、另一份把同類內容標「列舉」）。

### 3. 照地圖寫草稿（分章子代理，第二回合）

- 平台能接續子代理（Claude Code 的 SendMessage）：同一個子代理接著做，不重讀字幕。不能接續（例如 MiniMax Code 不支援）：重派，派工訊息帶自己那份校正後的地圖；這一回合仍要讀 `chNN.md` 的字幕來填字，但不再讀 `共用.md` §3（要你決定 3）。
- `--outline` 多讀 `map.md`：每行地圖印出縮好的 1–3 個模板（照語意＋特徵＋有沒有講者＋相鄰不同模板），子代理從裡面挑；A 的段照樣先放模板，理由寫進 `story.designIdea`；C 的段工具直接排字卡動態或關鍵詞，子代理只填字。
- 之後的骨架、`--check-draft`、`--merge-drafts`、分鏡表都不變。

## 品質護欄（對應「會不會降低品質」的四個風險）

| 風險 | 護欄 |
|---|---|
| 專用模板（`x-crowd`、`x-architecture-send`…）被通用模板蓋掉 | 特徵欄讓工具縮到那幾列；驗收量專用 `x-*` 的段數不能比現在少 |
| 先斷段再選模板，切出模板放不下的長度 | `--outline` 的段長檢查照留；放不下時工具建議併段或拆段，子代理改地圖那一行 |
| 分級判錯，該是 A 的被當成 C | 全片校正看得到 C 連續段；③ 照樣可以把任何一段升級成內容設計動畫（`auto-edit-review` 流程 D） |
| 同一語意永遠同一個模板，越看越單調 | 相鄰同模板 ⚠ 照留；同型連續出現時工具輪替候選模板 |
