## ③ ✖／⚠ 與改法（退路表用，給 `auto-edit-motion`、`auto-edit-review`）

| 看到 | 先做這個 |
|---|---|
| ✖ 未定位頂層 | 那個元素寫 `position: absolute` 和整數 px 的 `left`、`top` |
| ✖ 標題壓到內容 | 內容整組往下移到和標題列隔 40 px（下面每一層一起移） |
| ✖ 綁句失敗 | 照 → 改句號或詞；`no-seg` 就重跑 build |
| ⚠ 間距不足 | 內容整組往下移到 40 px |
| ⚠ 區塊重疊 | 移開到隔 24 px；刻意疊的加 `data-layout-allow-overlap` 並在回報寫理由（svg 線稿與連接線不算區塊，不會報） |
| ⚠ nowrap 餘裕不足 | 框加寬到訊息給的寬度，或縮短文字，不縮字 |
| ⚠ 右側空白過多 | 框寬改 `width: max-content`；同一欄等寬就讓 left 和 width 相同 |
| ⚠ 垂直不平衡 | 每個頂層元素的 `top` 照訊息加或減同一個數 |
| ⚠ 內距不足／行高不足 | 照訊息加寬加高；用 kit 的 `.sc-tNN` 字級 class（內距容許 2 px：差 ≤ 2 px 不報） |
| ⚠ 同一秒新元素太多／間隔太短 | stagger 改 0.5，或每個元素綁自己的句子 |
| ⚠ 完成態停太短 | 下一拍綁晚一點的句子；中間步驟改用「上一拍 + 秒數」，不要另外綁句（量的是兩拍之間畫面最長的一段靜止，拍前就開始的動作算到它結束為止） |
| ⚠ 最後一幕太短 | plan.json 這段的 `to` 往後延訊息給的秒數 |
| ⚠ 畫面沒有變化 | 照 → 在空檔裡那句補一拍 `P.at('#K@詞')`，讓那一刻有東西出現、亮起或換數字；一段要講的事太多就從那句拆成兩段（cli-003 §2.3c） |
| ⚠ 綁句對不上 | 照 → 把那個常數改成 `P.at('#M@詞')`（站名、項目在哪一句講到就綁哪一句的那個詞）；字幕那句真的是別的意思就保留，回報寫理由 |
| ⚠ 段長不符 | 結尾改 `P.end()`（不帶參數），刪 `const D` |
| ⚠ 沒有動畫分鏡 | 在 `work/storyboard.md` 這段底下照 `shared/template/BEATS.md` §1、§3 寫一張「#### 動畫分鏡 <段 id>」表，停點 ③ 給人看過再做動畫 |
| ✖ 缺拍／多出來的 P.at | 以停點 ③ 確認過的分鏡表為準：缺的拍在 script 開頭加 `const Tk = P.at('#N@詞')`；多的 P.at 刪掉，或分鏡表加一拍並重停 ③（同一個句號的 ＋秒數 拍用「上一拍 + 秒數」接，不用另外綁） |
| ✖ 語彙不存在 | 「動態」欄改成 `BEATS.md` §2 的名稱（訊息給最接近的一個），對象和參數寫在括號裡 |
| ✖ 分鏡表表頭不對 | 表頭照抄 `BEATS.md` §1，標題和表格之間只留空行 |
| ⚠ 分鏡用了沒做的動作 | 照分鏡在那一拍加 `BEATS.md` §2「對應」欄的 `P.*` |
| 同一條 ⚠ 改兩次還在 | 停下來，把那一行原文和 snapshot 給使用者決定 |

完整 msg／fix 原文：`cli-003.md` §2.1–§2.4（分鏡對齊 §2.3d）。

### §3 R7.3 骨架與方法表

骨架 `<script>` 段整段換成（其餘 HTML 不變；`#xflow-row` 的三個站改成每 0.5 秒進場一個）：

```html
  <script>
  (function () {
    var $q = function (s) { return typeof s === 'string' ? Array.prototype.slice.call(document.querySelectorAll(s)) : s; };
    const tl = gsap.timeline({ paused: true });
    const P = SceneMotion(tl, document.getElementById('x-flow'));
    [ 'in', 'out', 'drift', 'reveal', 'rise', 'maskUp', 'sideIn', 'sideOut', 'morph', 'push', 'count', 'bar', 'stroke', 'icon', 'check', 'type' ].forEach(function (k) { var f = P[k]; P[k] = function (s) { var a = Array.prototype.slice.call(arguments); a[0] = $q(s); return f.apply(P, a); }; });
    [ 'swap', 'axis', 'focus' ].forEach(function (k) { var f = P[k]; P[k] = function (s1, s2) { var a = Array.prototype.slice.call(arguments); a[0] = $q(s1); a[1] = $q(s2); return f.apply(P, a); }; });
    const T1 = P.at('#17'), T2 = P.at('#18'), T3 = P.at('#19');   // 講到那一句的開頭
    P.rise('#xflow-n1, #xflow-n2, #xflow-n3', 0.5, { stagger: 0.5 });
    P.in('#xflow-on1', T1);
    P.in('#xflow-on2', T2);
    P.in('#xflow-on3', T3);
    P.end();
    window.__timelines['x-flow'] = tl;
  })();
  </script>
```

「骨架的規則」改兩條、加一條：

- （取代 R:543）`- 時間軸的時間是「本段起點之後的秒數」。要對到某句字幕就寫 P.at：P.at('#18')＝那句開頭、P.at('#18e')＝那句結尾、P.at('#18@逐字稿')＝講到那個詞；要晚一點加第二個參數 P.at('#18', 0.3)。build 會把句子時間換成這段的秒數；句號或詞找不到時 --check 和 audit 都會 ✖。只綁每個新訊息的第一拍，同一件事接著發生的步驟用「上一拍 + 秒數」。`

方法表加 4 列（放在 `P.morph` 之前）：

| 方法 | 做什麼 | 預設 |
|---|---|---|
| `P.at(ref, off)` | 綁句：回傳這一句（或這個詞）在本段的秒數，`off`＝再往後幾秒。`ref` 寫法同 plan.json：`#18`、`#18e`、`#18@詞`、`#18+0.3`（`@詞` 要寫成字串字面值，build 才算得到）；也可以直接寫秒數 `P.at(3.2)` | `off` 0；找不到不會讓動畫壞掉，但 `--check` 與 audit 會 ✖ |
| `P.dur()`／`P.end()` | 這段的長度／把時間軸撐到這段結尾 | build 注入；plan.json 的 `to` 改了自動跟著變 |
| `P.focus(group, active, at, {dim, dur, ring})` | 一組裡只亮一個：active 亮度 1、其他降到 `dim`；`ring` 是每個元素裡亮框的選擇器（例 `'.xwarn-on'`），active 的框淡入、其他淡出；active 寫 `null`＝全部恢復。要照時間先後寫，而且每個元素要先進場 | `dim` 0.4、0.4 秒、`sine.inOut` |
| `P.type(sel, at, {cps, dur, caret})` | 打字：文字逐字出現，框的大小一開始就是打完的樣子（不會跳）；`<br>`、關鍵詞 `<span>` 原樣保留；打完游標消失（不閃） | 8.5 字／秒、等速 |
