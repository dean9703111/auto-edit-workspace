## 機制缺口

1. **情境（scenes/）沒有直式上限**：`portraitMax` 只在 `custom-fill.mjs`（fill.json）；scene.json 的 `max`、`maxItems`、`rules` 都是橫式的，`rules` 的 view 也沒有版式。04 家族直式放得下的量比橫式少（04a 每項 ≤ 13 字、04b 每項 ≤ 7 字、04c 站名 ≤ 3 字一行、04d 3 欄 ≤ 4 字／4 欄 ≤ 3 字），超過現在只會在 audit 才看到（04b 長項目 ⚠ layout-pad、更多內容會 ✖ clipped），`--check` 不會先提醒。建議 scene.json 也收 `portraitMax`（同一套寫法），直式專案 `--check` ⚠。
2. **排版程式不能換順序**：`data-<名>-portrait` 能換排法、間距，但 slot 的先後照 DOM，蛇形 2×2（04c、其他流程圖）做不出來。要有 `data-order-portrait` 之類的才能讓流程在直式改 2×2。
3. **小節角標 `.sc-sectag`（plan.json sections）直式字還是 40／38 px**，和 02 同一個問題，`main.mjs` 同一處可以比照加；不在這次指派範圍，沒改。
4. **舊的附件角標（`chtag`，`chapterBadge: false` 時）在直式 04 家族會落在舞台窗外**：`assemble.mjs` `chtagParts` 全畫面家族固定放 x 1424（小視窗欄），直式只看得到 x 120–1300。
5. **fx 的「直式預覽」（`fx/index.html`）沒有 `window.__regions`**：fx-20、fx-22 的直式參數在畫廊預覽看不到，只有直式專案 build 出來才看得到。
