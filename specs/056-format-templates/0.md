## 1. 情境動畫模板（`custom/x-*.html`）的直式寫法

### 什麼時候算「直式」

直式專案裡縮進上半的 1920×1080 子合成（`layout: "fullscreen"`，含直式預覽頁 `x-<名>-v.html`）：`kit/scene-motion.js` 判斷 `window.__regions` 有值、root 寬 > 高（009 的 `STAGED`），就在 root 寫 `data-format="portrait"`，`P.portrait` 是 `true`。

- 橫式：沒有 `__regions` → 不寫屬性，下面全部對不到，畫面逐像素不變。
- 疊加（`overlay`，1080×1920 座標）：寬 < 高 → 不寫；它本來就用直式座標寫。

### 寫法

| 要換什麼 | 寫法 | 誰處理 |
|---|---|---|
| 樣式 | `#x-<名>[data-format="portrait"] .xchk-row { height: 84px; }` | runtime 把 `#x-<名>` 改寫成 `[data-hf-authored-id]`，root 的其他屬性留著，所以對得到（x-checklist 實測）；預覽頁沒改寫，也對得到 |
| 排版屬性 | 任何 `data-<名>` 旁邊寫 `data-<名>-portrait`，例 `data-layout="row" data-layout-portrait="col"`、`data-gap="xl" data-gap-portrait="md"`、`data-justify-portrait`；root 上的也算 | `kit/scene-layout.js` 的 `portraitize`：`SceneMotion(tl, root)` 建立時、`SceneLayout.apply` 排版前（在 `widen` 之前）把值搬到 `data-<名>`。只換建立 SceneMotion 時已經在 DOM 裡的元素 |
| 字級 | root 寫 `data-portrait-type`（不用值） | `kit/scene.css`：直式時 `.sc-t30`–`.sc-t56` 一律換成 60px／行高 84（`--opt` 8）；60 以上不動 |
| 時間軸、數量 | script 裡 `if (P.portrait) …` | 綁句（`P.at`）不要分兩套；只換「做什麼」（例：少推一次、少一項） |
| 插圖（`kit/illus.js`）裡的字 | `[data-illus]` 元素寫 `data-text-scale-portrait="1.3"`（`data-text-scale` 是兩種版式都放大） | `ILLUS.mount(root)` 先叫 `SceneMotion.portrait(root)` 換屬性，再照倍數畫 SVG 的 `<text>`（REC、時間、搜尋列、書籤、視窗標題…）；形狀不變 |
| 鏡頭 | root 寫 `data-portrait-cam="free"` | `P.cam` 直式照橫式推（見下面「P.cam」） |
| 直式放得比較少 | fill.json 寫 `"portraitMax": { "items": 3, "items.text": 10, "title": 8 }` | `lib/custom-fill.mjs` 的 `portraitMaxWarnings`：清單名＝最多幾項、文字欄位＝最多幾字（全形 1、半形 0.5）、`<清單>.<欄位>`＝每項的那個欄位；直式專案超過 `build --check` ⚠（不擋），橫式不查。橫式上限（`max`、`maxItems`）照舊是 ✖ |
| 照詞換行（`P.chars` 拆成一字一格後，任何字之間都能換行） | timeline 開頭、`P.chars` 之前寫 `P.wrapWords('.xflow-text')`；`//` 斷開的每一行各自平衡加 `{ lines: true }`，「名詞：定義」在冒號後換行加 `{ colon: true }` | `kit/scene-motion.js`：直式才做（`P.portrait`，或元素所在的合成根高 > 寬＝1080×1920 的疊加），用 `Intl.Segmenter` 照詞包成不斷行的 span，標點和「的了嗎呢吧啊著過」黏前一個詞（收尾引號也是）、6 字以內的關鍵詞不拆；橫式不動。情境 06、08、09（含全幕版）、10、11、15 在用 |

為什麼字級表是 60 不是 57：縮 0.8475 後 57 剛好 48.3，可是 `P.spot` 把沒聚焦的列縮到 0.96，畫面上只剩 46.4（x-checklist 第一次試就 ⚠）。60 × 0.8475 × 0.96 ＝ 48.8。

### 檔頭

【版面】最後加一行「直式：」，寫直式改了什麼、放得下多少。範例（x-checklist）：

```
  直式：主卡位置不變（舞台縮放 0.8475）；root 的 data-portrait-type 把 52 字換成 60（畫面上 51，壓暗縮 0.96 時 48.8）；列高 80 → 84、空框 56 → 64
  （#x-checklist[data-format="portrait"]），4 項＋進度區＋間距＝504，上下各 38（第 1 列聚焦抬起後離標題列 ≥ 28）；
  項目 14 字 × 60 ＋ 列內 124 ≤ 1080，直式不用另設上限（不寫 portraitMax）。
```

直式不用改的模板也寫一行（「直式：不用改（最小字 xx px）」），之後的人才知道看過了。

### 直式的限制（子合成座標，縮放 0.8475）

- 舞台窗 x 120–1300、y 130–880：帶 id 的絕對定位元素擺位超出 → audit ✖ `portrait-window`
- 鏡頭推近後的內容外框：x 72.8–1347.1、y 130–908.8 → 超出 audit ⚠ `portrait-cam`
- 字：畫面上 ≥ 48（子合成 ≥ 57；有 `P.spot` 壓暗縮 0.96 的 ≥ 59，所以用字級表的 60）
- 第 1 列聚焦抬起後離標題列 ≥ 24（⚠ `title-gap`）、內容群到底塊的內距上下 ≥ 32（⚠ `layout-pad`）：列變高時常常撞到這兩條，x-checklist 列高 88 就撞了，84 才過

### P.cam 的結論

直式不帶位移、原點上緣中間（009 的寫法）是**刻意的**，不是漏做：卡頂就在舞台窗上緣 y 130（直式的 unsafe 線），離講者面板只剩 29–40 px；沒改版面的卡寬 x 120–1300，`{to}` 往焦點帶 k 0.12 再放大 1.04，左右就超出看得到的 x 73–1347。所以預設不變。

模板直式版面左右上下都留得出邊時，root 寫 `data-portrait-cam="free"`：`P.cam` 照橫式往焦點帶、原點 50% 50%，由 audit ⚠ `portrait-cam` 量有沒有出界。survey 說 x-prompt-tree「完成態靠推近」不正確：它的 `P.cam` 寫的是明確的 x／y／scale，完成態兩種版式都回到 scale 1；直式的問題是原點改成上緣中間，開場推近算出來的位置偏了（膠囊低了約 130 px）→ 包 C 改它時寫 `data-portrait-cam="free"` 就和橫式一樣。

## 3. 字卡動態（`fx/`）

- **band 類橫式裁切**（survey 共通發現 5）：修在 `lib/plan.mjs` 一處，不改特效檔。catalog `portrait: "band"` 的 14 張（07、09–18、21、31、33；07 縮放穿越也跨邊，一起算）橫式 `bg` 不寫時，用 catalog 自己的 `bg`（不透明整張幕，不縮到講者旁、不蓋臉）；明寫 `"none"` ⚠。直式照舊（band 直式本來就 ⚠「直式只剩中間一條」、直式不提供）。包 B 不用再改 `speaker-side.mjs`。
- **audit 的假 ✖**（`lib/audit-rules.mjs`、`lib/audit-page.mjs`、`audit.mjs`）：
  - `bg` 不寫＝透明，和 build 一致（舞台換算看 `item.opaque`，不看 plan 有沒有明寫 `bg: "none"`）
  - 捲軸型（25 翻牌、28 拉霸、29 里程表、30 標題切換）：直式量的時候保留 host 的 `data-layout-allow-overflow`，框外藏起來的字不報 clipped
  - 只量完成態：catalog 的 `done`（`timeline`＝時間軸最後一個補間結束、`label`＝時間軸的 `done` 標籤）在頁面上算，不量退場中飛出畫面的字；找不到就段尾前 0.6 秒
  - 3D 翻轉（`matrix3d`，例 fx-19 圓柱背面）的字照投影後的大小算
  - 壓到講者只算畫面（子合成）裡面的部分：推出畫面的詞換算後會落在講者框上，以前報 ✖ 蓋到臉（fx-05）
  - 02 章節角標（build 畫成常駐角標，沒有自己的段）指名了也不量（以前報 ✖ missing）
- 結果：直式 26 張 `portrait: "ok"` 的 fx 都 0 ✖（survey 時 40 張全 ✖）。fx-20、fx-22 字太小的 ⚠ 留給包 B。
