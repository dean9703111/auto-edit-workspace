# 044 提示卡只跳第一次、切換影片的選單重新設計

來源：作者 2026-11-15（同時開著六支課程宣傳片的剪輯台，port 4409–4414）：

1. 「然後『這裡是完成影片預覽的部分』彈窗第一次跳就好，不需要每次都出現，可能也在 setting 有記錄」
2. 「還有上方影片的下拉選單我希望有設計感一些，現在是默認的，還有破版」（附截圖：頁首左邊是「剪」標誌＋「剪輯台／ppa-短影片1」，右邊緊接一個瀏覽器原生樣式的下拉選單「ppa-短影片1 ⌄」）

## 現況（2026-11-15 盤點）

提示卡：

- 剪輯首頁有三張第一次才跳的提示卡：`#coach`（剪輯台）、`#coachFinal`（完成影片預覽）、`#coachRough`（字幕預覽），開場照這一頁是哪一種跳其中一張。
- 「看過了」只記在瀏覽器的 localStorage（`auto-edit-editor.coach.v2`、`…coach-final.v1`、`…coach-rough.v1`）。localStorage 是一個 origin 一份，每個剪輯台各佔一個 port＝各是一個 origin，所以每開一支影片都再跳一次；同一支影片換了 port 也會再跳。
- 這台機器的設定集中在 `shared/setting.json`（`lib/settings.mjs` 的 `readSettings`、`writeSetting`）；剪輯台已經會寫它（講者、字幕樣式的預設）。

切換影片（039 做的）：

- `project-switch.js` 在每一頁頁首的專案名稱右邊多放一個原生的 `<select id="projSwitch">`，寬 112 px、加上間距佔 128 px；名稱和左邊那一行專案名稱重複。
- 用無頭 Chrome 量（六個暫存專案，名稱照作者開的六支；流程列四步都確認過；剪輯首頁開 `?view=final`、有「下一步」那一格）：
  - 照原樣量：四頁在 860–1680 px（剪輯首頁另外量了 640、720、800 px）都沒有東西超出視窗、被切掉或疊在一起（039 為了這個讓頁首可以換行）。量到的是換行：剪輯首頁只開一個時 1116 px 就排得成一列，多了選單要 1244 px（量到 1240 px 還是兩列、1250 px 一列），中間這一段頁首是兩列（高 91 px，一列時 54 px），第二列只有靠右的按鈕。另外三頁各寬度都是一列。
  - 換行靠的是 `.topbar:has(.proj-switch)`。把這一條拿掉再量（等於瀏覽器不支援 `:has()`）：頁首要 1244 px 才排得下（最右邊的「?」右緣在 1228 px）：1120 px 時「修改單」「?」在視窗外，1160 px 時「修改單」被切一半、「?」在視窗外，1200 px 時「?」幾乎整顆在視窗外。這是唯一重現得出「右邊被擠到切掉」的情況，樣子和作者說的相符；作者實際用哪個瀏覽器沒有確認（文件寫的是 Chrome 或 Edge，兩個都支援 `:has()`）。

## 定案

### 提示卡

| # | 題目 | 定案 | 理由 |
|---|---|---|---|
| 1 | 記在哪 | `shared/setting.json` 的 `editor.seen`：`{ "editor": { "seen": ["coach-final.v1"] } }` | 這台機器所有專案、所有 port 讀同一份，也是作者說的「在 setting 有記錄」 |
| 2 | 代號 | 帶版號，和原本 localStorage 鍵的後半段一樣：`coach.v2`、`coach-final.v1`、`coach-rough.v1`（對照表是 `app.js` 的 `HINTS`） | 原本就靠換版號讓看過的人再看一次（`coach` 已經是 v2），這個做法要留著；兩邊同名，舊的 localStorage 紀錄照樣算數 |
| 3 | API | `GET /api/hints` → `{ "seen": […] }`；`POST /api/hints` 送 `{ "seen": "<代號>" }` → `{ "ok": true, "seen": […] }`。不併進 `/api/state` | 和載入狀態同時問，不多等；還沒重開的舊服務回 404，頁面當成「服務不會記」就好，不用認版本 |
| 4 | 兩邊都有紀錄時聽誰的 | 設定檔或 localStorage 有一邊記了就不跳。新的紀錄只寫設定檔；服務寫不進去才寫 localStorage | 設定檔是跨 port 的那一份。不採「只看設定檔」：作者已經在幾個 port 按掉過，那些紀錄要算數；測試和 `dev/tools/docs-visuals.mjs` 都是先塞 localStorage 讓提示卡不跳；舊服務也還要靠它 |
| 5 | 舊的 localStorage 紀錄要不要自動搬進設定檔 | 不搬。只有按提示卡上的按鈕才寫設定檔，載入頁面不寫 | 載入就寫的話，截說明圖的工具、任何預先塞 localStorage 的頁面都會改到作者的設定檔。代價：服務重開後，在還沒按掉過的 port 會再跳一次，按掉就全部記住 |
| 6 | 怎麼寫 | 用 `writeSetting` 只換 `editor` 這一個鍵，`editor` 底下別的欄位留著，代號接在 `seen` 後面、不重複；最多記 50 個；代號只收小寫英數、點、連字號 | 「只增不覆蓋其他設定」；上限和格式是防頁面出錯把設定檔塞爆 |
| 7 | 設定檔壞了、寫不進去 | 讀：當成沒看過（回空清單）。寫：不是合法 JSON 回 500、`editor` 不是物件回 409，都不蓋掉檔案；頁面收到失敗就改記 localStorage | 最差就是照舊再跳一次，頁面不會壞 |
| 8 | 測試 | 用 `startEditor` 的 `speakerTemplate` 指到暫存的 `shared/template`（和講者、字幕預設同一個做法）；`AUTO_EDIT_NO_LOCAL_BRAND=1` 又沒有指過去時不讀也不寫（寫回 503） | 多數測試用真的模板開剪輯台，不能讓它們寫到真的 `shared/setting.json` |
| 9 | 三張提示卡 | 同一套：`closeHint(元素 id)`、`hintSeen(元素 id)`，三個按鈕用一個迴圈掛 | 之後加提示卡只要在 `HINTS` 多一行 |
| 10 | 送出 | `POST` 帶 `keepalive` | 按掉馬上換頁（例如切到別支影片）也記得到 |

### 切換影片

039 的定案 1–5、7–11（清單怎麼來、什麼時候顯示、選了去哪、多久更新、清單沒變不重畫、自己關了留著上一次的樣子）都不變；039 的 6、6a（選單長什麼樣、放不下怎麼辦）由下面取代。

| # | 題目 | 定案 | 理由 |
|---|---|---|---|
| 1 | 選單放哪 | 不再多放一個元素：頁首的專案名稱（`#projName`）本身變成切換鈕，右邊多一個小箭頭，滑過有底色，點了在下面展開清單 | 原本的選單和專案名稱是同一個字出現兩次，還多佔 128 px，是頁首多一列的原因 |
| 2 | 怎麼把專案名稱變成按鈕 | 不搬動、不包一層：在原本的 `<div class="sub" id="projName">` 上加 `class="proj-switch"`、`role="button"`、`tabindex="0"`、`aria-haspopup="listbox"`、`aria-expanded`、`aria-controls="projList"`；箭頭用 `::after` 畫。只剩一個時把這些拿掉 | 這一行的字是各頁自己寫的（`textContent`，構圖頁還帶版式和尺寸），放子元素會被洗掉；只加屬性就互不干擾，四頁的 HTML 也不用改 |
| 3 | 清單 | `#projMenu`（浮在頁面上的面板）裡一行小字「切換影片」，下面 `#projList`（`role="listbox"`）一列一支（`role="option"`）。現在這一支：主色的勾、粗體、主色淡底、`aria-selected="true"`；滑過或鍵盤移到的那一列有底色；名稱太長用 …（`title` 是全名） | 語彙照 `editor.css` 原本的：面板＝`--card` 底＋`--line2` 框＋陰影（和右下角的提示訊息同一組），選到的＝主色淡底（和輸出選項同一個做法），滑過＝`--plate` |
| 4 | 鍵盤 | 切換鈕：Enter／空白開關、↑ ↓ 展開並移到這一支、Esc 收起來。清單：↑ ↓（到頭就停）、Home／End、Enter／空白選、Esc 收起來回到切換鈕、Tab 收起來往下一個走 | 作者要的；和原生下拉選單的手感一樣 |
| 5 | 剪輯台的快捷鍵 | 選單開著時，按鍵不往外傳（⌘／Ctrl 的組合鍵除外） | 剪輯首頁整頁都在聽快捷鍵：不擋的話在選單裡按空白會播放、按 Delete 會刪掉選到的段 |
| 6 | 收起來之後焦點在哪 | 鍵盤收的回到切換鈕；滑鼠收的（點外面、再點一次、點這一支）不留焦點 | 滑鼠點完之後按空白鍵要照舊是播放，不能又把選單打開 |
| 7 | 什麼時候收起來 | 選了、Esc、Tab、點選單外面、視窗失去焦點（包括點進預覽的播放器） | 播放器在 iframe 裡，點它不會通知外面的頁面，要靠視窗失去焦點 |
| 8 | 選了之後 | 先收起來再換頁；選這一支只收起來 | 039 的 11：按上一頁回來、或有東西沒存而留在這一頁時，選單是收著的 |
| 9 | 選項用 `<div>` 不用連結 | 是 | 用連結就多了「按著 ⌘ 點＝開新分頁」這個沒有人要的功能要顧 |
| 10 | 寬度 | 切換鈕比純文字寬 19 px（箭頭）。字最多能顯示的寬度和原本一樣（`max-width` 從 16vw 改成 16vw＋26 px，多的是內距）。視窗 860 px 以下原本會把這一行藏起來，變成切換鈕時照樣顯示 | 不能因為變成按鈕，構圖頁那一行就少顯示幾個字；窄視窗也要能切 |
| 11 | 放不下時 | 039 的換行留著當保險，但不靠 `:has()`：`project-switch.js` 在頁首加 `class="has-switch"`，樣式寫 `.topbar.has-switch { flex-wrap: wrap }` | 多 19 px 之後，剪輯首頁 1135 px 以上一列（原本的選單要 1244 px；量到 1130 px 兩列、1135 px 一列）；再窄就兩列，不會超出視窗。破版只在 `:has()` 沒有作用時重現得出來，所以把這個依賴拿掉 |
| 12 | 亮暗 | 剪輯台的介面只有一套深色（`color-scheme: dark`，沒有亮色版）；屬性面板的「主題」換的是影片，不是介面。新樣式只用原本的顏色變數，主色跟著 `kit/brand.css` | 沒有第二套要顧 |
| 13 | 只開一個、讀不到、舊服務、官網示範頁 | 頁首和原本一模一樣：沒有 `.proj-switch`、沒有選單 | 039 的 7 |

## 沒做的事

- 作者截圖裡「選單右邊被切掉」只在換行規則不作用時重現得出來；作者的瀏覽器是不是這樣沒有確認，也沒有拿那台瀏覽器實際看過新的樣子。新的做法兩種情況都顧到：不再多佔那 128 px，換行也不靠 `:has()`。
- 作者開著的六個剪輯台，服務的程式在記憶體裡：頁面重新整理後選單就是新的，提示卡要等那一支的服務重開（下次跑 `editor.mjs --project …` 時工具會比對版本、自己重開）才是按掉一次全部記住，在那之前照舊一個 port 記一份。寫這份文件時（17:42）4409、4410 已經被別的工作重開、有 `/api/hints`，4411–4414 還是舊的。這次沒有動那六個服務。
