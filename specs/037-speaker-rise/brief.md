# 037 直式講者上浮

作者原話（2026-11-15）：「我發現短影片的上方資訊結束後，不是用人往上浮的方案，這個問題也請修正，全部短影片都要調整，背後程式邏輯一同優化」

## 現況（改之前）

- 進上下分割：講者從滿版的位置飛進下半的講者面板（`pipMotion` 的 `enter: 'fly'`，`main.mjs` 0.75 秒）。
- 出上下分割：資訊幕色帶收回 0.5 秒、講者面板 0.3 秒淡出（`exit: 'layer'`）。面板淡掉之後露出底下滿版的講者，人從下半「跳」回上面，沒有連續的動作。

## 定案

1. 直式、這一段結束後講者是滿版（沒有別的幕、不是旁白、沒有推近）時，講者面板最後一個片段的 `exit` 改成 `'rise'`，這一段的 `txOut` 記成 `'rise'`（錄影段 `txOut` 照舊是 `'media'`，`exitFx` 改 `'cut'`）。
2. 上浮＝飛入的反向：面板容器用同一組 `FLY`（x、y、scale）回到裁切框原本的位置，0.75 秒 `power3.inOut`；面板的裁切從 `overflow: hidden` 改成 `clip-path: inset(0)`，同時往四周打開到整支影片（`inset` 負值），所以面板上緣一路蓋過上半的資訊、下緣不會露出底下。落位那一格和底下的講者逐像素重合，下一格直接拿掉，沒有接縫。
3. 資訊幕（和直式墊的純色底）這時不擦、不淡：停在完成態被面板蓋過去，段結束直接拿掉。面板上緣的主色線 0.2 秒淡出。
4. 不做的情況（照舊）：片尾 1 秒內結束的段（畫面要停在完成態）、講者面板片段不到 1.6 秒（飛入＋上浮會重疊）、後面直接接另一張幕、錄影段寫了 `exit` 是 slide／zoom／whip、橫式。
5. 報告的「轉場」那一行多一項「講者上浮 N（段）」；動畫分鏡第 0 拍的語彙多「講者上浮」。

- `shared/template/tools/lib/main.mjs`：`V2TX.rise`／`riseLine`、`.pip--rise`、上浮的兩條補間、`txOut === 'rise'` 的段不做退場。

## 同一輪一起做的兩個小修（2026-11-15）

### 直式的全畫面幕不放背景圖

作者原話：「短影片切上下時，上方背景圖會有一條線，感覺怪怪的，請優化」

- 原因：全畫面的背景圖 `bg-fs.jpg` 頂端有一條裝飾線。直式把 1920×1080 的幕整張縮進上半面板，那條線就橫在面板上緣，和上下墊的純色底（`#bd-<id>`）接不起來。
- 改法：`lib/main.mjs` 的 `bgCss(prefix, bg, { portrait })`，直式時 `.sc-surface-fs` 只用底色（`background-image: none`），也不輸出全寬版的那一條規則。橫式輸出不變。章節幕（`bg-ch`）沒動：短影片不到 180 秒，不放章節幕。

### 去背標記的屬性順序不拘

- `lib/matte.mjs` 的 `matteKindOf` 原本只認 `data-composition-id` 後面的 `data-matte`。內容設計動畫的設計師把它寫在前面時認不到：去背不會跑，audit 還會報「蓋到講者的臉」。現在根元素上寫在前面或後面都認得。
- 用法（還沒寫進設計師文件，這次是派工訊息裡交代的）：疊加的內容設計段（plan.json `"design": true, "layout": "overlay"`）根元素加 `data-matte="1"`，build 會把這一段的講者去背後疊在畫面上面；直式實測可用（ppa-短影片4 的開場）。
