# 規格：023 emotion-sfx-camera（音效照講者的情緒放；講者爆衝推近；甩鏡、柔焦、2.5D 俯仰）

**Feature Branch**: `023-emotion-sfx-camera`

**Created**: 2026-11-09

**Status**: 作者驗收通過（2026-11-09 驗收單：畫面五項可以、參數照做）

**Input**: 作者（2026-11-09）：「目前整體的音效使用率跟時機並沒有根據情緒出現，或許這個在一開始的預覽就能設計好？請評估方案」；看了「AI 影片製作用到的 24 個鏡頭運動名稱」後問「這種鏡頭語言，已經出現在目前的設計嗎？」。決定單（https://claude.ai/artifact/HGf5p1Gt3Z7TYq1pPwtj8f）貼回：

> 1 音效決定方式：A 情緒點先行／2 新增音效：先用現有 9 顆／3 鏡頭：講者爆衝變焦＝要；甩鏡轉場＝要；柔焦換焦點＝要；2.5D 俯仰進場＝要；手持微晃＝不要；推拉變焦＝不要／我先定的：照做

「我先定的」四條：每分鐘 ≤ 2 顆主音效、相距 ≥ 3 秒不變，超過時照情緒強弱留（金句、反轉 > 痛點、解法 > 落定）；音效峰值對齊 `#N@詞`；剪輯台改過的音效最優先；預覽不 render，情緒曲線畫在分鏡表頁。

## 問題

音效原本跟著「選了哪個模板」走（07 `tone: warn` 就配 alert），不是跟著講者講到哪裡有情緒；一分鐘超過 2 顆時照模板順序砍，講者真正的痛點、反轉可能被砍掉，留下的是無關緊要的預設音效。

## 做法

### 1. 情緒點（plan.json 第一層 `moods`）

```json
"moods": [
  { "at": "#12@千萬不要", "kind": "pain", "zoom": true },
  { "at": "#30@竟然", "kind": "turn" },
  { "at": "#61@一個小時", "kind": "land", "sfx": null }
]
```

| kind | 中文 | 音效 | 強弱 |
|---|---|---|---|
| `quote` | 金句 | sparkle | 5 |
| `turn` | 反轉 | shine | 4 |
| `pain` | 痛點 | alert | 3 |
| `win` | 解法 | success | 3 |
| `land` | 落定 | impact | 2 |

- 峰值對齊 `@詞` 的開口（`event − peak + 1 格`）；`sfx` 換一顆、`null` 不出聲；附加音效（click）不能用。
- 取捨優先序：段上明寫的 `sfx`、章節音效（100）> 情緒點（10 + 強弱）> 模板預設（0）。同一分鐘有情緒點時，模板預設音效先讓位（`sfxYield`）。3 秒內兩顆留強的；一分鐘超過 2 顆照強弱留；每集上限（sparkle 6、shine 3、thunder 3）超過照 `SFX_SWAP` 換。
- 沒寫 `moods` 的舊專案行為不變（模板預設音效的優先序都是 0，和以前一樣照 KEEP_FIRST、時間排）。

### 2. 講者爆衝推近（`zoom: true`）

- 詞開口 0.2 秒 `expo.out` 推到 1.25 倍，停到這句講完（最少 0.8、最多 2.5 秒），收的時候直接切回；中心是講者框的臉（框中心、上方 30%）。
- 每分鐘最多 1 次（同一分鐘留情緒強的）；那一刻講者被整張幕、側邊欄蓋住或只有聲音 → 拿掉；遇到接點、整張幕提早收，0.8 秒內就會被切掉 → 拿掉。原因寫進 `--check` 的「講者爆衝推近」行。
- 寫在 `#footage` 的 scale 補間；已經在剪輯台「放大」區間裡時從那個倍率推。

### 3. 流程接點

| 步驟 | 做什麼 |
|---|---|
| `--scaffold` | chNN.md 加「情緒點」一節：這份約幾個、最多幾個、推近最多幾次，列字幕裡的候選詞（`moodCandidates`，只是提示） |
| 分章草稿 | 草稿 JSON 寫 `moods`；`--check-draft` 數量、推近次數 ⚠，詞對不到 ✖ |
| `--merge-drafts` | 收進 plan.json（放在 `scenes` 前面）、`_merged.json` 留全部候選 |
| `--storyboard` | 「需要我決定的事」前面加情緒點勾選表（時間、音效照 `--check --json` 的實際結果；推不到照實寫）；分鏡表頁上方畫情緒曲線（不 render） |
| `--apply-storyboard` | ☑ 留、取消拿掉、勾回候選加回 |
| 剪輯台 | 音效軌畫情緒點菱形（實心＝出聲、空心＝不出聲或讓位、外圈＝推近），只能看 |
| `--check --json` | 第一層 `moods: [{ i, kind, at, outAt, sfx, dropped, off, zoom }]` |

### 4. 甩鏡、斜躺擺平、換焦點（media 段與 kit）

| 鏡頭語言 | 寫法 | 做什麼 |
|---|---|---|
| 甩鏡轉場 | media 段 `"enter": "whip"`、`"exit": "whip"` | 0.3 秒從右甩進（expo.out）、往左甩出（expo.in），最快那幾格拉長 1.15 倍、模糊 24px；不配音效 |
| 2.5D 俯仰進場 | media 段 `"enter": "tilt"`（只有進場） | 面板以底邊為軸從透視斜躺（rotateX 22°、rotateY −8°）0.65 秒擺平；要 `fit: "contain"`（cover ✖） |
| 柔焦換焦點 | kit `P.rack(ALL, sel, at, {blur, dim})` | sel 清楚、同組其他模糊 6、稍淡 0.75，0.45 秒；`null` 全部回清楚；用 CSS filter，不和 `P.spot`／`P.dim` 搶 opacity；audit 詞彙「換焦點」 |

- 前一段是整張幕時，甩鏡、斜躺和 slide／zoom／tape 一樣墊在底下直到進場完成；小視窗在接縫交棒（順手修好墊底期間兩個小視窗），甩鏡、斜躺進場時小視窗原地淡入、不飛。
- 剪輯台進出場下拉加甩鏡；斜躺只在進場、cover 段不顯示；快速試聽有示意。
- 什麼情況用哪一種寫在 style.md「螢幕錄影與圖片」：節奏快、講一句就切去看操作 → 甩鏡（相鄰兩段 media 不要都甩）；第一次端出成品 → 斜躺擺平；參考圖貼背景 → 紙膠帶。

**章節甩鏡不做**（作者 2026-11-09 驗收單：先不做）：章節擦入已經是轉折的訊號；直式章節的宿主已經有 stageTransform，和 GSAP 的 x／scaleX 打架；分鏡表每個章節都寫「章節擦入」。

## 實作時發現的舊問題（作者 2026-11-09 驗收單：修、audit 先擋下）

- **整張幕蓋住錄影進場**：整張幕從錄影擦進來時 z 31，緊接著用 slide／zoom／tape／whip／tilt 進場的 media 段（z 30）進場那幾格被蓋住。→ 墊底進場時素材提到和前一段同一層（同 z 照 DOM 先後，後面的在上；不會一路往上疊）。media.test 驗 z 與順序（拿掉修正會失敗），snapshot 25.98 秒錄影甩進蓋在幕上。
- **P.* 選擇器從最外層 id 開始**：HyperFrames 0.9 把子合成插進完成影片時，最外層 `<div id="x-…" data-composition-id>` 的 id 被拿掉（完成影片預覽實測：`#xr-1` 的上層是沒有 id 的 div，再上層是宿主 `el-x01`）。CSS、動畫檔自己的 `document.querySelector*`、GSAP 字串照樣找得到（實測 `document.querySelectorAll('#x-rack #xr-1')`、`tl.to('#x-rack #xr-2')` 都有作用）；kit 的 v2 原語用 `root.querySelectorAll` 直接查（`KIT_ROOT_QUERY` 27 個：pop、dim、rack、spot、chars、wipe…）→ 找不到：pop／dim 靜靜沒有動畫，rack／spot 丟錯、整段動畫消失。→ audit ✖ `root-selector`（只擋這 27 個；舊原語走 GSAP，留著最外層 id 反而不會選到同一支範例在另一段的元素），kit-syntax.md 加一句。範例原本就踩到的一起改：x-crowd 的 pop、dim，x-crowd-queue、x-ui-mock-tidy 的 pop，x-scene 三支的骨架描線（含 preview 圖庫複本）——這幾處在完成影片裡一直沒有動畫。
