# 057 剪輯台：背景音樂軌與音量滑桿

2026-11-16 作者在 ppa-主宣傳片 加了底樂（`bed.music=bed-skyward`），打開剪輯台問「他應該會出現在下方背景音樂嗎？」，聽完說明後：「要加，時間軸加背景音樂軌和音量滑桿」。

現況：
- build 會把底樂混好，放進合成檔：`<audio id="bgm-bed" src="assets/bed-<曲名>-<hash>.wav" …>`。淡入淡出、講話時壓低都已經算進那個 wav。
- build 印一行「底樂：<曲名>（plan.json）鋪 0:00–2:01，講話時比人聲小 20.0 dB（…），淡入 2 秒、淡出 3 秒」。
- 剪輯台的時間軸只有六軌：字卡／動畫、素材、主軌畫面、字幕、人聲、音效（`editor/timeline.js` 的 `TRACK_NAMES`）。
- 「整支 → 聲音」只有人聲、音效、素材原聲三個滑桿（`editor/app.js` 的 `vol.*`）。
- 底樂音量只能用 `build.mjs --set bed.volume=<dB>`（−12～+12）調。

## 要做的（我先定的，作者事後可以推翻）

1. **時間軸「背景音樂」軌**，放在「音效」下面。
   - 有底樂時畫一條：
     - 從鋪的起點到終點。
     - 條上寫曲名。
     - 頭尾畫出淡入、淡出的斜坡。
     - 講話時壓低的區間畫得比較低或比較暗；這一集「整段固定音量」就不畫壓低。
     - 能照人聲軌的做法畫出底樂 wav 的波形更好。
   - 沒有底樂時，這一軌照樣顯示，裡面一行淡字「沒有背景音樂」。這一集寫了 `bed.music=none` 時，淡字改成「這一集不配」。
   - 點這一軌：右側跳到「整支 → 聲音」，背景音樂滑桿亮起來。
   - 不做拖曳改時間、換曲。
2. **「整支 → 聲音」加「背景音樂」滑桿**，放在素材原聲下面。
   - 範圍 −12～+12 dB，一格 1 dB，寫 plan.json 的 `bed.volume`。檢查規則和 `build.mjs --set bed.volume` 一樣。
   - 顯示格式和其他三個滑桿一樣。
   - 沒有底樂時滑桿是灰的，提示「這一集沒有背景音樂」。
   - 拖的時候預覽的音量要馬上跟著變，做法照其他滑桿。下次 build 會用新的 `bed.volume` 重混 wav，不能和即時調整重複疊加。
   - 「恢復預設」之類的既有按鈕，行為和其他滑桿一致。
3. **說明與文件**：
   - `editor/index.html` 的操作說明加一行「背景音樂」。
   - `shared/template/EDITOR.md`「剪輯台會寫哪些欄位」加 `bed.volume`。
   - `.agents/skills/auto-edit-style/references/music.md` 的「底樂大聲一點／小聲一點」補一句：剪輯台「整支 → 聲音 → 背景音樂」也能調。

## 驗收

- 剪輯台相關測試（`dev/tests/editor-*.test.mjs`）和 `dev/tests/docs.test.mjs` 都過。
- 新增測試涵蓋：
  - 有底樂、沒有底樂、`bed.music=none` 三種情況，這一軌顯示什麼。
  - 滑桿寫進 plan.json 的 `bed.volume`，超出範圍不寫。
- 用暫存專案在瀏覽器看過：軌道、斜坡、滑桿、即時音量。不要拿真的 `projects/ppa-*` 測試。

## 第二輪（2026-11-16 21:15）

作者看了第一輪做好的軌道和滑桿：「背景音樂應該也是用原始的音量，但是我可以透過調整拉 bar 才比較合理吧？一樣要有關閉鎖定等等的比較好辨識」。他在截圖裡把滑桿拉到了 +12 dB 上限。

我問新配樂預設放哪，作者選「預設 0 dB（原本音量）」。所以：

- **`bed.volume` 改刻度**：0＝曲庫檔原本的音量（−20 LUFS），範圍 −40～+6。
  - 講話時壓低（沒有剪段）：沒人講話時是曲庫檔＋volume，講話時用 sidechain 壓 6 dB。
  - 整段固定音量（有剪段）：整段都是曲庫檔＋volume。
  - 輸出的 true peak 要 ≤ −1。
- **背景音樂軌的標頭**：和人聲、音效軌一樣，有音量數字、靜音、鎖定。
- **ppa-主宣傳片**：原本寫了舊刻度的 `bed.volume: 12`，改回 0（預設）。
