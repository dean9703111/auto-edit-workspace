- 預設拍型：**D 清單**（BEATS.md §3 D）。
- 和 D 不一樣的地方：
  - 「彈出」方向反過來：從上方 28u 落下（`P.pop(..., { dy: -28, from: 0.94 })`）——堆疊的語意是「一層疊上去」；縮放起點 0.94（1064 寬的層從 0.82 放大太像拉近）。
  - 拍 0 多描一條地基線（看得出從哪裡往上疊）。
  - D 的「退焦（前一條 → 0.6）」用「聚焦」的壓暗做（`P.spot(..., { dim: 0.6 })`，下面已疊好的層都 → 0.6）；聚焦在＋0.6（層是新落下的，§7 第 4 條）。多「＋0.9 漂浮」（拍與拍之間的微動）。
  - 收綁「合起來就是…」那一句（`ALL`）；沒有那句時 `const ALL = T4 + 2.0`（＝D 的「最後一條＋2.0」，不是綁句點、不算停留）。
  - 層寬 1064，聚焦放大只用 1.02（放大 1.07 會撐到卡片邊）。
- 拍 0 的「講到」只寫「段起點」、不寫 `#110`：檔裡沒有綁段起點那一句的 P.at，寫了句號 audit 會報 ✖ 分鏡第 0 拍找不到對應的 P.at。
- 層與層間隔 ≥ 2.5 s（忙到＋1.1，停 ≥ 1.2）；ALL ≥ T4＋2.5；D ≥ ALL＋2.6。
- 弱模型要填：標題（≤ 10 字）、每層名稱（≤ 6 字）與說明（≤ 12 字）、圖示、每層的 `#N@詞`、`ALL` 的句號；層數 3–4（3 層刪掉 l4，位置與地基線由 data-layout 自動重排）。
- 人通常會改：落下要不要過衝（不要就加 `ease: P.V2.EASE.in`）、收綁哪一句。
