- 預設拍型：**C 對比**（BEATS.md §3 C）。左欄＝痛點（2–3 條，逐條進場），右欄＝解法。
- 和拍型 C 不一樣的地方：
  - C 的拍 1（左欄）展開成每個痛點一拍（像 D 清單：進場＋退焦前一條），因為痛點是逐條講到的。
  - C 的拍 2「劃掉」不另外綁句：綁在解法詞前 0.75 秒（講「所以我乾脆…」的時候），音效併到解法那一顆。原因：P.sfx 帶 off 會多一個綁句點，劃掉到解法只差 0.75 秒，audit 的「完成態停留」會 ⚠；弱模型的寫法（P1–P3、FIX）也不用多綁一句。
  - C 的拍 3「新的詞」與拍 4「優點的詞」合成解法一個綁句（FIX），爆點用 FIX＋0.6；音效用 shine（爆點），不用 success。
  - 劃掉用 `P.strike(…, { dim: false })`，壓暗交給「退焦（左欄 → 0.5）」：整列（圖示、字、紅線）一起退到 0.5，紅線不會比字更淡。
  - 光澤掃過打在解法卡裡的光澤層 `#xfix-gloss`（卡本身不裁切，聚焦的亮框才不會被切掉）。
- 弱模型要填：標題（≤ 10 字）、三個痛點（≤ 7 字）與「講到」`#N@詞`、解法（≤ 6 字）與副句（≤ 8 字，選填）、FIX 的 `#N@詞`、圖示。
- 人通常會改：劃掉要不要早一點（例如綁在「所以」那個詞）；解法的音效（shine 每集上限 3 顆，用完了改 success）。
