- 預設拍型：**D 清單**（BEATS.md §3 D；brief 指 x-callout 看 §4 通用排法或 F——§4 的結構和 D 相同，只差收在＋2.6；這支收綁總結句，所以照 D）。
- 和 D 不一樣的地方：
  - 多「拍 1 主體」：主體圓先彈出（標籤都是在講它，先讓觀眾知道主角）。
  - 每一拍多一條引線：彗星描線從標籤走到主體（P6「線要走過去」）＋端點小圓描線；上一個標籤的引線與端點退焦 0.6（只留一個焦點）。
  - D 的「退焦（前一條 → 0.6）」對標籤用「聚焦」的壓暗做（`P.spot(..., { dim: 0.6 })`），對引線用 `P.dim`（線不是聚焦群組的成員，兩種補間不落在同一個元素上）。聚焦在＋0.6（標籤是新彈出的，§7 第 4 條）。多「＋0.9 漂浮」。
  - 收綁總結那一句（`ALL`）；沒有那句時 `const ALL = T4 + 2.0`（＝D 的「最後一條＋2.0」）。收的「退焦（引線 → 1）」是把引線亮回（`P.dim(..., { to: 1 })`），語彙表沒有「亮回」這個動作。
- 拍 0 的「講到」只寫「段起點」、不寫 `#100`：檔裡沒有綁段起點那一句的 P.at，寫了句號 audit 會報 ✖ 分鏡第 0 拍找不到對應的 P.at。
- 標籤與標籤間隔 ≥ 2.5 s（忙到＋1.1，停 ≥ 1.2）；ALL ≥ T4＋2.5；D ≥ ALL＋2.6。
- 弱模型要填：標題（≤ 10 字）、主體圖示、標籤（≤ 4 字）與圖示、每個標籤的 `#N@詞`、`ALL` 的句號；標籤數 2–4（刪標籤照檔頭）。
- 人通常會改：引線要不要彗星頭（不要就把 `P.comet` 換 `P.stroke`）、收綁哪一句。
