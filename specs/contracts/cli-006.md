## 0. `--help` 原文

```
講者調光＋瘦臉（零依賴：Node 22、ffmpeg、HyperFrames 的 chrome-headless-shell、shared/template/vendor/mediapipe）

  node shared/template/tools/look.mjs run --project projects/<專案>               偵測臉部 → 瘦臉底片 work/rough-look.mp4 → 對照圖 work/look-preview.jpg
  node shared/template/tools/look.mjs run --project projects/<專案> --background  同上，改在背景跑（預估超過 2 分鐘時用；進度用 status 看）
  node shared/template/tools/look.mjs preview --project projects/<專案>           只重畫對照圖、重印偵測率與位移（不重新偵測）
  node shared/template/tools/look.mjs status --project projects/<專案>            設定、資產、快取、執行進度與下一步
  node shared/template/tools/look.mjs clear --project projects/<專案>             刪掉 landmark、瘦臉底片、對照圖與 work/.look/（下次重算）
  node shared/template/tools/look.mjs ensure [--download]                         檢查 shared/template/vendor/mediapipe 的 4 個檔（sha256）；--download 補下載缺的

run 的選項：--every 1|2（每幾格偵測一次；2＝偵測快一倍、中間內插；預設 1）、--force（不管快取全部重算）、--chrome <路徑>
設定：shared/template/kit/look.json（預設）＋ plan.json 第一層的 "look"（{ "color": 0–1, "slim": 0–1.2 } 或 false）
調光不用跑這支：build 重新編碼底片時直接 bake。瘦臉 > 0 時 build 要用最新的 work/rough-look.mp4，過期會停下來請你先跑 run。
```

## 1. 共用參數與退出碼

| 參數 | 子指令 | 說明 |
|---|---|---|
| `--project <路徑或名稱>` | run／preview／status／clear | 同 build.mjs |
| `--template <資料夾>` | 全部 | **測試用**：換 `shared/template`；文件不教使用者 |
| `--chrome <路徑>` | run | 指定 chrome-headless-shell（同 `audit.mjs`）；沒給就照 `findChrome()` 找 |
| `--every 1\|2` | run | 預設 1 |
| `--force` | run | 不看快取，偵測與變形全部重做 |
| `--background` | run | 轉到背景（§2.4） |
| `--download` | ensure | 下載缺的或 sha256 不符的檔 |
| `--help` | — | 印 §0，退出碼 0 |

| 退出碼 | 意思 |
|---|---|
| 0 | 完成（含 ⚠：瘦臉自動略過、偵測率 < 95 % 等） |
| 1 | 有 ✖（缺 rough.mp4、缺 Chrome 或資產而且瘦臉 > 0、Chrome 沒回應、長度不符、已經在跑、ensure 驗不過或下載失敗） |
| 2 | 參數錯誤 |

參數錯誤原文（審查 C-07）：`✖ 看不懂的參數「x」 → 看用法：node shared/template/tools/look.mjs --help`；`✖ 沒有 run／preview／status／clear／ensure 以外的子指令「x」 → 看用法：…`；`✖ 沒有 --x 這個參數 → 看用法：…`；`✖ --project 後面要接值 → 看用法：…`；`✖ 要給子指令（run／preview／status／clear／ensure） → 看用法：…`；`✖ ensure 不能加 --project → 看用法：…`；`✖ --every 只能是 1 或 2，現在是「3」 → 改成 --every 1 或 --every 2`。

所有 ✖ 行都是 `✖ <發生什麼> → <怎麼修>`；第二次失敗就停下來回報（憲法 III.4）。**`→` 後面有指令時，指令放在行尾、後面不接任何字**（說明放在 `→` 前面的括號裡），從指令開頭複製到行尾就能執行（審查 C-02）。

## 2. `look.mjs run`

### 2.1 行為

1. 讀設定（`resolveLook`）。color 與 slim 都 0，或 slim ＝ 0：印「不用跑」那一行，退出 0。
2. 檢查 `work/.look/state.json` 的 `run`：還在跑（pid 活著）→ ✖ 已經在跑。
3. 檢查資產（sha256，`ensure` 同一套）與 Chrome；缺 → ✖（因為使用者要的是瘦臉）。
4. **[1/3] 找臉**：平均抽 12 格（t ＝ (k＋0.5) ÷ 12 × 長度），用多尺度格子找臉，得臉寬中位數。換算到 rough-look 畫面 < 60 px → 存 `summary.slimOk = false, reason = 'small'`；12 格都沒有臉（沒加 `--force`）→ `reason = 'noface'`。兩種都**跳過 2、3**，直接畫對照圖（只有調光）。
5. **[2/3] 偵測**：landmark 最新而且沒加 `--force` 就跳過（印「用快取」）。否則逐格偵測，寫 `work/face-landmarks.json`。偵測率 < 80 % → `slimOk = false, reason = 'rate'`，跳過 3。
6. **[3/3] 變形**：瘦臉底片最新而且沒 `--force` 就跳過。否則解碼 → 變形 → 編碼到暫存 → 驗長度 → rename 成 `work/rough-look.mp4`。
7. 畫對照圖（同 `preview`）。
8. 全程把 stdout 同時寫進 `work/.look/run.log`（每次 run 覆寫），`state.run` 隨進度更新。

## 3. `look.mjs preview`

### 3.1 行為

- 需要 `work/face-landmarks.json`（或 state 記著 `reason = 'small'`，那時只畫調光）；都沒有：`✖ 還沒偵測臉部 → 先跑 node shared/template/tools/look.mjs run --project projects/<專案>`，退出 1。
- 選 6 格：頭、中、尾（長度的 5 %、50 %、95 %，往最近的偵測到的格對齊，±2 秒內找不到就用原格並標「沒偵測到」）＋頭偏離最大的 3 格（臉中心離中位數位置最遠，以臉寬為單位；彼此及和前 3 格至少相隔 2 秒）。
- 每列三欄：原圖（640×360；直拍來源 360×640，009 FR-101）｜套用後（同大小，調光＋瘦臉，用 ffmpeg lut3d 加 JS 變形）｜臉部放大（以臉中心為中心、邊長 2.4 × 臉寬，縮成 360×360）＋輪廓（綠＝原本的 OVAL、紅＝套用後的 OVAL）。列標題用點陣字寫 `mm:ss.s`（`lib/raster.mjs` 只有數字與少數符號，欄名寫在指令輸出）。
- 存 `work/look-preview.jpg`。不寫其他檔、不改快取。

```
講者對照圖：work/look-preview.jpg（6 列：頭 0:08.5、中 1:25.4、尾 2:42.3、頭偏離最大 1:58.2／0:41.0／2:05.6）
```

- ⚠（各自一行）：
  - `⚠ 偵測率 93.10%（< 95%）→ 看對照圖的未偵測區間；這些地方瘦臉會自動淡掉，不會跳`
  - `⚠ 位移 ＝ 臉寬 6.81%（95% 的格；> 6.5%）→ 瘦臉太強，脖子與領口可能被拉彎；把 slim 調低（plan.json 的 look.slim 或剪輯台「講者」）`（看 95 百分位；門檻與校準見 `contracts/look.md` §8）
  - `⚠ 有 120 格偵測到 2 張以上的臉（只瘦最大的那張）`
- 臉太小時：`講者對照圖：work/look-preview.jpg（3 列：只有調光 0.8；瘦臉略過：臉寬 43 px < 60 px）`；抽樣沒臉時括號裡是 `瘦臉略過：抽樣 12 格都沒偵測到臉`。
- 失敗：`✖ <原因> → <改法>`；原因本身沒有 → 時補 `→ 確認 rough.mp4 能播；第二次失敗就停下來回報`，退出 1。

## 5. `look.mjs clear`／`look.mjs ensure`

### 5.1 `clear`

- 刪 `work/face-landmarks.json`、`work/rough-look.mp4`、`work/look-preview.jpg`、`work/.look/`（都在 `work/` 裡，AGENTS.md 規則 1 允許）。正在跑時拒絕：`✖ 正在跑（pid N）→ 等它跑完或結束那個程序再 clear`。
- 印：`已刪除：work/face-landmarks.json、work/rough-look.mp4、work/look-preview.jpg、work/.look/（下次 look.mjs run 會重新偵測與變形；瘦臉 > 0 時 build 會請你先跑 run）`；沒東西：`沒有要刪的（work/ 裡沒有 look 的檔）`。退出 0。
- 文件只在「status 說快取壞了」或作者除錯時用；交付後這些中間檔要保留（AGENTS.md 規則 7）。

### 5.2 `ensure [--download]`

- 照 `shared/template/vendor/mediapipe/manifest.json`（格式見 `specs/006-look/plan.md` §3）逐檔驗 size 與 sha256。
- 印：
  ```
  資產檢查：shared/template/vendor/mediapipe（manifest.json，4 個檔，共 18,715,722 B）
    ✔ vision_bundle.mjs                  156,344 B
    ✔ wasm/vision_wasm_internal.js       334,128 B
    ✖ wasm/vision_wasm_internal.wasm     不存在
    ✔ face_landmarker.task             3,758,596 B
  → 加 --download 從固定網址下載缺的檔（約 14.5 MB）：node shared/template/tools/look.mjs ensure --download
  ```
  全部 ✔：最後一行 `✔ 4 個檔都對`，退出 0；有 ✖ 沒加 `--download`，退出 1。
- `--download`：用 Node 22 內建 `fetch` 從 manifest 的 `url` 下載到 `<檔>.download`，驗 sha256 後 rename；每檔印 `  ↓ wasm/vision_wasm_internal.wasm 14,466,654 B ✔`。失敗：`✖ 下載 <檔> 失敗（<原因>）→ 確認網路能連 cdn.jsdelivr.net 與 storage.googleapis.com；公司網路擋住時請作者把 shared/template/vendor/mediapipe/ 整個複製過來`，退出 1。sha256 不符：`✖ 下載的 <檔> sha256 不對（<前 12 碼>）→ 沒有換上去；來源可能被改過，停下來回報`，退出 1。
- 安裝類操作：AI 照 AGENTS.md 規則 3，跑 `--download` 前先告訴使用者指令與用途（下載約 18 MB 的臉部偵測模型，作者 2026-10-31 已核准這份資產）。
