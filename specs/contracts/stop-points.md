## 2. 固定回覆格式

### 2.1 最後兩行（逐字照抄，`<…>` 換成實際值）

| 停點 | 倒數第二行 | 最後一行 |
|---|---|---|
| ① | `⏸ 停點 ① 剪輯清單｜請看 <剪輯清單網址>` | `請回：勾好後說「可以」，或要改的列` |
| ② | `⏸ 停點 ② 構圖倍率｜請看 work/構圖預覽.jpg 和 work/構圖預覽-套卡.jpg` | `請回：倍率（1.0／1.15／1.3）` |
| ③ | `⏸ 停點 ③ 分鏡表｜請看 <分鏡表網址>` | `請回：改好後說「可以」，或要改的地方` |
| ④ | `⏸ 停點 ④ 完成影片預覽｜請看 <完成影片預覽網址>` | `請回：要改的段落（例：s05 往左移）或「可以了，輸出完成影片」` |
| ⑤ | `⏸ 停點 ⑤ 剪輯台｜請看 <剪輯台網址>` | `請回：調完說「調好了」（會自動存）` |
| ⑥ | `⏸ 停點 ⑥ 背景預覽｜請看 <暫存資料夾>/preview.jpg 和 <暫存資料夾>/zones-fs.jpg` | `請回：「可以」或「重做」` |
| ③ 改版（014） | `⏸ 停點 ③ 分鏡表（<段> v<N>）｜請看 work/版本/<段>/v<N>/分鏡.md` | `請回：「可以」或要改的拍` |

- 停點 ③ 的那一行和憲法 V 的範例逐字相同。
- ③ 改版是停點 ③ 的變體（停點仍是六個）：停點 ④ 之後指名一段重新設計時用；好幾段一起改寫成「（s08 v2、s12 v2）」、請看列出每一份 分鏡.md。`versions.mjs new` 會印出填好的這一行。停點紀錄的停點欄寫 `③ 分鏡表（s12 v2）`，status.mjs 照括號裡的段與版本給下一步。
- 路徑一律相對專案資料夾 `projects/<專案>/`（③），網址照工具印出的原文（① ② ④ ⑤；① 是 `editor.mjs` 印的「剪輯清單：」那一個），⑥ 的暫存資料夾寫完整路徑。
- 網址前面是半形空格、後面直接換行（2026-11-09）：緊接全形字（舊格式的「｜請回：」）時，有些 AI 工具會把後面的字當成網址的一部分，點開變「找不到這個頁面」；請看好幾個項目用「 和 」隔開，不用「、」。
- 「請回：」那一行之後不能再有任何文字。

### 2.2 整則回覆的骨架（≤ 15 行，憲法 III.5）

```
<做完什麼＋產物>：工具印的 ✓ 原文（檔名、一個數字）
<要你決定的事>：工具印的「需要你決定」原文；沒有就整段省略
<驗證>：只在產出檔案時寫（初剪、輸出）；工具已經印 ✓／⚠ 就貼原文，不另外跑指令（AGENTS.md 規則 6）
⏸ 停點 <編號> <名稱>｜請看 …
請回：…
```

- 網址只寫在停點那兩行；前面不寫「頁面 HTTP 200」這類驗證，也不在第一行再標一次停點編號。

例（停點 ①）：

```
✓ 剪輯清單：work/cuts.md（NG 4 列，其中待確認 1 列；章節 3 章）
需要你決定 1 項（work/cuts.md 最後一節）：
- 第 5 列「我們先看…」逐字稿和講稿對不上，標了待確認
⏸ 停點 ① 剪輯清單｜請看 <剪輯清單網址>
請回：勾好後說「可以」，或要改的列
```

## 4. 停點紀錄（寫回 `work/製作進度.md`，給 002 `status.mjs` 讀）

`work/製作進度.md` 裡固定有一節，標題逐字是 `## 停點紀錄`，下面一張表，欄位順序固定：

```
## 停點紀錄

| 時間 | 停點 | 狀態 | 使用者原話 | 寫回哪裡 |
|---|---|---|---|---|
| 2026-11-02 14:10 | ① 剪輯清單 | 待回覆 | — | — |
| 2026-11-02 14:20 | ① 剪輯清單 | 通過 | 「清單沒問題，繼續」 | work/cuts.md |
| 2026-11-02 15:02 | ② 構圖倍率 | 略過 | 「不用停」 | plan.json frame（採用 1.15，qc 建議） |
```

- 「時間」：`YYYY-MM-DD HH:MM`（本機時間）。
- 「停點」：`①`–`⑥` 加一個半形空格加名稱，名稱和 §1 第一欄一字不差。
- 「狀態」只有四種：`待回覆`、`通過`、`修改後重停`、`略過`。
- 每次停下來先加一列「待回覆」；使用者回覆後**新增**一列（不改舊列），寫通過／修改後重停／略過。
- 「使用者原話」逐字貼，用「」包起來；太長就截前 40 字加「…」。
- 判斷規則（`status.mjs` 照這個做）：同一個停點以**最後一列**為準；最後一列是「待回覆」的停點＝目前卡住的停點。

## 5. 「不用停」的條件

| 使用者說 | 效果 |
|---|---|
| 「不用停」「一路做完」「全部做完」 | 這一次的流程裡 ①–④ 都不停；⑤ ⑥ 照停 |
| 「跑到停點 N」「做到停點 N」 | N 之前的停點都不停，到 N 照停 |
| 「做到預覽」（舊說法「做到 Studio」） | 等於「跑到停點 ④」 |
| 「做到分鏡表」 | 等於「跑到停點 ③」 |

- **有效範圍**：只對說這句話的那一則訊息啟動的流程有效；下一則訊息沒有再說，就恢復每個停點都停。
- **⑤ 剪輯台不能略過**：剪輯台是使用者自己操作，沒人調就沒有東西可存。
- **⑥ 背景預覽不能略過**：寫 `shared/` 要使用者同意（AGENTS.md 規則 1）。
- 略過停點時一樣要寫檔、一樣要在停點紀錄加一列「略過」，並在最後的回報加一行 `⏭ 停點 <編號> 略過：<採用了什麼>`。採用的預設值：

| 停點 | 略過時採用 |
|---|---|
| ① | 照 `work/cuts.md` 原樣剪；「待確認」有寫字的列先把「剪」改成 `[ ]`，**不剪** |
| ② | `qc.mjs framing` 印的「建議」倍率（004 加這一欄，見 spec「請 004 加」）；沒有建議欄時用 1.0 |
| ③ | 草稿就是定稿；金句候選表沒勾的**不上** |
| ④ | 直接 `auto-edit-deliver` |
