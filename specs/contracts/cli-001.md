## 1. `node setup/install-skills.mjs`

把 `.agents/skills/auto-edit-*` 這 9 支 Skill **複製**（不是 symlink；Windows 的一般帳號不能建 symlink，分析報告 02 §5.4）到兩個位置：

| 位置代號 | 路徑（Mac） | 路徑（Windows） | 給誰讀 |
|---|---|---|---|
| `project` | `<工作區>/.claude/skills/auto-edit-<名稱>/` | `<工作區>\.claude\skills\auto-edit-<名稱>\` | Claude Code（專案層 Skill） |
| `user` | `$HOME/.minimax/skills/auto-edit-<名稱>/` | `%USERPROFILE%\.minimax\skills\auto-edit-<名稱>\` | MiniMax Code（`PROMPTS.md:127`、`setup/check.ps1:364` 用的同一個資料夾） |

- 工作區根目錄＝`setup/` 的上一層（用 `import.meta.url` 算，不看目前資料夾），所以在哪裡執行都一樣。
- 使用者家目錄用 `os.homedir()`；路徑一律 `path.join`，不寫 `~`（憲法 II）。
- 只用 Node 22 內建模組（`node:fs`、`node:path`、`node:os`、`node:url`），零依賴；不呼叫 shell、不呼叫 git。

### 1.1 參數

| 參數 | 值 | 預設 | 說明 |
|---|---|---|---|
| `--target` | `project`／`user`／`all` | `all` | 裝到哪裡 |
| `--dry-run` | — | 關 | 只印會做什麼，不寫任何檔 |
| `--check` | — | 關 | 只比對已安裝的和原始檔是否一致，不寫檔；不一致結束碼 1 |
| `--json` | — | 關 | stdout 只印一個 JSON（格式 §1.4） |
| `--dest <資料夾>` | 路徑 | — | **測試用**：把兩個位置都換成 `<資料夾>/project`、`<資料夾>/user`；給 `dev/tests` 用，文件不教使用者 |
| `--help` | — | — | 印用法（§1.5 原文），結束碼 0 |

不認得的參數：印 `✖ 不認得的參數：<參數> → 跑 node setup/install-skills.mjs --help 看可用的參數`，結束碼 2。

### 1.2 行為

1. 讀 `.agents/skills/` 底下名稱是 `auto-edit-` 開頭的資料夾，照名稱排序。每支都先驗證，任一支不過就整個不裝（結束碼 1）：
   - 有 `SKILL.md`；frontmatter 只有 `name`、`description`、`version` 三種欄位，`name` 等於資料夾名稱，`description` 是單行。
   - 驗證失敗印：`✖ .agents/skills/<名稱>/SKILL.md：<原因> → <改法>`（例：`✖ .agents/skills/auto-edit-rough/SKILL.md：frontmatter 有不允許的欄位 allowed-tools → 只能用 name／description／version`）。
2. 對每個目標位置的每一支：
   | 目標資料夾的狀態 | 做法 | 印的狀態字 |
   |---|---|---|
   | 不存在 | 建資料夾、複製整個 Skill 資料夾、寫標記檔 | `新裝` |
   | 存在，而且有標記檔 `.auto-edit-install.json` | 內容和原始檔一樣：不動。不一樣：整個資料夾換成新的（先刪掉這個資料夾，再複製）、重寫標記檔 | `沒變`／`更新（N 個檔不同）` |
   | 存在，但沒有標記檔（使用者自己的同名 Skill） | **不動**，記一個 ✖ | `✖ 衝突` |
   | 是 symlink | **不動、不跟著連結走**，記一個 ✖ | `✖ 衝突` |
3. 只碰 `auto-edit-` 開頭、而且有標記檔的資料夾；`.claude/skills/` 裡的 `speckit-*`、`~/.minimax/skills/` 裡的 `hyperframes`、`auto-editor` 等其他 Skill 一律不碰。
4. 原始檔不再有、但目標位置還有標記檔的 `auto-edit-*` 資料夾（Skill 改名或刪掉時）：印 `⚠ <路徑> 已經沒有原始檔 → 不用的話自己刪掉這個資料夾`，不自動刪（AGENTS.md 規則 1：刪 `work/` 以外的檔要先問）。
5. 標記檔 `.auto-edit-install.json` 內容：`{ "source": ".agents/skills/<名稱>", "version": "<SKILL.md 的 version>", "files": { "<相對路徑>": "<sha256>" } }`。比對「一不一樣」就比這張表和原始檔重算的 sha256。
6. 目標的上層資料夾（`.claude/skills/`、`~/.minimax/skills/`）不存在時自動建立。

### 1.3 印出的關鍵行（原文）

```
安裝 auto-edit Skill：9 支（來源 .agents/skills/）
  project  .claude/skills/auto-edit-longform        新裝
  project  .claude/skills/auto-edit-rough           更新（2 個檔不同）
  user     ~/.minimax/skills/auto-edit-longform     沒變
  …
✓ 完成：9 支 × 2 個位置，新裝 9、更新 1、沒變 8
```

- 路徑欄：`project` 寫相對工作區的路徑；`user` 在 Mac 寫 `~/.minimax/skills/…`、在 Windows 寫 `%USERPROFILE%\.minimax\skills\…`（只是顯示，程式內部用 `os.homedir()`）。
- `--dry-run`：每列狀態字前面加 `（預演）`，最後一行改成 `預演：9 支 × 2 個位置，會新裝 9、更新 1、沒變 8；沒有寫任何檔`。
- 有衝突：衝突那一列後面接 `→ 這個資料夾不是 install-skills 裝的；改名或移走它，再跑一次 node setup/install-skills.mjs`，最後一行改成 `✖ 有 N 個衝突，其他的已經裝好`。
- `--check` 一致：`✓ 9 支 × 2 個位置都和 .agents/skills/ 一致`。不一致：每個不一致的列印 `⚠ <路徑> 和原始檔不同（N 個檔）`／`⚠ <路徑> 還沒裝`，最後一行 `→ 跑 node setup/install-skills.mjs 更新`。

### 1.4 `--json`

```json
{ "ok": true, "dryRun": false, "check": false, "skills": 9,
  "items": [ { "skill": "auto-edit-rough", "target": "project", "path": "/abs/.claude/skills/auto-edit-rough", "show": ".claude/skills/auto-edit-rough", "status": "updated", "changed": 2 } ],
  "agents": [ { "agent": "auto-edit-worker", "target": "project", "path": "/abs/.claude/agents/auto-edit-worker.md", "show": ".claude/agents/auto-edit-worker.md", "status": "unchanged" } ],
  "conflicts": [], "orphans": [] }
```

`status` 只有 `installed`／`updated`／`unchanged`／`conflict`／`missing`（`--check` 才有）／`stale`（`--check` 才有）。`show` 是印在畫面上的路徑（§1.3 的路徑欄）。`agents` 是子代理定義（`.agents/agents/*.md` → `<工作區>/.claude/agents/`，只有 `project` 這個位置；`--target user` 時是空陣列），狀態字和 `items` 一樣；同名、內容不同又沒有標記檔的是 `conflict`，路徑也進 `conflicts`。

### 1.5 `--help` 原文

```
把 .agents/skills/auto-edit-* 的 9 支 Skill 複製到 Claude Code 與 MiniMax Code 讀得到的位置（零依賴，只用 Node 22）

  node setup/install-skills.mjs              裝到兩個位置：<工作區>/.claude/skills/、~/.minimax/skills/
  node setup/install-skills.mjs --target project|user|all
  node setup/install-skills.mjs --dry-run    只印會做什麼，不寫檔
  node setup/install-skills.mjs --check      只比對已安裝的和原始檔是否一致（不一致結束碼 1）
  node setup/install-skills.mjs --json       stdout 只印一個 JSON

只更新它自己裝過的 auto-edit-* 資料夾（有 .auto-edit-install.json 標記檔）；同名但不是它裝的、或是 symlink，一律不動並報 ✖。
改了 .agents/skills/ 之後重跑一次就會更新。
```

### 1.6 結束碼

| 碼 | 意思 |
|---|---|
| 0 | 全部完成（或 `--check` 全部一致；或只有 ⚠ orphan） |
| 1 | 有 ✖：原始 Skill 驗證失敗、有衝突、或 `--check` 有不一致 |
| 2 | 參數錯誤 |
