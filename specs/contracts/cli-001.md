# 契約：001 的指令（cli-001）

- **擁有者**：001 skills-docs。**照它做**：001 自己（setup 文件、`check.sh`／`check.ps1`、`auto-edit-setup` Skill）、007（`dev/check-all.mjs` 可以呼叫 `--check`）、`status.mjs`（呼叫 `checkInstalled()`）。
- **格式**：照 `specs/README.md` 契約表 `contracts/cli.md` 那一列要求的欄位（完整指令、參數、印出的關鍵行原文、退出碼、錯誤訊息格式）。檔名用 `cli-001.md` 是主代理派工時的命名，和 README 寫的 `cli.md` 不同，待主代理統一（見 spec「需要主代理裁決」第 1 條）。
- 001 只有一個指令：`setup/install-skills.mjs`。

## 1. `node setup/install-skills.mjs`

正本是 `.agents/skills/auto-edit-*` 這 9 支 Skill（進 git）。工具偵測這台電腦裝了哪些 Agent，在**工作區的專案層位置建連到正本的連結**；之後改正本不用重跑。

| Agent（`--agent` 的值） | 偵測：家目錄有這個資料夾 | 讀哪裡 | 工具做什麼 |
|---|---|---|---|
| Claude Code（`claude`） | `~/.claude`（有 `CLAUDE_CONFIG_DIR` 就看它） | `<工作區>/.claude/skills/`、子代理 `<工作區>/.claude/agents/` | 建連結 |
| MiniMax Code（`minimax`） | `~/.minimax` | `<工作區>/.minimax/skills/`（它的提示詞寫的專案層位置） | 建連結；清掉舊版的全域複本 `~/.minimax/skills/auto-edit-*` |
| Codex（`codex`） | `~/.codex`（有 `CODEX_HOME` 就看它） | `<工作區>/.agents/skills/` | 不用做事 |
| Cursor（`cursor`） | `~/.cursor` | `<工作區>/.agents/skills/` | 不用做事 |

- 一個都偵測不到：全部都裝（之後才裝的 Agent，`status.mjs` 每次跑 `checkInstalled()` 會提醒重跑）。
- **連結的做法**：Mac／Linux 用 symlink，寫相對路徑（`../../.agents/skills/<名稱>`，整個工作區搬家也不會斷）。Windows 的資料夾用 junction（一般帳號就能建，不用系統管理員或開發人員模式；只能寫絕對路徑）。子代理是單一檔案，用檔案 symlink；Windows 沒開開發人員模式建不了，就複製。
- **建不了連結才複製**：每個目標資料夾先建一個測試連結 `.auto-edit-link-test-<pid>` 再拿掉；建不了（exFAT 隨身碟、網路磁碟）就照舊版的做法複製，資料夾裡放標記檔 `.auto-edit-install.json`，改了正本要重跑。
- **專案層優先**：舊版（複製到全域位置的版本）裝在 `~/.minimax/skills/auto-edit-*`、有標記檔、`source` 是 `.agents/skills/…` 的資料夾一律移除，不然會和專案層的重複、甚至蓋過去。刪不掉就印指令給使用者執行。
- 工作區根目錄＝`setup/` 的上一層（用 `import.meta.url` 算，不看目前資料夾），所以在哪裡執行都一樣。使用者家目錄用 `os.homedir()`；路徑一律 `path.join`，不寫 `~`（憲法 II）。
- 只用 Node 22 內建模組（`node:fs`、`node:path`、`node:os`、`node:url`、`node:crypto`），零依賴；不呼叫 shell、不呼叫 git。
- `.claude/`、`.minimax/` 都在 `.gitignore` 裡。

### 1.1 參數

| 參數 | 值 | 預設 | 說明 |
|---|---|---|---|
| `--agent` | `claude`／`minimax`／`codex`／`cursor` 用逗號接，或 `all` | 偵測 | 不偵測，只裝指定的 |
| `--dry-run` | — | 關 | 只印會做什麼，不寫、不刪任何檔 |
| `--check` | — | 關 | 只比對裝好的和正本是否一致，不寫檔；不一致結束碼 1 |
| `--json` | — | 關 | stdout 只印一個 JSON（格式 §1.4） |
| `--help` | — | — | 印用法（§1.5 原文），結束碼 0 |

- 不認得的參數：印 `✖ 不認得的參數：<參數> → 跑 node setup/install-skills.mjs --help 看可用的參數`，結束碼 2。`--agent` 的值不認得：`<參數>` 是 `--agent <值>（可以用 claude、minimax、codex、cursor 或 all）`。
- **測試用**：環境變數 `AUTO_EDIT_INSTALL_COPY=1` 當作建不了連結，走複製那條路；測試把 `HOME`／`USERPROFILE` 指到暫存的假家目錄控制偵測結果。文件不教使用者。

### 1.2 行為

1. 讀 `.agents/skills/` 底下名稱是 `auto-edit-` 開頭的資料夾，照名稱排序。每支都先驗證，任一支不過就整個不裝（結束碼 1）：
   - 有 `SKILL.md`；frontmatter 只有 `name`、`description`、`version` 三種欄位，`name` 等於資料夾名稱，`description` 是單行。
   - 驗證失敗印：`✖ .agents/skills/<名稱>/SKILL.md：<原因> → <改法>`（例：`✖ .agents/skills/auto-edit-rough/SKILL.md：frontmatter 有不允許的欄位 allowed-tools → 只能用 name／description／version`）。
   - 子代理定義 `.agents/agents/*.md` 也驗證（`name` 等於檔名、有 `description`）。
2. 對每個要建連結的 Agent 的每一支（目標 `<工作區>/<Agent 資料夾>/skills/<名稱>`）：
   | 目標的狀態 | 做法 | 印的狀態字 |
   |---|---|---|
   | 不存在 | 建連結（建不了才複製＋標記檔） | `新裝（連結）`／`新裝（複製：這個磁碟建不了連結）` |
   | 連結，指到這個工作區的正本 | 不動 | `沒變（連結）` |
   | 連結，指到某個 `.agents/skills/<同名>`（工作區搬過家、別份工作區） | 拿掉連結（不碰它指到的資料夾），重建 | `重新連結（原本指到 <路徑>）` |
   | 連結，指到別處 | **不動**，記一個 ✖ | `✖ 衝突` |
   | 資料夾，有標記檔（舊版複製的） | 建得了連結：刪掉換成連結；建不了：內容不同就整個換新的 | `改成連結（原本是複製）`／`沒變（複製）`／`更新（複製，N 個檔不同）` |
   | 資料夾，沒有標記檔（使用者自己的同名 Skill） | **不動**，記一個 ✖ | `✖ 衝突` |
3. 子代理定義（只有選到 Claude Code 才裝）：`.claude/agents/<名稱>.md` 連到 `.agents/agents/<名稱>.md`。狀態和第 2 點一樣；複製的檔記在 `.claude/agents/.auto-edit-install.json` 的 `files`（`.claude/agents/` 裡可能有使用者自己的子代理）。已經有同名檔、內容和正本一樣：當成它的（換成連結）；內容不一樣又沒記在標記檔：✖ 衝突。全部都是連結時不留標記檔。
4. 只碰 `auto-edit-` 開頭的；`.claude/skills/` 裡的 `speckit-*`、`~/.minimax/skills/` 裡的 `hyperframes`、`auto-editor` 等其他 Skill 一律不碰。
5. 正本已經沒有的 `auto-edit-*`（Skill 改名或刪掉時）：它建的連結直接拿掉（`拿掉連結（正本已經沒有了）`，不會刪到檔案）；它複製的資料夾只印 `⚠ <路徑> 已經沒有正本 → 不用的話自己刪掉這個資料夾`，不自動刪（AGENTS.md 規則 1：刪 `work/` 以外的檔要先問）。
6. 舊版的全域複本（見 §1 開頭）：選到的 Agent 有 `legacy` 位置才清（目前只有 MiniMax Code）。印 `移除（舊版的全域複本；專案層優先）`；刪不掉印 `✖ 刪不掉（<錯誤碼>）→ 自己執行：<指令>`（Mac `rm -rf "<路徑>"`、Windows `Remove-Item -Recurse -Force "<路徑>"`），結束碼 1。
7. 標記檔 `.auto-edit-install.json` 內容（只有複製的才有）：`{ "source": ".agents/skills/<名稱>", "version": "<SKILL.md 的 version>", "files": { "<相對路徑>": "<sha256>" } }`。比對「一不一樣」就比這張表和正本重算的 sha256。
8. 目標的上層資料夾（`.claude/skills/`、`.minimax/skills/`）不存在時自動建立。

### 1.3 印出的關鍵行（原文）

```
安裝 auto-edit Skill：9 支（正本 .agents/skills/）
Agent（偵測到的）：Claude Code、MiniMax Code（連結）；Codex、Cursor（直接讀 .agents/skills/，不用裝）
  claude   .claude/skills/auto-edit-longform          新裝（連結）
  claude   .claude/skills/auto-edit-rough             改成連結（原本是複製）
  minimax  .minimax/skills/auto-edit-longform         沒變（連結）
  claude   .claude/agents/auto-edit-worker.md         新裝（連結）
  全域     ~/.minimax/skills/auto-edit-longform       移除（舊版的全域複本；專案層優先）
  …
✓ 完成：9 支 × 2 個 Agent（Claude Code、MiniMax Code），新裝 9、改成連結 9、更新 0、沒變 0；子代理 1 個（.claude/agents/）：新裝 1、改成連結 0、更新 0、沒變 0；移除舊的全域複本 9 個
```

- 第二行：`Agent（偵測到的）：…`／`Agent（--agent 指定）：…`／`Agent：一個都沒偵測到，全部都裝：…`。
- 路徑欄：專案層寫相對工作區的路徑（`/` 分隔）；全域在 Mac 寫 `~/.minimax/skills/…`、在 Windows 寫 `%USERPROFILE%\.minimax\skills\…`（只是顯示，程式內部用 `os.homedir()`）。
- 只選到 Codex、Cursor：最後一行 `✓ Codex、Cursor 直接讀 .agents/skills/，不用裝`。
- 有複製的：最後一行前面多一行 `⚠ 有 N 個是複製的（這個磁碟或帳號建不了連結）→ 改了 .agents/ 的正本之後要重跑 node setup/install-skills.mjs`。
- `--dry-run`：每列狀態字前面加 `（預演）`，最後一行改成 `預演：9 支 × 2 個 Agent（…），會新裝 9、改成連結 0、更新 0、沒變 0…；沒有寫任何檔`（有舊的全域複本時中間多 `；會移除舊的全域複本 N 個`）。
- 有衝突：衝突那一列後面接 `→ 這個資料夾不是 install-skills 裝的；改名或移走它，再跑一次 node setup/install-skills.mjs`，最後一行改成 `✖ 有 N 個衝突，其他的已經裝好`（全域複本刪不掉時是 `✖ N 個舊的全域複本刪不掉，其他的已經裝好`，兩種都有就用 `、` 接）。
- `--check` 一致：`✓ 9 支 × 2 個 Agent（…）都和 .agents/skills/ 一致；子代理 1 個（.claude/agents/）也和 .agents/agents/ 一致`。不一致：每個不一致的列印 `⚠ <路徑> 還沒裝`／`⚠ <路徑> 的連結指到別的地方（<路徑>）`／`⚠ <路徑> 和正本不同（N 個檔）`／`⚠ <路徑> 是舊版裝的全域複本，會和專案層的重複 → 跑 node setup/install-skills.mjs 移除`，最後一行 `→ 跑 node setup/install-skills.mjs 更新`。

### 1.4 `--json`

```json
{ "ok": true, "dryRun": false, "check": false, "skills": 9,
  "detected": ["claude", "minimax", "codex", "cursor"], "linked": ["claude", "minimax"], "native": ["codex", "cursor"],
  "items": [ { "skill": "auto-edit-rough", "target": "claude", "path": "/abs/.claude/skills/auto-edit-rough", "show": ".claude/skills/auto-edit-rough", "status": "relinked", "mode": "link" } ],
  "agents": [ { "agent": "auto-edit-worker", "target": "claude", "path": "/abs/.claude/agents/auto-edit-worker.md", "show": ".claude/agents/auto-edit-worker.md", "status": "unchanged", "mode": "link" } ],
  "legacy": [ { "skill": "auto-edit-rough", "target": "minimax", "path": "/Users/x/.minimax/skills/auto-edit-rough", "show": "~/.minimax/skills/auto-edit-rough", "status": "removed" } ],
  "conflicts": [], "orphans": [], "copies": [] }
```

- `items`／`agents` 的 `status` 只有 `installed`／`relinked`／`updated`／`unchanged`／`conflict`／`missing`（`--check` 才有）／`stale`（`--check` 才有）；`mode` 是 `link` 或 `copy`；`changed` 是不同的檔數（複製的才有）。`show` 是印在畫面上的路徑。
- `legacy` 的 `status`：`removed`／`failed`（多一個 `fix`：要使用者執行的指令）／`found`（`--check`、`--dry-run`）。
- `copies` 列出複製（不是連結）的絕對路徑。

### 1.5 `--help` 原文

```
把 .agents/skills/auto-edit-* 的 9 支 Skill 連結到這台電腦裝了的 Agent 讀得到的位置（零依賴，只用 Node 22）

  node setup/install-skills.mjs                              偵測裝了哪些 Agent，在工作區建連結
  node setup/install-skills.mjs --agent claude,minimax|all   不偵測，指定 Agent（claude、minimax、codex、cursor）
  node setup/install-skills.mjs --dry-run                    只印會做什麼，不寫檔
  node setup/install-skills.mjs --check                      只比對裝好的和正本是否一致（不一致結束碼 1）
  node setup/install-skills.mjs --json                       stdout 只印一個 JSON

Claude Code → .claude/skills/、MiniMax Code → .minimax/skills/：連到 .agents/skills/ 的正本，改了正本不用重跑。
Codex、Cursor 直接讀 .agents/skills/，不用裝。子代理定義 .agents/agents/*.md 一起連到 .claude/agents/（Claude Code）。

舊版裝在 ~/.minimax/skills/ 的全域複本會移除（專案層優先）。同名但不是它裝的，一律不動並報 ✖。
```

### 1.6 結束碼

| 碼 | 意思 |
|---|---|
| 0 | 全部完成（或 `--check` 全部一致；或只有 ⚠） |
| 1 | 有 ✖：原始 Skill 驗證失敗、有衝突、舊的全域複本刪不掉、或 `--check` 有不一致 |
| 2 | 參數錯誤 |

### 1.7 `checkInstalled()`

`import { checkInstalled } from 'setup/install-skills.mjs'` → `{ ok, none, stale }`：就是 `--check --json` 換成人看得懂的句子，不印、不安裝。`none` 是「一支都還沒裝」（`check.sh` 用來分 `missing`／`too_old`）；`stale` 同一個位置、同一種狀態併成一行（例：`.claude/skills 還沒裝 auto-edit-rough、auto-edit-style`、`~/.minimax/skills 還有舊版的全域複本 auto-edit-rough（專案層優先）→ 跑 node setup/install-skills.mjs 移除`）。參數 `{ agent }` 只有測試會用。

## 2. 測試（`dev/tests/install-skills.test.mjs`）

每個案例在系統暫存資料夾做迷你工作區（`setup/install-skills.mjs`＋`.agents/`）和假的家目錄，用 `HOME`／`USERPROFILE` 指過去。

| 案例 | 期待 |
|---|---|
| 家目錄有 `.claude`、`.minimax`，第一次裝 | 18 個連結都指到正本（Mac／Linux 是相對路徑）；不寫家目錄；結束碼 0 |
| 再跑一次；改正本 | 全部 `沒變（連結）`；連結讀到新內容，`--check` 照樣一致 |
| 偵測 | 只有 `.claude` → 只建 `.claude/skills`；只有 `.codex`、`.cursor` → 什麼都不建；一個都沒有 → 全部建 |
| `--agent minimax`；`--agent vim` | 只建 `.minimax/skills`；結束碼 2 |
| 舊版複本 | 專案層有標記檔的 → `改成連結（原本是複製）`；`~/.minimax/skills/auto-edit-*` 有標記檔的 → 移除、`--check` 先報 ⚠；沒標記檔的、別的 Skill 不動 |
| 衝突 | 沒標記檔的同名資料夾、指到別處的連結 → ✖ 衝突、結束碼 1、都不動，其他照裝 |
| 連結指到別份工作區的 `.agents/skills/<同名>` | `--check` 報 ⚠；安裝時重新連結，原本指到的不動 |
| 正本已經沒有的 `auto-edit-*` 連結 | 拿掉 |
| `AUTO_EDIT_INSTALL_COPY=1` | 退回複製（有標記檔）、印 ⚠ 要重跑；改正本後 `--check` ⚠、安裝只更新那一支；拿掉變數再跑 → 改成連結 |
| 原始檔 frontmatter 加 `allowed-tools` | 驗證失敗、一個檔都沒寫、結束碼 1 |
| `--dry-run` | 沒有任何檔被建立或刪除 |
| `--check` 在裝完後拿掉一個連結 | `⚠ … 還沒裝`、結束碼 1、不寫檔 |
| `--foo` | 結束碼 2 |
| 子代理 | 和 Skill 一起連；沒選到 Claude Code 不裝；同名內容一樣 → 接手；內容不一樣 → ✖ 衝突、不動；別的子代理不碰；name 和檔名不同 → 驗證失敗 |
| `checkInstalled()` | 不印、不安裝；`none`、併行、舊版全域複本那一行、衝突那一行 |
| 被 `node -e` 匯入 | 不當成直接執行 |
