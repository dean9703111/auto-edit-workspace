# cli-014：`versions.mjs`（段落版本與改版）

擁有者：014 segment-versions。共通規則照 `cli.md`（工作區根目錄執行；`✖ <原因> → <改法>` 結束碼 1；`⚠ <原因> → <改法>` 不影響結束碼）。

## 1. 資料夾

```
work/版本/
├─ .state.json              { live: {段: N}, prev: {段: N}, storyboardMtime }（工具自己用）
└─ <段>/
   ├─ v<N>/
   │  ├─ 段落.json          plan.json 的那一段（原樣）
   │  ├─ x-<名稱>.html      情境動畫段才有
   │  ├─ illus-local/*.svg   x 檔用到的才有
   │  ├─ 分鏡.md            「# <段> v<N>（存檔｜改版）」＋（改版）「## 這版要改什麼」＋「## 分鏡」（storyboard.md 那一節）
   │  ├─ 預覽.mp4           build --test <段起點>,<段長＋0.5> → render --quality draft
   │  ├─ 預覽.jpg           預覽每 0.5 秒一格（最多 24 格；橫式 4 欄 480 寬、直式 6 欄 240 寬）
   │  └─ .meta.json         { id, v, kind: 存檔|改版, state: 提案|已確認|完成|放棄, time, note, hash, srt, files }
   └─ 比較-v<舊>-v<新>.mp4   左舊右新，各縮成畫布的一半，上方 64 px 標版本號，聲音用新版，長度取長的（短的停在最後一格）
```

- 「做完的版本」＝有 `段落.json`。只有 `分鏡.md` 的是提案。
- hash＝段落 JSON＋x 檔＋svg 的內容（分鏡.md 不算）；「目前」＝hash 和現在的 plan.json、x 檔一致的那一版。

## 2. 指令

| 指令 | 做什麼 | 關鍵輸出（原文） |
|---|---|---|
| `save --seg s12[,s08]` | 和某版一樣 → 不另存（缺預覽才補）；有「已確認」的提案 → 存進那一版（保留「這版要改什麼」）；其他 → 新的一版。上一個使用中的版本有預覽就出比較影片 | `s12：存成 v2（…/）`、`s12：沒變，目前就是 v1（…/）`、`  預覽：…/預覽.mp4（6.033 秒）、預覽.jpg`、`  比較：…/比較-v1-v2.mp4（左 v1、右 v2）` |
| `new --seg s12[,s08] [--note "…"]` | 先 save；開 v<N+1>/分鏡.md（提案）；已有提案就沿用 | `s12：提案開好了 …/分鏡.md（現在的樣子是 v1）`、`→ 下一步：…`、最後兩行 `⏸ 停點 ③ 分鏡表（s12 v2）｜請看 …/分鏡.md`、`請回：「可以」或要改的拍` |
| `accept --seg s12[,s08]` | 提案「## 分鏡」整節取代 storyboard.md 的「### s12」那一節（沒有就插在「## 需要我決定的事」前）；記下 storyboard.md 的修改時間 | `s12：v2 的分鏡寫回 work/storyboard.md（### s12 那一節）`、`→ 下一步：…`、最後一行 `node shared/template/tools/versions.mjs save --project projects/<專案> --seg s12` |
| `use --seg s12 --ver v1` | 沒做完的提案標「放棄」→ save 現在的樣子 → plan.json 那段、x 檔、svg、storyboard.md 那一節換成 v1 | `s12：退回 v1：plan.json 這段、x-….html、storyboard.md 那一節都換成 v1 的`、`→ 下一步：…`、最後一行 `node shared/template/tools/build.mjs --project projects/<專案>` |
| `list [--seg s12] [--json]` | 每段每版一列；`← 目前`；比較影片 | `  v1  2026-11-01 23:25  存檔  預覽.mp4  ← 目前` |

## 3. 錯誤與提醒（原文開頭）

| 訊息 | 什麼時候 |
|---|---|
| `✖ plan.json 沒有「s99」這一段 → …` | `--seg` 寫錯 |
| `✖ s12 的 v2 分鏡還在等使用者確認 → …accept…；不改了就跑 …use … --ver v1（提案標成放棄）` | 提案還沒 accept 就 save |
| `✖ s12 還和 v1 一模一樣：v2 的分鏡還沒做 → …` | accept 了但 x 檔、plan 都沒改就 save |
| `✖ …/分鏡.md 的「這版要改什麼」還是範本那一行 → …` | accept 前沒寫「這版要改什麼」 |
| `✖ …/分鏡.md 的「## 分鏡」底下找不到「### s12｜…」那一節 → …` | 提案把標題刪掉了 |
| `✖ s12 沒有做完的 v3（有：v1、v2）→ …` | use 指到提案或不存在的版本 |
| `⚠ s12 的預覽沒做：<原因> → … 修好後再跑一次同一行（檔案已經存好，只會補預覽）` | build ✖、render 失敗（版本檔案照樣存好） |
| `⚠ 字幕在 v1 之後改過，這段的句號（#N）可能對不上 → …` | use 的那一版存檔時 rough.srt 和現在不同 |
