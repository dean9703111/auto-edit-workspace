### 4.5 `media.mjs srt-align`（F8：字幕斷句照完整語句、樣式照剪映）

```
node shared/template/tools/media.mjs srt-align --project projects/<專案> [--dry-run] [--remap-plan] [--max 18]
```

**單位**：有 `講稿.md`＝講稿每一行（`#` 標題、`>` 引言、```` 區塊、`<!-- -->`、含 \` 的說明行、整行括號、分隔線、空行都不算）；沒講稿＝`work/rough.srt` 每則依「，。！？；」切成子句（時間先照字寬在那一則裡比例分）。

**時間**：`work/transcript.json`（詞級）每個詞的時間平均分給它的字；講稿全文（`normText`）對逐字稿全文做**全域序列對齊**（Needleman–Wunsch，字元層級：相同 0、替換 1、插入／刪除 1）。每一行的起迄＝行裡對到的第一個字的起點、最後一個字的終點；相同字比例 < 0.34 或沒有字對到＝對不上 → 用前後對得上的行之間照字寬內插（⚠）。沒有 transcript.json 時用 `rough.srt` 的整則當「詞」（按字數比例，⚠，之後跑 snap-srt）。

**斷句**（`ALIGN` 常數）：

| 規則 | 值 |
|---|---|
| 一則最多 | 18 字，直式 10 字（`canvas.mjs` 的 `caption.maxChars`；直式時第一行印 `版式：直式 → 每則最多 10 字（來源：…）`；`visibleLen`：全形 1、半形 0.5；明寫 `--max` 時以參數為準） |
| 超過就拆 | 先斷在「、，。！？；：」（兩邊都 ≤ 18、最平均）；都沒有才斷在 30–70% 之間兩字時間差最大處（⚠ 沒有標點） |
| 合併 | 上一行不是「。！？」結尾、下一行不是連接詞開頭（而／但／所以／因為／另外／如果／或者／然後／接著／最後／為了／現在／不過／可是／因此／於是／首先／其次／再來／那麼／當／雖然／只是／其實），合併後 ≤ 18 字，而且 **同一口氣**（兩行之間停頓 ≤ 0.12 秒）或 **有一邊 ≤ 4 字**（停頓 < 1 秒）；內插的行、拆出來的段不併 |
| 空檔 | 相鄰兩則空檔 < 1 秒 → 前一則延到下一則開頭（剪映的字幕首尾相接） |
| 顯示文字 | 去「，。；：」（半形 `, ; :` 不在數字中間時也去），保留「、！？」；拿掉標點後中英文之間補半形空格；行尾「、」去掉 |

**輸出**（`--dry-run` 與寫回都印）：

```
字幕對講稿：講稿.md 84 行，時間用 work/transcript.json（686 個詞）全域對齊
  則   起–迄                 長     字   字幕
  1    0:00.16–0:02.08         1.92   9   嗨！大家好我是鼎淵
  5    0:08.04–0:11.48         3.44  18   並且跟我一樣使用手機在固定的機位錄影   （併 2 行；講稿第 5、6 行）
  …
共 70 則（併 14 次、拆出 0 則）；平均 11.4 字、最長 18 字；每則中位 2.16 秒；相鄰空檔中位 0.00 秒
```

沒講稿時第一行是 `字幕對子句：work/rough.srt 45 則 → 61 個子句，時間用 …`。表的最後一欄：`併 N 行`、`拆`／`⚠ 拆（沒有標點）`、`⚠ 內插`（有講稿時加 `；講稿第 a、b 行`）。

**⚠**（原文）：

| 情況 | 原文 |
|---|---|
| 對不上 | `⚠ N 行講稿在逐字稿裡對不上，時間用前後句內插：第 7 行「…」、… → 播 rough.mp4 那一段聽：沒講（剪掉了）就從字幕刪掉，有講就到剪輯台調起迄`（沒講稿時「N 個子句」「#n「…」」） |
| 沒標點的長行 | `⚠ N 則超過 18 字又沒有「、，」可以斷，斷在中段停頓最長的地方：#a、#b → 到剪輯台看斷得對不對` |
| 太短 | `⚠ N 則不到 0.6 秒：#a「…」0.45s、… → 到剪輯台和前後句合併` |
| 沒有詞級時間 | `⚠ 沒有 work/transcript.json：時間是整則按字數比例估的 → 寫回後要跑 node shared/template/tools/media.mjs snap-srt --project projects/<專案>（有 transcript.json 就不用）` |
| remap 找不到詞 | `⚠ <段 id 或 compositions/x-….html>：#N@詞 的「詞」在新字幕找不到 → 改成時間 #M+秒（到剪輯台或 plan.json 換成新字幕裡的詞）` |

**✖**（結束碼 1，不寫任何檔）：沒有 transcript.json 也沒有 rough.srt（附轉錄指令）；transcript.json 不是 JSON／不是 `[{ text, start, end }]`／比 rough.mp4 舊 1 秒以上（附轉錄指令）；講稿讀不到講解行；字數太大（講稿字數 × 逐字稿字數 > 4 億格）；**plan.json 已經用到 `#N` 又沒加 `--remap-plan`**：`work/hyperframes/plan.json 已經用到句號（#N），重新斷句後句號會全部位移 → 加 --remap-plan 再跑一次（…）`。

**寫回**：`work/rough.srt` 先備份成 `work/rough.srt.align-<時間戳>`（`status.mjs` 靠它判斷 srt-align 跑過）；SRT 存的就是顯示文字（剪輯台、`#N@詞` 都用它；`#N@詞` 找詞用 `normText`，不受標點影響）。最後一行：有講稿 `→ 字幕已經是講稿的字：只剩講稿本身的錯字要改（規則 4）；有 transcript.json，不用跑 snap-srt，再跑 media.mjs cutpoints`（沒有 transcript.json 時「接著跑 snap-srt」）。

**`--remap-plan`**（`remapPlanByTime`、`remapCustomRefs`）：plan.json（含 `outro.from`）與 plan.json 裡 custom 段的 `compositions/x-*.html`（只換 `<script>` 裡、不在註解與 HTML 註解裡的 `P.at('#N…')` 字面值）照**時間**換到新句號：`#N@詞` → 新字幕裡有這個詞、離舊句最近的那一句；`#Ne` → 結尾 ±0.15 秒有新句結尾就 `#Me`；其他 → 同一個秒數（±0.3 秒內有新句開頭就綁那一句，差 ≤ 0.1 秒寫 `#M`），否則落在的那一句＋差。段落有 `anchor`、`from` 是句首 `#N` 時，`from` 改綁含 anchor 的新句開頭（±3 秒內），這段的其他時間一起平移，別段寫同一個 `"#N"` 的（例前一段的 `to`）也一起換。plan.json 與每個改到的 x-*.html 先備份 `.align-<時間戳>`。`storyboard.md` 的句號會過期（以 plan.json 為準）。
