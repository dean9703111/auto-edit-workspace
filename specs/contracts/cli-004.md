#### 2.2.1 完成態（第 2 輪，B-01）

截圖前用 003 `audit` 的瀏覽器工作階段（`lib/audit-browser.mjs` 的 `openSession`，和 snapshot 同一個 HyperFrames runtime 與 seek）讀每段的動畫時間軸：`#el-<id>` 那個子合成 `window.__timelines` 的每個 tween → `[起, 迄, 種類]`（完成影片秒；種類：opacity 從 < 0.2 到 ≥ 0.2＝進場、反過來＝退場、其他＝變化）。相隔 ≤ 0.05 s 的併成一塊「在動」，比整段還長的（循環動畫）不算。

| 步 | 規則 | 例 |
|---|---|---|
| 1 | 目標＝`out.end − 0.6` | |
| 2 | 最後一塊動畫裡沒有進場、前面還有別塊 → 它是退場：目標改成 `min(目標, 這塊開始 − 0.1)`，「為什麼」印 `完成態（退場前 0.1 秒）` | 03 側邊欄：內容 D − 1.1 開始淡出、面板 D − 0.7 推回 → D − 1.2；fx 29 數字計數：D − 0.8 開始滾回 0 → D − 0.9；fx 04 衝刺縮放：2.4 s 起飛走 → 2.3 s |
| 3 | 目標那一刻還在某一塊裡 → 改成那塊開始 − 0.1，重複；印 `完成態（動畫停住的最後一刻）` | |
| 4 | 退到段頭（< `out.start + 0.1`）＝整段都在動 → 回到步驟 2 的目標，印 `段尾前 0.6 秒（整段都在動，沒有停住的畫面）` | fx 34 故障切片 |

- fx：`fx/catalog.json` 的 `done` 是 `"label"` 的卡（27 打字機，tween 不在時間軸上）不做上面的分析，截 host 的 `data-start` ＋ 時間軸的 `labels.done`，「為什麼」印 `完成態（動畫的 done 標記）`；時間軸沒有這個標記就照段尾前 0.6 秒，印 `⚠ <id> 的 fx 時間軸沒有 'done' 標記：完成態照段尾前 0.6 秒截 → 截到動畫中途就回報 003`。`done` 是 `"timeline"` 的照上表。
- 一般 0.4 s 淡出（`P.out(…, D − P.OUT)`）不影響：D − 0.6 早於它。
- 不早於這段**最後一個進場完成**（opacity 由透明到不透明、或遮罩揭開 `clipPath inset(…100%…) → inset(0 0 0 0)`；例 07 的 key 綁 `#N@詞` 在段尾附近才揭開）：晚於上表結果時改截它，印 `完成態（最後一個進場完成）`。
- 被下一段**不透明**的段（`opaque`：子母畫面、全幕）在這段裡開始就蓋住：每張都不晚於 `蓋住 − 0.1`，印 `被 <id> 蓋住前 0.1 秒`。那時最後一個進場（條列是那一組）還沒完成 → 印「為什麼」`被 <id> 蓋住前 0.1 秒（「<那個元素的字>」還沒出現）`，並 ⚠：`<id> 的「<字>」在 m:ss.ss 才完整出現，但 <蓋住的段> 在 m:ss.ss 就蓋住了，觀眾看不到 → <id> 的那個拍點綁早一點的詞（#N@詞），或 <蓋住的段> 的 from 延後到 <完成 + 0.6 s> 之後`。
- 讀不到時間軸（找不到 runtime、頁面沒就緒）→ 照舊（`out.end − 0.6`、條列 + 0.9 s），開頭印 `⚠ 讀不到動畫時間軸（<原因>）：完成態用段尾前 0.6 秒、條列用進場後 0.9 秒估 → 截圖停在動畫中途就重跑一次`。
- 速度：範例專案 28 段讀時間軸 1.7 s（M1 Max）。

## 5. `brand.mjs bg`：HTML 背景圖截圖（G07 HTML 路線）

```bash
node shared/template/tools/brand.mjs bg --html <檔.html> --kind fs|side|ch [--out <資料夾>]
```

| 參數 | 值 | 預設 | 說明 |
|---|---|---|---|
| `--html` | `.html` 檔 | 必填 | 畫背景的網頁；顏色用 `var(--brand)`、字型用 `var(--font-cjk)`（工具會自動接上 `kit/brand.css`、`kit/fonts.css`） |
| `--kind` | `fs`／`side`／`ch` | 必填 | 尺寸與留空區見 §5.2 |
| `--out` | 資料夾 | HTML 所在的資料夾 | **不能在 `shared/template/` 裡面** |
| `--chrome`、`--kit` | 路徑 | | 測試用（`--kit` 沿用現行） |

### 5.1 做什麼

1. 在 `--out` 寫 `.bg-<kind>.render.html`：原 HTML 的 `<head>` 後面插入 `<base href="<HTML 所在資料夾的 file URL>/">`、`kit/fonts.css`、`kit/brand.css` 兩個 `<link>`（file URL）、`<style>html,body{margin:0;width:<W>px;height:<H>px;overflow:hidden}</style>`；原檔不改。
2. Chrome：`<chrome> --headless --hide-scrollbars --force-device-scale-factor=1 --window-size=<W>,<H> --virtual-time-budget=5000 --user-data-dir=<暫存> --screenshot=<out>/raw-<kind>.png <render.html 的 file URL>`（逾時 60 s）。
3. `ffmpeg -i raw-<kind>.png -q:v 2 bg-<kind>.jpg`，`ffprobe` 驗尺寸。
4. `zones-<kind>.jpg`：同一張疊上留空區框（ffmpeg `drawbox`，線寬 4，不需要 freetype）。
5. 量留空區乾不乾淨：每個框內算亮度（0.299R＋0.587G＋0.114B），和框內中位數差 > 40 的像素占比 > 0.5 % → ⚠（建議初值：4 px 寬的線橫過 1260 px 寬的主卡區約占 0.56 %）。
6. `--out` 裡三張 `bg-fs.jpg`、`bg-side.jpg`、`bg-ch.jpg` 都在時，產生 `preview.jpg`：上排三張原圖（640×360、320×360、640×360）、下排三張疊框版，共 1600×720。
7. HTML 裡有 `http://`、`https://` → ⚠。
8. 刪掉 `.bg-<kind>.render.html`；`raw-<kind>.png` 保留（給作者比對）。

**不會**寫 `shared/template/bg-*.jpg`（AGENTS.md「換風格」：使用者同意後才複製）。
