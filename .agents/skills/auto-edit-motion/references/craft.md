# 畫得好、動得好（設計師的心法，一頁讀完）

`design.md` 的補充：寫鏡位腳本前讀「畫法」，做動畫前讀「動法」。整理自 `hyperframes` skill 的 `types/explainer.md`、`types/data.md`、`motion.md`，只留這個工作區用得到的；不用另外載入那個 skill。

## 畫法：一段講清楚一件事

先判斷這句話是哪一種形狀，再挑畫面，同一集相似的句子才不會都長一樣：

| 形狀 | 畫面 |
|---|---|
| 一個數字落下 | 數字是畫面上最大的東西，先講它為什麼重要再讓它出現；變成看得見的量（一排格子、一群人、一條長度） |
| 推翻一個說法 | 錯的那句劃掉，對的蓋上去 |
| 前後對比 | 同一個東西的兩個狀態，左右或前後切換 |
| 很多收斂成幾個 | 散開的點聚成幾組 |
| 依序的步驟 | 一張圖一步長一塊，講到哪一步才出現哪一塊 |
| 從很多裡挑一個 | 一排裡一個亮起、其他壓暗 |
| 東西怎麼運作 | 畫出那個東西本身，讓它動給人看（機器、流程、路線），標籤貼在零件旁邊 |

- **一張圖慢慢長大**：從最簡單的樣子開始，每一拍加一塊，講到才出現；不要一次把整張圖丟上畫面。
- **同一個東西一路變形**：上一拍的東西變成下一拍的東西（條變成軸、點變成一群人），觀眾不會跟丟。
- **一個真的例子走完全程**：一句話、一個數字、一張截圖，從第一步走到結果。
- 標籤貼在它說的那個東西上，跟著它一起出現；不用圖例，不做條列投影片。
- **一看就是套版的**：條列重點的投影片、圓圈裡放圖示、三張卡排一列、整張圖一次出現、畫面上的字和講的話一字不差。

## 動法

- **進場慢落地、退場乾淨**：進場用長尾的 ease-out（`expo.out`、`power4.out`），0.4–0.6 秒；退場用 `power3.in`，比進場短 40–50%，一個動作走完，不要滑一下、停、再走。
- **緩動照角色挑**：全部用同一個 `power2.out` 0.5 秒，看起來就像機器做的。鏡頭移動、整片換色用 `power2.inOut`。
- **錯拍**：下一個東西在前一個做到 30–50% 時開始；一組東西用 `stagger: 0.07` 左右錯開。全部同時出現很廉價，完全排隊很呆。
- **彈性**：位置、大小可以微彈（`back.out(1.4)`），透明度和顏色不彈。
- **落地就靜止**：標題、卡片落定之後完全不動，動作交給下一個元素；不做呼吸、漂浮、慢慢放大這種循環。
- **停留**：要讀的字停 0.5 秒＋每個字 0.3 秒；最後一個畫面至少停 2 秒。
- **數字**：用 `font-variant-numeric: tabular-nums`，滾動 1.2–1.6 秒然後停住；不要畫面上每個數字同時在跑。
- **圖表**：照閱讀順序長出來：框和軸 → 參考線 → 資料畫進來 → 在重點那一筆上加一個註解；只亮一條，其他灰掉。
