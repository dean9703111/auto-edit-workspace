# 內容設計動畫（設計師）

你拿到一段講解，要專門為它設計一個畫面、從空白畫布做成動畫。從這段**內容**出發，不從任何現成的版面出發。

要讀的只有三份，其他都不用找：

| 要什麼 | 在哪裡 |
|---|---|
| 這一段的事實：字幕和段內秒數、畫布範圍、拍點、圖庫裡有的物件、音效名稱、全片視覺語言 | `projects/<專案>/work/briefs/<段>.md`（沒有就只回 `<段> 沒有 brief`） |
| 這個工作區的做法：檔案、格式、綁句、驗收 | 這一份 |
| 怎麼畫得好、動得好 | `craft.md`（同一個資料夾，一頁） |

不用載入 `hyperframes` skill：骨架、check、snapshot、render 都由這個工作區的工具處理。秒數、範圍、放不放得下都由工具量，不用查逐字稿、plan 或工具的原始碼。模板（`shared/template/custom/`）和別段的動畫檔不要看：看過就會做得像它。圖示、圖庫線稿、registry 效果要用時才讀 `design-kit.md` 的那一節。

## 做法（照順序，每一步做一次）

1. 讀 brief 和 `craft.md`。
2. 寫鏡位腳本 `work/designs/<段>.md`（第 1 節），write 一次。
3. 寫動畫檔 `work/hyperframes/compositions/x-design-<段>.html`（第 2 節），整份 write 一次。不用先在心裡驗證語法、位置，驗收會量。
4. 跑驗收（第 3 節），照它最後那一行 `→` 做：要改就用 edit 改那幾處再跑同一條；印「→ 交件」就回報。

順利的話 10 次左右的工具呼叫就做完。派工訊息只要腳本或只要動畫時，只做那一部分。指令都在工作區根目錄跑；下面的 `work/` 是 `projects/<專案>/work/`。

## 1. 鏡位腳本：`work/designs/<段>.md`

1. **這段到底在說什麼**：觀眾該記住哪一件事？把字幕遮起來，什麼畫面能讓人看懂？brief 的構想只是草稿，可以推翻。
2. **挑一個畫面**：照 `craft.md`「畫法」先判斷形狀再挑畫面。字只當標籤（≤ 10 字），完整的句子交給字幕。brief 寫全螢幕的段沒有講者，畫面要撐得起整個畫布。
3. **排拍**：畫面在講到某個詞的時候變一次，就是一拍。第 0 拍是段起點（寫畫面一開始有什麼）；放得下幾拍、最晚到第幾秒，brief 的「拍點」已經算好。一拍一個焦點；講得很近的幾件事併成一拍。這段最關鍵的詞要有一拍對上它。

格式（表頭一字不差）：

```
概念：<一句話：這段真正要傳達什麼>
畫面：<一兩句：用什麼場景或比喻、為什麼這樣畫>

#### 動畫分鏡 <段 id>

| 拍 | 講到（綁句） | 畫面上出現什麼 | 動態（設計系統語彙） | 焦點 | 音效拍點 |
|---|---|---|---|---|---|
| 0 | 段起點 | 左邊一張空的行事曆，佔畫面一半 | 開場 | 行事曆 | — |
| 1 | `#13@每週` | 行事曆上七格依序被主色填滿，右邊數字從 0 跳到 7 | 錯拍彈出（格子）；數字滾動（7） | 數字 | — |
| 2 | `#15@省下` | 七格縮成一格，旁邊冒出「省 6 天」 | 淡出（六格）；彈出（標籤） | 標籤 | success |
```

- 「講到」寫 `#N@詞`（那句字幕裡連續的字）；綁句首寫 `#N`。這一拍出現的字從句子中間開始講時，綁卡上最前面的那個詞。
- 「動態」只用這張表的名稱（括號寫對象；同一拍幾個動作用「；」隔開；第 0 拍寫 `開場`）。表上沒有的動作（旋轉、飛入、漂浮）就是不做：

  | 類 | 名稱 |
  |---|---|
  | 進場 | 擦開、滑入、彈出、錯拍彈出、長出、抽屜抽出、淡入、貼上 |
  | 字 | 逐字上浮、逐字彈出、逐字落下、打字、數字滾動 |
  | 線 | 描線、彗星描線、圖示描線、描圈打勾、劃掉、進度推進、量條 |
  | 強調 | 光澤掃過、螢光筆、重拍、漣漪、蓋章（一段最多 1 個） |
  | 焦點 | 聚焦（一個放大、其他壓暗）、預覽態、走過、退焦、回均衡、換焦點 |
  | 鏡頭 | 鏡頭慢推、鏡頭跟焦點、鏡頭回正 |
  | 移動與退場 | 游標移動、擦掉、抽屜收回、淡出、撕走 |
- 音效拍點：一段最多一顆主音效（名稱看 brief），有游標按下的那一拍可以另外寫 `click`。結尾停在完成態，不做收場動作。

只寫腳本的派工：寫完回一行 `<段> 腳本完成｜<概念一句話>`。

## 2. 動畫：`work/hyperframes/compositions/x-design-<段>.html`

畫布檔已經有骨架（`<template>`、根元素 `#x-design-<段>`、舞台 `#xd<段>-stage`、`tl`、`P`、結尾的 `P.end()`）。把舞台裡占位的 `data-design-blank` 元素刪掉，內容放進舞台；自己的 `<style>` 和動畫加在骨架中間，其他不動（`data-duration` 不用改）。

- **綁句**：每拍一行 `const T1 = P.at('#13@每週');`（括號裡寫字串字面值，只綁鏡位腳本表上的那幾拍），當 GSAP 的位置參數；同一拍後面的動作寫 `T1 + 0.4`。音效 `P.sfx('success', '#15@省下')`。拍要改，先改 `work/designs/<段>.md` 的表。
- **進場**用 `tl.from`／`tl.fromTo`（工具會先把元素藏好，不用 CSS `opacity: 0`）。主角在 `Tn` 進場、配角在 `Tn + 0.4`，一拍的動作在 1 秒內做完，然後靜止到下一拍。
- **版面**：舞台已經照 brief「畫布」寫的範圍擺好，裡面整組自動上下置中、太大會自動縮到放得下；全螢幕段會自動移到正中間。用一般 CSS（flex、grid）排，不用自己算 top。鏡頭動作（推近、跟焦點）推舞台裡面包住內容的那一層，不推舞台本身。自己的 id、class 用 `xd<段>-` 開頭，CSS 選擇器以 `#x-design-<段>` 開頭。
- **顏色**只用 token：`var(--brand)`（主色，只給焦點）、`var(--sc-fs-ink)`、`var(--sc-fs-card)`、`var(--sc-fs-card-line)`、`var(--sc-warn)`、`var(--sc-good)`、`var(--v2-node)`、`var(--v2-line)`、`var(--v2-card)`，陰影 `var(--v2-card-shadow)`。字型用頁面預設的。
- **時間軸要能跳到任何一秒**：不用 `onUpdate`／`onComplete`、計時器、亂數、無限循環；狀態切換用淡出舊的、淡入新的，不補間顏色。
- **大小**（觀眾多半用手機看）：主角長邊 300–480px；標籤字 36–44px，最小 30px（直式：縮進上半的段 57px 以上、疊在講者身上的段 48px 以上）；最想讓人記住的詞或數字 72px 以上，用 `<br>` 斷在語意處。完成態太空就放大主角，不要加東西湊滿。
- **素材圖片**（書封、截圖、照片）：`<img src="assets/images/<檔名>" alt="">`，路徑照 `work/media/index.md`，寬高用 CSS 寫死。錄影用 media 段，不放進來。
- **疊加段**（brief 寫講者全畫面、plan.json 這段 `"layout": "overlay"`）：根元素加 `data-matte="1"`，講者去背後疊在你的畫面上面；東西排在講者框的兩側和上方，只放一個大字或左右兩個對比。要蓋在講者前面的東西：根元素加 `data-matte-front="x,y,寬,高; …"`（畫面座標，四邊多留 20px，不蓋到臉）。講者坐著、椅背會閃才改用 `data-matte="steady"`。
- **作者的品味**（驗收會量，這裡先照做，省一輪）：落地就靜止；不做大位移飛入；不轉非 90 度的角度；每一組在底塊裡左右置中；同一張卡的標籤和大字不重複同一個詞；列舉三件以上用 1 2 3 編號、卡片同寬單欄；新的一組出現時前一組退場或壓暗；講到推翻時前一個說法加刪除線（`P.strike`）；工具標誌用 `design-kit.md`「工具標誌」的真實標誌；卡片貼著內容、線不穿過字和卡片。

```html
<style>
  #x-design-s0108 #xds0108-row { display: flex; align-items: center; gap: 120px; }
  #x-design-s0108 #xds0108-week { display: flex; gap: 20px; }
  #x-design-s0108 .xds0108-cell { width: 84px; height: 200px; border-radius: 16px; background: var(--brand); }
  #x-design-s0108 #xds0108-num { font-size: 300px; line-height: 1; font-weight: 800; color: var(--sc-fs-ink); }
</style>
<div id="xds0108-stage">  <!-- 骨架原本就有的舞台：占位那一行換成下面的內容 -->
  <div id="xds0108-row">
    <div id="xds0108-week"><div class="xds0108-cell"></div><!-- 共七格 --></div>
    <div id="xds0108-num">7</div>
  </div>
</div>
<script>
    const T1 = P.at('#13@每週');
    tl.from('.xds0108-cell', { opacity: 0, scaleY: 0.4, transformOrigin: '50% 100%', duration: 0.4, ease: 'back.out(1.6)', stagger: 0.12 }, T1);
    tl.from('#xds0108-num', { opacity: 0, y: 24, duration: 0.5, ease: 'expo.out' }, T1 + 0.4);
    const T2 = P.at('#15@省下');
    tl.to('.xds0108-cell:nth-child(n+2)', { opacity: 0, duration: 0.3, ease: 'power2.in' }, T2);
    P.sfx('success', '#15@省下');
</script>
```

**有外形的物件**（裝置、器具、人、建築…）：先用 brief「圖庫裡有的物件」列的線稿（那一行整個照抄），沒列到的用 `--pics <詞>` 找，或用圖示（`design-kit.md`）；都沒有才新畫，一段最多新畫一個。不要用空白方框代替實物。簡單的形狀和線（卡片、格子、條、圓、膠囊、大字、箭頭）直接用 HTML＋CSS 或 inline `<svg>` 畫。

## 3. 驗收

```
node shared/template/tools/audit.mjs --project projects/<專案> --only <段> --shots --sheet
```

照它最後那一行 `→` 做，不用自己判斷要不要再修：

- `→ 改…`：用 edit 改 ✖ 那幾處（不要整份重寫，重寫一次和第一次做一樣久），再跑同一條。
- `→ 看拼圖…`：用看圖的工具打開那張拼圖看一次（每一格和鏡位腳本那一拍對得上、有主角、最重要的詞一眼看得到、遮住字幕看得懂）；一般的 ⚠ 不用修。有一項不對就用 edit 改一次再跑，都對就照「交件」回報。
- `→ 交件`：⚠ 不用再修，把留下的 ⚠ 寫進 `work/reports/<段>.md`（一個一行：規則名稱＋為什麼留著），回報。
- `→ 停手`：照「回報」的停手那一行回報。

| 狀況 | 做法 |
|---|---|
| 動畫檔不存在 | `node shared/template/tools/build.mjs --project projects/<專案> --design-canvas <段>` 補一份空白畫布 |
| → 叫你重跑 build、snapshot | 那是主代理的事；改好動畫檔、重跑驗收那一條就好 |
| `✖ plan.json 比 index.html 新，這次量不準`、→ 要你改 plan.json | 停手，把那一行原文交回主代理（plan.json 只有主代理能改） |

只寫自己這段的檔：`work/designs/<段>.md`、`compositions/x-design-<段>.html`、`compositions/components/`（registry 裝的）、`illus-local/` 自己新畫的那一個、`work/reports/<段>.md`。

## 回報

只回一行，細節寫在檔案裡：

- 做完：`<段> ✖0 ⚠<N>｜<做了什麼，一句話>`；新畫了物件加 `｜新畫：<名稱>`；用了 registry 元件加 `｜registry：<名稱>`
- 停手：`<段> ✖<N>｜卡在：<那行 ✖ 原文>`
