# 拆參考片

使用者說「拆這支參考片」「分析這支影片怎麼剪」「學這支片的剪法」，而且給了影片檔的路徑時照這份做。只給網址、沒有檔案：請使用者自己下載後給路徑，不要自己下載。

產出只有一份報告：`projects/<專案>/work/reference/<名稱>/報告.md`。不改 `shared/`、不改 plan.json、不新畫模板；報告寫完，要不要套用由使用者下一句話決定。只學手法：對方的素材、角色、文案、Logo 都不搬過來。

## 步驟

**1. 抽格**

```
node shared/template/tools/media.mjs ref --project projects/<專案> --file "<參考影片路徑>" --name <名稱>
```

完成判準：印 `✓ 參考片 …`，下一行有 `index.md` 和縮圖總表的檔名。只讀參考影片，不會複製或改它。

**2. 看圖**

`work/reference/<名稱>/index.md` 和每一張 `sheet-NN.jpg` 都要讀。格子上的數字是那一格的時間；右上角有黃色方塊＝換鏡頭後那一格。看不清楚的字就寫「看不清楚」，不要猜。

**3. 照九個維度寫**

一個維度寫幾行就好，每一行附時間（照格子上的數字），寫看得到的事實，不寫「很有質感」這種評語。

| 維度 | 看什麼 | 對到工作區的哪裡 |
|---|---|---|
| 片型 | 橫式或直式、講者露臉佔多少、有沒有全程動畫 | 開工決策表（`auto-edit-longform`） |
| 字體 | 粗細、黑體或襯線、中英混排、幾種字體 | `shared/template/kit/fonts/`（只有 3 套，對不上寫「缺」） |
| 色彩 | 主色、底色亮或暗、強調色有幾個 | `brand.mjs`、`shared/template/styles/` |
| 字卡 | 字幕的樣式和位置、大字卡多久出現一次 | `shared/style.md`「字幕」、07、15、字卡動態 |
| 元素 | 圖示、插圖、貼紙、照片、螢幕錄影、裝飾 | `kit/icons.json`、`kit/illus-gallery.jpg`、media 段 |
| 模組 | 每一個招式：長什麼樣、用在哪種句子 | `node shared/template/tools/build.mjs --list` 的模板 |
| 動態 | 怎麼進場（彈、擦、打字、貼上）、怎麼強調、鏡頭怎麼動 | `shared/template/BEATS.md` §2 的名稱 |
| 節奏 | 畫面多久換一次、哪裡變快 | `index.md` 的節奏表、`shared/style.md`「節奏」 |
| 轉場 | 段和段怎麼接 | `shared/template/SITUATIONS.md` §4 的轉場語彙表 |

**4. 寫報告**

`報告.md` 固定四節，標題照抄：

```
# 參考片分析：<名稱>

## 一、基本資料
（照抄 index.md 開頭那三行）

## 二、九個維度
### 片型
…（九個小節，順序照上面那張表）

## 三、模組對照
| 時間 | 招式（長什麼樣） | 用在哪種句子 | 工作區對應 | 狀態 |
|---|---|---|---|---|
| 0:12.0 | 同一個詞連換材質 | 揭曉主題 | `x-wordcut` | 已有 |

## 四、建議
### 這一集就能做
### 要作者新做
### 不建議學
```

- 「狀態」只寫三種：`已有`（寫模板名）、`調參數`（寫要改哪個欄位）、`缺`。
- 「這一集就能做」：換主色、換風格包、指定某幾段用哪個模板，每條寫成使用者可以直接說的一句話。
- 「要作者新做」：狀態是 `缺` 的招式。只列出來，不要自己做模板。
- 「不建議學」：和 `shared/style.md` 衝突的做法（寫是哪一條），或要用到對方素材的。

## 回報

最多 15 行：參考片的基本資料一行、九個維度各一句、模組 `已有`／`調參數`／`缺` 各幾個、報告路徑。最後一行：`→ 下一步：要套用就說「這集用 <報告裡的建議>」；要新做模組請交給作者`。

## 退路

| 症狀（工具原文） | 做法 |
|---|---|
| `✖ 找不到參考影片` | 把路徑原文回報給使用者，請他確認；路徑有空白要加引號 |
| `✖ … 讀不到畫面或長度` | 回報原文，請使用者換一個影片檔 |
| 縮圖太小、字看不清楚 | 重跑步驟 1 加 `--every 0.5`（格子變密）；還是看不清楚就寫「看不清楚」 |
| 鏡頭數只有 1–2 個 | 參考片是程式產生的動畫片，換鏡頭偵測不到；節奏改看縮圖裡畫面內容多久換一次 |
