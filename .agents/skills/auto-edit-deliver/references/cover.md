# 封面圖

使用者說「做封面」「封面圖」「做縮圖」時照這份做。要先有 `work/rough.mp4`（剪乾淨之後就能做，不用等完成影片）。

一次出三張讓使用者挑，一個情境一張：去背＋內容、情境模擬、大塊圖示。內容寫在 `work/cover/cover.json`，工具排版出圖，不自己寫封面的 HTML。

## 步驟

1. **拿指令**：使用者貼來「做這支影片的封面（專案 …」那一段（封面台的「複製封面指令」）就照那一段做，跳到第 3 步。只說「做封面」時跑：

   ```
   node shared/template/tools/media.mjs cover --project projects/<專案> --brief
   ```

   使用者指定了封面上的字就加 `--title "第一行|*強調詞*"`（`|` 換行，`*詞*` 套主色底）；沒指定不用問，那一段會要你照摘要每一張各想一組。
2. **照印出來的那一段做**：寫 `cover.json`、出圖（寫法、字數上限、要不要生圖、出圖指令都在那一段裡）。
3. **回報**：出好的幾張都附上（`<deliver-assets>` 的 image），寫每一張的標題；附封面台的網址（`node shared/template/tools/editor.mjs --status --project projects/<專案>` 印的網址後面加 `/cover`；沒開就先跑一次不加 `--status` 的）。換講者的表情、改字、選定都在那一頁，選定的那張是 `output/cover/cover.jpg`。

## 判準

- 橫式專案是 1920×1080（YouTube 縮圖）；直式專案是 1080×1920，標題和主視覺都在中間 3:4 裡。版式照專案，不用自己指定。
- 工具印 `⚠ 去背模型還沒下載` 時照樣出圖，只是講者沒有去背：把這一行貼給使用者，問要不要下載（約 170 MB）；同意才跑 `media.mjs matte-setup` 再重做。
- 工具印 ✖（字太長、太多行、找不到圖示）就照 → 改 `cover.json`，不要自己改 HTML 硬塞。
- 使用者要改某一張的字、換表情：請他在封面台改（改完按「重新出圖」），或你改 `cover.json` 後加 `--only <情境>` 重出那一張。
- 換主色後封面跟著變（讀 `kit/brand.css`）；要換字型、版型時回報給使用者，不要自己改 HTML。
