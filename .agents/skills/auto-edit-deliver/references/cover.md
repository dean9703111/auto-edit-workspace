# 封面圖

使用者說「做封面」「封面圖」「做縮圖」時照這份做。要先有 `work/rough.mp4`（剪乾淨之後就能做，不用等完成影片）。

## 步驟

1. **問標題**（使用者沒給才問，一次問完）：封面上的字，不是影片標題。最多 3 行、一行最多 9 個字寬；手機上封面只有拇指大，字越少越好。使用者說「你想」時，從講稿挑觀眾最在意的那個結果或數字，給 3 個讓他選，不要自己定。
2. **出圖**：`|` 換行，`*詞*` 是要強調的詞（套主色底，一張最多一個）；`--kicker` 是標題上面的小標（集數、系列名），沒有就不寫。

   ```
   node shared/template/tools/media.mjs cover --project projects/<專案> --title "第一行|*強調詞*" --kicker "EP 12"
   ```

   會寫 `output/cover/cover-a.jpg`（人物跳出）、`cover-b.jpg`（色塊分割）、`cover-c.jpg`（底部標題），和 `work/cover/candidates.jpg`（8 格候選）。
3. **挑表情**：看 `work/cover/candidates.jpg`，挑眼睛張開、嘴型自然、手勢沒有糊掉的那一格，用工具印的秒數再跑一次同一條加 `--at <秒>`。第一次用的那一格已經符合就不用重跑。
4. **回報**：三張都附上（`<deliver-assets>` 的 image），說明用的是第幾秒；請使用者挑一張，或說要改的字。

## 判準

- 橫式專案是 1920×1080（YouTube 縮圖）；直式專案是 1080×1920，標題和臉都在中間 3:4 裡（動態牆裁成 3:4 也看得到）。版式照專案，不用自己指定。
- 工具印 `⚠ 去背模型還沒下載` 時照樣有三張，只是講者沒有白邊：把這一行貼給使用者，問要不要下載（約 170 MB）；同意才跑 `media.mjs matte-setup` 再重做。
- 工具印 ✖（標題太長、太多行）就照 → 刪字，不要縮小字級硬塞。
- 換主色後封面跟著變（讀 `kit/brand.css`）；要換字型、版型時回報給使用者，不要自己改 HTML。
