# 螢幕錄影與圖片配對

規則在 AGENTS.md；本檔只寫這一階段的指令、判準、停點、退路。
衝突時：使用者當下的話 > AGENTS.md > shared/style.md > USAGE.md > USAGE-reference.md > 本 Skill；派工時派工訊息 > 本 Skill。

| 輸入 | 指令 | 產出 | 完成判準 | 停點 |
|---|---|---|---|---|
| `素材/螢幕錄影/`、`素材/圖片/`，或 `--check` 印的「只有聲音」區間 | `media.mjs scan`、`media.mjs frame --grid` | 分鏡表 media 列草稿（主代理寫進 storyboard.md） | 每段口播對到同一個操作；「只有聲音」的區間全部蓋住 | 沒有（併進 ③） |

做法的唯一定義：USAGE.md 第 5 節；節奏與標註規則：style.md「螢幕錄影與圖片」。

## 開始前

| 條件（看得到的事實） | 做法 |
|---|---|
| 當子代理 | 不寫檔，只回報（AGENTS.md「子代理分工」）；派工訊息和本檔衝突時照派工訊息 |
| `work/media/index.md` 已經存在、素材沒換 | 跳過步驟 1 |

## 步驟

**1. 掃素材**

```
node shared/template/tools/media.mjs scan --project projects/<專案>
```

完成判準：`work/media/index.md` 存在，每支錄影有 `work/media/<檔名>/sheet-NN.jpg`；「只有聲音」的區間也列在 index.md。
常見錯誤：素材檔名有空白、括號 → 指令照 index.md 印的檔名加雙引號。

**2. 對字幕配起點**

```
（不用指令：讀 work/media/index.md 與 sheet-NN.jpg，對照 work/rough.srt）
```

每段口播找「錄影裡正在做同一個操作」的那一格，寫素材檔名、`in` 秒數（註明 sheet 第幾格）、理由。
完成判準：每一列都有素材檔名、`in`、對到的句號（`#N`–`#Me`）、理由。
常見錯誤：口播和畫面對不上 → 調起點、變速（style.md「螢幕錄影與圖片」的上限）或拆段，不要讓觀眾看別的畫面聽說明。

**3. 讀座標**

```
node shared/template/tools/media.mjs frame --project projects/<專案> --src "素材/螢幕錄影/<檔名>" --at <秒> --grid
```

完成判準：每個運鏡 `moves`、紅框 `marks`（含跟捲動的 `path`）、說明卡 `callouts`、聚光燈 `spot`、放大鏡 `lens` 都有素材原尺寸的 `[x, y, w, h]`，箭頭 `arrows` 有 `[x, y]`（目標靠箭尾那一側的邊，USAGE.md 5.4）。
常見錯誤：用了 1920×1080 的畫面座標 → `--check` 會 ✖「超出素材範圍」，回到這一步用格線圖重讀。

**4. 標註**

```
node shared/template/tools/build.mjs --project projects/<專案> --check
```

選哪一種照 USAGE.md 5.5 表下的「選哪一種標註」：講「這一塊」用紅框；講「這是什麼／按這個」用說明卡；只看一塊用聚光燈；目標太小用箭頭；字太小用放大鏡；一步一步的操作加 STEP 膠囊。錄影捲動時讓同一個紅框跟著移（`path`）。直式專案：16:9 錄影只有 1080 寬，一定加 `moves` 推近到操作區；手機直式錄影用 `"pip": false`＋`"fit": "cover"` 鋪滿。說明卡、聚光燈、箭頭出現的期間不能運鏡：推近要在標註的 `at` 之前結束。數量、停留下限照 style.md「螢幕錄影與圖片」。錄影裡看得到游標按下的地方寫 `"clicks"`（style.md「音效」）。
完成判準：`--check` 和 media 相關的 ✖ 是 0；報告那一列的「運鏡 N、紅框 N、標註 N、STEP N、箭頭 N、放大鏡 N」和你寫的一致。
常見錯誤：`marks：… 同時有 N 個紅框` → 位置相近、連續講同一塊的合成一個大框（說明卡的框也算）；`箭頭 0（拿掉 1）` → 照 ⚠ 改 `to` 或 `from`。

**5. 交回**

```
node shared/template/tools/build.mjs --project projects/<專案> --check
```

主代理：把結果寫進 storyboard.md 的 media 列（USAGE.md 2.3）。子代理：照「回報格式」回報，不寫檔。
完成判準：`--check` 的「只有聲音」那一行寫「已被 media 段或全畫面蓋住」。
常見錯誤：還有沒蓋住的區間 → 回步驟 2 補一段，或改用不透明的全幕（04 家族）。

## 自我核對

- [ ] 每段 media 都對到口播同一個操作
- [ ] 座標是素材原尺寸
- [ ] 只有聲音的區間全部蓋住
- [ ] 錄影段沒放下方資訊卡（style.md）
- [ ] 從講者切到錄影的第一段音效是 `whoosh`（style.md「音效」）
- [ ] 當子代理時沒有寫任何檔

## 退路表

| 症狀（工具原文） | 做法 | 第二次還失敗 |
|---|---|---|
| `src：找不到 素材/螢幕錄影/… → 檔名要和專案的 素材/ 資料夾裡一模一樣（現有：…）` | 照括號裡的檔名改 | 停下來回報：指令、錯誤原文、已經試過什麼 |
| `素材 … 長 Ns；從第 Ns 起播 Ns 要用到第 Ns` | `in` 往前、`to` 提早或 `speed` 改小，或拆兩段 | 停下來回報 |
| `… 超出素材範圍 W×H` | 重跑步驟 3 讀座標 | 停下來回報 |
| `只有聲音的區間 …–… 有 Ns 是黑畫面` | 把前一段的 `to` 延到下一段的 `from`（0 秒相接），或加一段 media | 停下來回報缺素材 |
| 說明卡、聚光燈、箭頭的 ✖ 寫「期間不能有運鏡」 | 推近的 `dur` 結束時間提早到標註 `at` 之前，或拉回全景改到標註退場之後 | 停下來回報 |
| 說明卡 ✖ 寫完整可讀不夠、或 `side` 放不下 | `until` 往後延；`side` 照訊息改，或不寫讓 build 自動挑 | 停下來回報 |

## 工具呼叫預算

每支錄影最多 6 次（AGENTS.md「階段預算」）。超過就停下來回報卡在哪。

## 回報格式

當子代理時最多 25 行；每段一列：

```
| 句號 | 素材檔名 | in（sheet 第幾格） | speed | 運鏡／紅框／標註／放大鏡座標 | 理由 |
|---|---|---|---|---|---|
| #20–#24e | 素材/螢幕錄影/操作示範.mp4 | 12.5（sheet-01 #7） | 1 | moves #20+0.5 [0,120,640,360]；callouts #21「設定」[40,200,180,60]；clicks #21@設定 | 口播「打開設定頁」＝sheet #7–#10 |
只有聲音的區間：全部蓋住（或：還差 1:10.00–1:12.00）
我沒有改的東西：plan.json、storyboard.md、rough.srt、shared/
```
