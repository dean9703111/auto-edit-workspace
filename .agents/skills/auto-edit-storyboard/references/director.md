# 導演：寫這集的視覺語言

影片 5 分鐘以上才需要（短片跳過）。分章子代理各看各的章，沒有人看全片：同一個比喻會重複出現、該呼應的地方接不起來。先花一小段時間想清楚，後面每個人都照這份做，一致又不重工。

## 派工訊息

```
你是這集的導演，負責 projects/<專案> 的視覺語言。照 .agents/skills/auto-edit-storyboard/references/director.md 做。
```

沒有子代理工具就主代理自己寫。

## 做法

讀 `projects/<專案>/講稿.md`（沒有講稿讀 `work/rough.srt`）和 `work/分鏡素材/index.json`（每章的句號範圍）。不用讀別的。寫 `projects/<專案>/work/分鏡素材/視覺語言.md`，最多 2000 字：

```markdown
# 視覺語言

這集在講：<一句話>

## 貫穿全片的主題（2–5 個）

- **<名稱>**：<長什麼樣、第一次在哪出現（#N）、之後在哪回來、每次一樣的是什麼、變的是什麼>

## 配色

<主色給什麼、紅色給什麼、綠色給什麼>

## 指定做內容設計動畫的段（上限看 --scaffold 印的目標）

| 段 id | 句號 | 版面 | 要傳達什麼、用什麼畫面（一句話） |
|---|---|---|---|
| d0101 | #1–#3e | fullscreen | … |

## 其他段的方向（選填）

- <哪幾句適合配錄影、提示詞打字、數字、對照>
```

判斷哪些段值得設計：故事、比喻、因果轉折、前後對比、最想讓人記住的畫面。條列、流程、單一數字用模板就好。段 id 用 `d<章號兩位><流水號兩位>`。

## 回報

只回一行：`視覺語言完成｜主題 <N> 個｜指定 <N> 段`。
