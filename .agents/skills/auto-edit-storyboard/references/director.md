# 導演（主代理）：全片校正語意地圖

分章子代理各看各的那一份，沒有人看全片：A（亮點）會在每份平均分配、同一個比喻重複出現、同樣的內容一份標「步驟」另一份標「列舉」。第一回合的地圖全部回來後，主代理當導演，**只讀合併後的地圖、不讀字幕**，把全片的決定做完，第二回合每份照它寫。

## 做法

1. 跑 `node shared/template/tools/build.mjs --project projects/<專案> --map-merge`。它把各份的 `work/drafts/<份>.map.md` 接成 `work/分鏡素材/語意地圖.md`，開頭有摘要（A 預算、各語意的分布、A 提名）和 ✖／⚠。地圖本身有 ✖（語意寫錯、範圍不對）：把原文交回那一份的子代理，或自己改那一行。
2. 讀 `語意地圖.md`（長片約 100 行），做三件事，直接改各份地圖那幾行（只改級、語意，不改句號範圍）：
   - **A 名單**：全片排序，留最值得專門設計的時刻，超過上限的改成 B；開場、結尾一定要有。判斷：故事、比喻、因果轉折、前後對比、最想讓人記住的畫面；把字幕遮起來只看畫面，模板做不到的才是 A。條列、流程、單一數字用模板就好。
   - **統一標法**：同樣的內容在不同份要同一個語意、同一級（摘要的「各語意」標了「B、C 都有」的先看）。
   - **貫穿主題**：寫 `work/分鏡素材/視覺語言.md`（格式見下）。影片 5 分鐘以上一定要寫，`--map-merge` 沒有它會 ✖。
3. 再跑一次同一條。⚠ 看一輪就好：照 → 改那幾行，再跑一次就停，留下的 ⚠ 寫進回報。印「語意地圖通過」就照它「→ 派工：」下面那幾行派第二回合。

## 視覺語言.md

最多 2000 字：

```markdown
# 視覺語言

這集在講：<一句話>

## 貫穿全片的主題（2–5 個）

- **<名稱>**：<長什麼樣、第一次在哪出現（#N）、之後在哪回來、每次一樣的是什麼、變的是什麼>

## 配色

<主色給什麼、紅色給什麼、綠色給什麼>

## 其他段的方向（選填）

- #N–#M：<這幾句適合配錄影、提示詞打字、數字、對照>
```

主題和各段方向都寫上句號（`#N–#M`）：工具照句號把和某一段有關的那幾列帶進那一段的 brief，其他的不帶；沒寫句號的主題會整份帶給每一段。

A 名單不用寫進這份（在地圖上）；同一個比喻只給一個 A，其他 A 回來呼應它。只定主題、畫面元素和配色，**不要指定某幾段用同一個模板**（相鄰兩段同模板工具會 ⚠）：要呼應，寫「同一個元素回來」（例：同一本說明書、同一條路上的關卡），模板讓子代理照秒數挑。

## 回報

照 `auto-edit-storyboard` 的回報格式；這一步只在回報裡加一行：`語意地圖：<N> 行（A <N>、B <N>、C <N>）｜主題 <N> 個`。
