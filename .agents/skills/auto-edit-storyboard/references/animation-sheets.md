# 動畫分鏡、插圖清單、快速初稿

給 `auto-edit-storyboard` 步驟 5 用：判定表填完，有情境動畫（`x-*`）或 04 家族的段才讀。拍型的行號在 `work/分鏡素材.md` 第 7 節。

**快速初稿**（只有使用者說「快速初稿」「先出初稿」「動畫之後再做」才用，回報第一行寫「快速初稿」）：判定表照填、首選照寫；首選是情境動畫的段，plan.json 先放 §3「次選」欄的卡（只有聲音的區間放不透明的全畫面卡），「為什麼不是動畫」寫「快速初稿，待做 x-<名稱>」，先不寫動畫分鏡。停點 ④ 回報列「待做動畫：<段> x-<名稱>、…」；使用者說「s05 做動畫」「動畫都做」就走改版（`node shared/template/tools/versions.mjs new --project projects/<專案> --seg <段,段>`，2 段以上平行派子代理）。

**動畫分鏡**（情境動畫 `x-*`、04 家族的段；06／07／12／13 字卡不用）：

1. 看判定表那一列的「拍型」，照分鏡素材第 7 節讀 `shared/template/BEATS.md` 那個拍型的行數，抄整張表到那一段底下（標題 `#### 動畫分鏡 <段 id>`，表頭照抄）。
2. 只填講到的 `#N@詞` 和畫面上的字；動態欄只用語彙表的名稱，不自己加拍、刪拍（BEATS.md §1）。
3. 拍型「待定」的照 BEATS.md §4 排，並列進「需要我決定的事」。

**示意動畫**（拍型 S、`x-scene`）多做兩件事（BEATS.md §5）：

1. 分鏡表用八欄表頭（後面加「插圖元件（狀態）」「位置」），「位置」寫排法 `<區域>｜<排法> <第幾個>`（例 `panelTop｜row 1／3`），不寫像素（`shared/style.md`「版面」）。
2. 表下面寫 `#### 插圖清單 <段 id>`，表頭 `| 元件 | 來源 | 怎麼來 |`，每個元件照這個順序選來源，前一種能用就不要往下（`shared/template/kit/illus-style.md` §1）：畫廊裡有 → 直接用 `data-illus="<元件名>"`（畫廊每格下面有寫法）；lucide 圖示（`kit/icons.json`）單個或 2–3 個組合放進卡片、膠囊能表達 → 用圖示；都不行 → 照 `shared/template/kit/illus-style.md` 新畫一個 SVG。相片、背景、質感圖不走這條；示意插圖一律是向量線條。畫廊先打開 `shared/template/kit/illus-gallery.jpg` 看；「新建 SVG」列的「怎麼來」寫 `規格：<名稱>，建議尺寸 <寬>×<高>，狀態 <a>／<b>；描述：…`。插圖清單和分鏡在停點 ③ 一起確認。
