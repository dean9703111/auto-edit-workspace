# `work/storyboard.md` 骨架

給 `auto-edit-storyboard` 步驟 6 用。格式的唯一定義是 `shared/template/USAGE.md` 2.3；這裡是可以直接複製、把 `<…>` 換掉的骨架。段落編號用 s01、s02…（media 段用 m01…、情境動畫用 x01…），和 plan.json 的 `id` 一致。

**截圖與分鏡表**

- `qc.mjs storyboard` 自己算每段的完成態（條列逐條換的每次一張、錄影段每個標註到位一張），不要自己算秒數跑 `snapshot --at`。
- 最後印的 `![s01](storyboard-preview/s01.png)` 那幾行照順序貼進每段「截圖觀察」上面，**只貼這一次印出來的那幾行**（同一段張數變了，工具會清掉舊檔並印「清掉同一段的舊截圖（這次張數變了）：…」）；每張後面的「為什麼」（完成態、第 N 條、…到位、整段都在動）照 USAGE.md 2.3 讀。
- 截圖停在動畫中途（字半透明、卡片在飛）→ 重跑一次 storyboard，還是一樣就在「需要我決定的事」列出段號和秒數。
- 照 `references/storyboard-template.md` 寫 `work/storyboard.md`；「音效」欄寫 `預設`、`無`、換的名稱（例 `shine`），錄影段加 `clicks 2 下（#21@安裝、+3.2）`。
- 拿不定版面的段落：先把第一個方案的圖改名成 `s05-A.png`，改 plan.json、build、再跑一次 storyboard 得到 `s05.png`，兩張並排請使用者選。

- 條列逐條換的段，每條各截一張：`![s04-1](storyboard-preview/s04-1.png)`、`![s04-2](…)`。
- 截圖貼 `qc.mjs storyboard` 印的那幾行，順序不要動。
- 「#### 動畫分鏡」只有情境動畫（`x-*`、04 家族）的段才寫；字卡段（06／07／12／13 等）不寫。示意動畫（`x-scene`）的段用八欄表頭，「位置」寫排法（`panelTop｜row 1／3`），不寫像素（`shared/style.md`「版面」），下面再加「#### 插圖清單」（`shared/template/BEATS.md` §5）；元件換成這段用到的，「新建 SVG」那列照「規格：<英文名>，建議尺寸 W×H，狀態 a／b」寫（`media.mjs illus-lint` 會讀）。表頭一個字都不能改（audit 會讀）；動態欄只寫 `shared/template/BEATS.md` 語彙表的名稱。
- 使用者會在分鏡表網頁（`editor.mjs` 印的「分鏡表：」網址）調整，也可能直接改這份檔；他說「改好了」「可以」時，先重新讀檔。網頁只改「畫面文字」和動畫分鏡「畫面上出現什麼」裡的字、金句「卡上文字」與勾選（`☑`＝上、`☐`＝不上）、`- 音效：`，以及兩個要求欄：`- 想換成：<情境>`、`- 補充說明：<文字>`。有要求欄的段先照要求重做、重截、刪掉那兩行，再重貼停點 ③（`SKILL.md`「停點」）；這兩行不要自己寫進草稿。
- 畫面文字的字一律用「」包起來：網頁只開放改「」裡的字，旁邊的欄位名、`#N@詞` 使用者動不到。
