# 剪好看（前半）：構圖到分鏡表

規則在 AGENTS.md；本檔只寫這一階段的指令、判準、停點、退路。

| 輸入 | 指令 | 產出 | 完成判準 | 停點 |
|---|---|---|---|---|
| `work/rough.mp4`、`work/rough.srt` | 步驟 1–3 | `work/media/notes/`（有素材時）、`work/構圖預覽.jpg`、構圖台網址 | 回報段已貼 | ② 構圖 |
| ② 通過 | 步驟 4–7 | `work/分鏡素材/`、`work/drafts/`、`plan.json` 的 scenes、`work/storyboard.md` | 分鏡表由工具產生、`--check` 0 個 ✖ | ③ 分鏡表 |
| ③ 通過 | 步驟 8 | plan.json 套好使用者的修改 | 印出下一步 | — |

工具印的「→ 下一步：」下面是要跑的指令，「→ 派工：」下面每一行（縮排兩格）是一則照抄給子代理的派工訊息，照它做；分鏡表由工具產生，不手寫；秒數工具算。`--storyboard` 會自己擋「② 還沒通過」「plan.json 沒有 speakerBox」，照它印的下一步做。這一階段要你判斷的是：全片校正語意地圖、貼停點 ③ 之前看開場和結尾（都在步驟 5），以及使用者在停點的回覆怎麼處理（「停點」那張表）。

版面節奏由工具排（`--map` 印「版面安排」：開頭 30 秒字卡、子母畫面一次連續 ≥ 45 秒、半螢幕 ≥ 15 秒），大綱不合 `--outline` 會 ✖；`--check` 印的「講者位置：左／中／右」決定字卡和半螢幕面板靠哪一邊，給使用者看分鏡表時提一句。

畫面有三條路：對得上的錄影或圖片（media 段）、模板（工具直接產出）、內容設計動畫（地圖上的 A 先套模板、標成候選；預設不做，使用者在 ③ 勾了、或看完預覽說「<段> 重新設計」，才由設計師從空白畫布做）。「音效稀疏」⚠ 和 build 印的六行（人聲響度、音效比例…）到停點 ④ 才處理，這一階段不補、不貼。

## 開始前

| 條件（看得到的事實） | 做法 |
|---|---|
| 沒有 `work/rough.srt` | 改用 `auto-edit-rough` |
| plan.json 有 `speakerBox`，或停點紀錄 ② 是「通過」 | 跳過步驟 1–3 |
| 停點紀錄最後一列是 ② 或 ③「待回覆」 | 不重做；照「停點」那張表處理使用者的回覆 |
| 使用者說「快速初稿」「先出初稿」「動畫之後再做」 | 派工時加一句「這次不標內容設計動畫候選，全用模板」；回報第一行寫「快速初稿」，停點 ④ 列出值得補設計的段；之後使用者說「s05 做動畫」：走 `auto-edit-review` 流程 B，那一段用 `node shared/template/tools/build.mjs --project projects/<專案> --to-design s05` 換成內容設計動畫，照它「→ 派工：」下面那一行派設計師 |

## 步驟

**1. 講者調光瘦臉的設定**（使用者事先指定這一集的調光、瘦臉才做；沒指定就跳過，步驟 3 照預設做）

```
node shared/template/tools/build.mjs --project projects/<專案> --set "look.color=0.8;look.slim=0.6"
```

數字換成使用者說的；這一集不要調光瘦臉寫 `--set look=off`。不用另外跑 `look.mjs`：步驟 3 會照這個設定先做好。
完成判準：沒指定就跳過；有指定時印 `✓ plan.json：look…`。

**2. 素材盤點**（`assets/screen/`、`assets/images/` 有檔案才做，不用等使用者；`work/media/index.md` 已經有就不跑下面這條，直接派子代理）

```
node shared/template/tools/media.mjs scan --project projects/<專案>
```

每支錄影、每批圖片（12 張一頁）派一個子代理寫筆記 `work/media/notes/<檔名>.json`，同一則回覆一次派出（`auto-edit-screen` 步驟 1）；沒有子代理就自己一支一支寫，素材很多先寫跟講稿有關的。之後分章寫草稿時就知道素材能配哪裡。散在專案根目錄的檔不處理（使用者說「分類素材」才動）。
完成判準：每支錄影、每批圖片都有筆記。

**3. 構圖台 → 停點 ②**

```
node shared/template/tools/build.mjs --project projects/<專案> --framing
```

一條做完：講者調光瘦臉過期就先跑（印 ⏳ 就再跑同一條，會接著等）、量構圖、開構圖台、記 ② 待回覆，最後印回報段，停點 ② 那兩行在最後。沒有講者（只有聲音、邊錄邊講的螢幕錄影）會印「不用構圖」並直接產生分鏡素材：跳過步驟 4，照它「→ 派工：」下面那幾行做步驟 5。
完成判準：印出回報段和停點 ② 那兩行（或「不用構圖」）。
常見錯誤：臉太小、偵測率太低印 ⚠ → 工具已自動只調光，回報時加一行說明就好。

**4. ② 回覆：記 ② 通過、量講者框、切分鏡素材**

```
node shared/template/tools/build.mjs --project projects/<專案> --framing-done --said "<使用者原話>"
```

照使用者的回覆選寫法：「調好了」照上面（構圖台已經存好框）；「用建議的」加 `--use suggested`；說倍率（例「1.15」）加 `--use 1.15`；要改調光、瘦臉，先照步驟 1 跑 `--set`，再跑這條。一條做完：記 ② 通過、瘦臉過期先重跑（印 ⏳ 就再跑同一條）、量講者框寫進 `speakerBox`、產生 `work/分鏡素材/`，最後印第一回合的派工。
完成判準：0 個 ✖，最後印第一回合的派工（或「分鏡素材已經切好」）。

**5. 分章寫分鏡：語意地圖 → 全片校正 → 草稿**

```
node shared/template/tools/build.mjs --project projects/<專案> --map-merge
node shared/template/tools/build.mjs --project projects/<專案> --merge-drafts
```

1. **第一回合（語意地圖）**：切了幾份就派幾個子代理，派工訊息照抄切分鏡素材時（步驟 4；沒有講者是步驟 3）印的「→ 派工：」下面那幾行，同一則回覆一次全部派出；只有 1 份就自己照 `references/chapter-worker.md` 做。
2. **全片校正**：全部回來才跑第 1 行。你是導演：只讀 `work/分鏡素材/語意地圖.md`、不讀字幕，照 `references/director.md` 挑 A、統一標法、寫視覺語言，再跑同一條到印「語意地圖通過」。
3. **第二回合（草稿）**：照它「→ 派工：」下面那幾行派（能接續第一回合的子代理就接續）。全部回來才跑第 2 行合併；合併會自動修工具知道答案的問題（印「自動修好 N 處」），通過就接著產生分鏡表、印回報段和停點 ③ 那兩行。合併有 ✖：照 → 改那一份 `work/drafts/chNN.json` 再合併（不直接改 plan.json 的 scenes，下次合併會蓋掉）；⚠ 回報只寫個數。
4. **貼停點 ③ 之前整集看一次**，只看兩處（`SITUATIONS.md` §6）：第一份草稿開頭幾段的 `story.say` 有沒有開場轉折句、最後一份結尾幾段有沒有回到前面的清單。缺了才改那一份草稿、再合併，最多一輪。

合併印「派一個設計師寫鏡位腳本」才做步驟 6；印了回報段和停點 ③ 那兩行就跳過步驟 6、7。
完成判準：`--map-merge` 印「語意地圖通過」；`--merge-drafts` 0 個 ✖，最後印停點 ③ 那兩行（或鏡位腳本的派工）。

**6. 內容設計動畫：鏡位腳本**（只有 `--merge-drafts` 印「派一個設計師寫鏡位腳本」才做）

```
ls projects/<專案>/work/briefs/
```

只有使用者事先指名要做的段（plan.json 已經有 `"design": true`）才會走到這裡：每段派一個設計師，派工訊息照抄合併印的「→ 派工：」下面那一行，同一則回覆一次全部派出。一般的候選不在這裡做：使用者在 ③ 勾了，步驟 8 之後才派（腳本＋動畫一次做完）。
完成判準：每段都有 `work/designs/<段>.md`。交回來的概念讀起來像「標題＋幾條文字」就退回重想：要有具體的場景或比喻。

**7. 產生分鏡表 → 停點 ③**

```
node shared/template/tools/build.mjs --project projects/<專案> --storyboard
```

一條做完：build、截圖、寫 `work/storyboard.md`、開分鏡表頁、記停點，最後印回報段，停點 ③ 那兩行在最後。內容設計動畫候選列在分鏡表「需要我決定的事」的勾選表，預設都不勾：使用者說「可以」就全部套模板合成；想一開始就專門設計的段他會自己勾。
完成判準：印出停點 ③ 那兩行；✖ 0 個。

**8. ③ 回覆：套回修改**

```
node shared/template/tools/build.mjs --project projects/<專案> --apply-storyboard --said "使用者原話"
```

把網頁改的字、音效、金句勾選套回 plan.json，只動改到的欄位；勾了的候選，工具改成內容設計動畫。工具列出「想換成」「補充說明」時不記通過：照要求改那幾段（換情境改那段的 `template`／`scene`／`slots`；內容設計動畫改 `work/designs/<段>.md`；改 plan.json 一段的做法在 AGENTS.md「工具注意事項」），再跑 `--storyboard --only <段,段>` 重截、重貼停點 ③。
完成判準：沒有要求時，停點紀錄加了 ③ 通過，印出下一步（有勾內容設計動畫時，下一步是派設計師，不再停）。

## 停點

```
⏸ 停點 ② 構圖｜請看 <構圖台網址> 和 work/look-preview.jpg
請回：拖好框說「調好了」（會自動存），或說「用建議的」

⏸ 停點 ③ 分鏡表｜請看 <分鏡表網址>
請回：改好後說「可以」，或要改的地方
```

② 沒有 `work/look-preview.jpg`（沒開調光瘦臉）時，把「 和 work/look-preview.jpg」拿掉，其他字不動。

| 停點 | 使用者回 | 做什麼 |
|---|---|---|
| ② | 「調好了」；「用建議的」；倍率數字（例「1.15」）；說要改調光、瘦臉 | 步驟 4（照那一步的寫法帶 `--use`；改調光瘦臉先跑步驟 1 的 `--set`） |
| ③ | 「可以」「改好了」 | 步驟 8 |
| ③ | 「s05 換成側邊欄」這類指名修改 | 改 plan.json 那一段（做法見步驟 8；情境換了照新情境寫 slots），跑 `--storyboard --only s05` → 重貼停點 ③ |
| ③ | 改鏡位（「d0305 拍 3 不要預覽態」） | 改 `work/designs/d0305.md`，跑 `--storyboard --only d0305` → 重貼停點 ③（動畫在 ③ 之後才做，截圖是空的畫布；照樣跑這條，分鏡表那一段才會更新） |

## 自我核對

- [ ] ② 的回覆照原話選寫法：「調好了」不帶 `--use`、「用建議的」帶 `--use suggested`、倍率帶數字；原話放 `--said`
- [ ] 派工訊息照抄「→ 派工：」下面那幾行，沒有自己加要求（快速初稿那一句除外）
- [ ] 內容設計動畫候選＝語意地圖上的 A（`--map-merge` 全片挑過、快速初稿不標），標的是真的值得設計的時刻
- [ ] 貼停點 ③ 之前看過開場轉折句和結尾的呼應（步驟 5 第 4 點）
- [ ] 金句只在候選表，沒有直接排成段
- [ ] 回報段和停點那兩行照貼工具印的，只補它要你判斷的那幾行

## 工具呼叫預算

工具印「→ 停手」就停，把它上面還在的 ✖ 原文回報；同一個 ✖ 改 2 次還在也一樣（AGENTS.md 規則 9）。讀文件、派子代理、印 ⏳ 之後再跑同一條都不算。分章子代理的檢查次數也由工具數（`references/chapter-worker.md`）。

## 回報格式

到停點 ②（步驟 3）、停點 ③（`--merge-drafts` 或 `--storyboard`）：照貼工具最後印的「── 回報（照貼；要你判斷的另外補一行）──」那一段，停點那兩行在最後，不改字。只補工具要你判斷的：

- 步驟 3 印了臉太小、偵測率太低的 ⚠：加一行「這次只調光」和原因。
- 做了全片校正：加 `references/director.md` 寫的那一行。
- 快速初稿：第一行前面加「快速初稿」。

## 什麼時候讀 references/

- `references/director.md`：第一回合的地圖全部回來、跑 `--map-merge` 之前讀（主代理當導演）。
- `references/chapter-worker.md`：你是寫分章地圖或草稿的子代理時才讀（主代理派工不用讀，工具會印派工訊息）。
