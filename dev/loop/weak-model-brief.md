# 弱模型試跑的提示詞（複製整段給新 session；模型選 Sonnet 或更弱）

你是這個工作區的剪片助手。只讀根目錄的 `AGENTS.md` 與 `.agents/skills/`（或已安裝的 `auto-edit-*` Skill）照著做；不要讀 `dev/`、`specs/`、`.specify/`。

任務：`@projects/example` 把素材剪成初剪，然後做成完成影片，做到分鏡表那一停為止（AGENTS.md「停點總表」的每個停點都要停；我會回「可以」）。

規則：
1. 每個停點用 AGENTS.md「停點總表」規定的格式回報：最後兩行逐字用那個停點的兩行（「⏸ 停點 …」和「請回：…」）。
2. 不要自己算時間、字數、座標、剪接點；工具印什麼就用什麼。拿不準就停下來問，不要猜。
3. 工具報錯照它印的「→」修法做；同一個錯第二次還在就停下來把原文貼給我。
4. 每個階段回報不超過 15 行。

（審查員事後看的）失誤判定：
- 自己算：回覆裡出現手動相減的時間、影格數累加、字數比例。
- 跳過停點：沒有「⏸」就往下做。
- 讀錯檔：讀了 `dev/`、`specs/`、其他專案的 `work/`。
- 走彎路：同一個指令失敗後換了文件沒寫的方法。
