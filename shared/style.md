# 工程師下班有約：剪輯風格規範

這份文件是給 AI 看的剪輯規則。規劃動畫、上字幕、挑音效時，一律以這份為準。

## 畫布

- 1920×1080、30fps
- 講者固定機位，位置以專案資料夾裡的場地照為準（範本附的是 `projects/範例/場地照-測試.jpg`；Skill 每集自動截的是 `work/場地照.jpg`）

## 講者

14 講者介紹字卡用這裡的資料。換成自己的影片時，改成你的名字與頭銜；這一節刪掉或留空，就不放講者介紹。

- 姓名：林鼎淵（最多 5 字）
- 頭銜：外商工程師、暢銷書作家、企業內訓講師（1–3 個，每個最多 6 字）

## 字幕

- 字型：英文與數字用 **Google Sans Flex**，中文用 **Noto Sans TC**
  - Google Sans Flex 沒有中文字，一定要搭配中文字型，不能只指定它
  - 兩套都是 Google Fonts 上的開源字型（SIL Open Font License）
- 字色：白色
- 底板：黑色，不透明度 70%，直角（不要圓角），寬度貼合文字（不要整條橫幅）
- 字級：字高約畫面高度的 5%（1080p 約 54px）
- 字間距：1
- 位置：水平置中，距離畫面底部約 60px
- 每則最多 18 個字，只排一行；超過就拆成兩則，不要斷在詞語中間
- 優先在逗號、句號等標點處斷開，再考慮字數
- 同一時間只顯示一則字幕
- 技術名詞保留英文原文，中英文之間加半形空格（例：用 MiniMax Code 剪片）
- 實作在 `shared/template/kit/captions.css`，由 `build.mjs` 套用

## 動畫視覺

- 顏色以 `shared/template/kit/brand.css` 為準（預設深藍黑＋招牌黃 #FFD400）；版型只從 `shared/template/` 情境庫挑，規格見 `shared/template/USAGE.md`
- 風格：硬邊、實心底板，**不要光暈、不要發光、不要漸層外框**
- 圖示先行：情境有圖示欄位就配圖示，同一個物件全集用同一個圖示；清單的圖示要配就每一項都配，不要只配一部分
- 圖示是「描出來」的：容器先進場，0.15 秒後把線描出來（0.7 秒，模板自動做）；總結、回顧用圓環＋打勾，流程圖的站不打勾，只換框色
- 不可擋到講者的臉和手勢，安全範圍以場地照判斷
- 不可壓到字幕區（畫面底部 160px）

## 節奏

- 進場時機：資訊卡在講到那個重點的那一則字幕開始時進場
  - 中文逐字稿只有整句的時間碼，對齊到 `work/rough.srt` 的那一則；重點詞在長句尾巴時，用 `#N@詞` 對到那個詞（`shared/template/USAGE.md` 3.4），不要自己猜秒數
- 一起進場：同一張卡的標題、條列項目一起出現，不要一項一項等
- 停留時間：一般卡 2.5–4 秒；07 重點字卡（不論 tone）停到這個重點講完，至少 4 秒
- 換卡：前後兩張接得很近時，上一張退場和下一張進場同時進行，不要等上一張完全消失才開始
- 動作秒數：進場 0.3–0.5 秒、出場 0.3 秒

## 情境動畫優先

- 口播在講一個情境時（過程、前後對比、數值變化、比喻、因果、沒有錄影的介面操作），做情境動畫，不要只下一張字卡；合適的動畫越多越好
- 字卡留給一個名詞、一句重點、一個提醒
- 挑法與範例見 `shared/template/USAGE-reference.md` R7.1；兩段動畫之間講者至少露臉 3 秒

## 字卡文字

- 8–14 個字，是重點摘要，不是逐字照抄字幕
- 密度：大約每 3–8 句一張，實機操作的段落往稀的那端下
- 不下卡的情況
  - 操作指示句（例如「點擊右上角」）
  - 成功、完成之類的狀態句
  - 只有一句話的打勾項目（要湊成清單才下）
- 「提醒」卡只寫提醒與注意事項
- 講到 3 個以上並列的項目，用條列（12／13）或側邊欄（03）、全畫面清單（04a）

## 螢幕錄影與圖片

插入的做法（plan.json 的 media 段、怎麼配對、座標怎麼讀）在 `shared/template/USAGE.md` 第 5 節；這裡是節奏與標註的規則。

- 只有聲音的旁白一定要配畫面（螢幕錄影或圖片），不留黑畫面
- 一段口播配一段錄影：從講到那個操作的那一則字幕開始，講完就回到講者；錄影要和口播講的是同一個操作，對不上就調起點、變速或拆段，不要讓觀眾看著別的畫面聽說明
- 錄影太慢可以加速（最多 4 倍）；等待、載入的空檔剪掉或加速，不要讓畫面停著
- 錄影預設靜音，只聽口播；錄影本身的聲音是重點時才保留
- 講者縮到右下角子母畫面；只有聲音的段落沒有講者，不放子母畫面
- 錄影段落不放下方資訊卡；要強調畫面上的東西，用紅框、運鏡、放大鏡；字卡密度往稀的那端下
- 紅框：實線 4px、警示紅、硬邊無光暈，上下左右內距相等；同一時間最多 2 個；位置相近、連續講同一塊時一開始就畫一個大框，不要一句一框反覆閃；停不到 0.5 秒的不畫；最後一個框講完再多停 1 秒
- 運鏡：推近到口播在講的那一塊，講完拉回全景；一次 0.6–1 秒；推近不超過 4 倍（再大會糊，改用放大鏡）
- 放大鏡：給小字、數字、小按鈕；只框要看清的那一小塊，等比放大；至少停 1.2 秒；一次一個，不和運鏡同時
- 圖片預設整段緩慢推近（1.00→1.05），讓畫面不要死板

## 音效

只能用 `shared/sfx/` 裡的檔案。build 會依情境自動配，分鏡表的音效欄寫「預設」就好；只有要換或拿掉，才在 plan.json 的那一段寫 `sfx`。

| 事件 | 音效 | 預設配給哪些情境 |
|---|---|---|
| 字卡揭開 | `pop.wav` | 05、06、08–15 |
| 條列逐條、步驟切換 | `tick.wav` | 03、04a–d、05、08、12、13（附加） |
| 側邊欄推入、角標滑入 | `swipe.wav` | 02、03 |
| 章節轉場、全畫面幕 | `whoosh.wav` | 01、04a–d |
| 講重點、答案揭曉 | `ding.wav` | 07、09 答案（附加） |
| 解法、成果 | `success.wav` | 07 `tone: "good"` |
| 踩坑、注意 | `alert.wav` | 07 `tone: "warn"` |
| 蓋章、重擊 | `impact.wav` | 字卡動態 |
| 翻牌 | `flip.wav` | 字卡動態 |
| 打字 | `type.wav` | 字卡動態 27 |
| 故障 | `glitch.wav` | 字卡動態 34 |
| 鋪墊上升 | `riser.wav` | 字卡動態 17、18、20、21、37 |

- 一張卡最多一個主音效
- 兩個主音效相距不到 3 秒時，只留前一個（附加音效不算），避免音效太密
- 音效音量要比人聲小，不能蓋過講話
- 附加音效（條列每條一顆 `tick`、QA 答案的 `ding`）音量比主音效小，由 build 自動配；不想要就在那段寫 `"sfxExtra": false`
- 從講者切到螢幕錄影的第一段配 `whoosh.wav`；之後連續的錄影段不配
- 個別音效太大聲或太小聲，在剪輯台調那一段的音量（plan.json 的 `sfxVolume`，dB）
