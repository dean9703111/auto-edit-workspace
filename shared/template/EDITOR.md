# 剪輯

「剪輯」是一個在瀏覽器裡用的小工具：輸出成片之前，使用者自己裁剪、調聲音、改字幕和卡片上的文字、設轉場，不用一句一句跟 AI 講。結果寫回 `plan.json` 和 `work/rough.srt`，AI 之後重新產生成片。介面名稱為「剪輯」與「構圖」（舊稱剪輯台、構圖台）。

- 程式：`shared/template/tools/editor.mjs`（頁面在 `shared/template/tools/editor/`）
- 只需要 Node.js 22、ffmpeg／ffprobe；「成片預覽」另外用到 `npx hyperframes` 已經下載過的播放器。不用安裝任何套件，也不連網路。
- `edit` 欄位的格式和 build 怎麼處理它，見 `shared/template/USAGE.md` 第 6 節。

## 一、給 AI

### 1. 什麼時候開

使用者說「打開剪輯台」時，是停點 ⑤（`AGENTS.md`「停點總表」）；流程照 `.agents/skills/auto-edit-review/SKILL.md` 流程 C。給網址時回覆最後一行照停點 ⑤ 的固定格式。

停點 ②（構圖）也用剪輯台：啟動後印的「構圖台」網址（`…/framing`）給使用者，最後一行照停點 ② 的固定格式（`.agents/skills/auto-edit-storyboard/SKILL.md` 步驟 2）。構圖台只要有 `work/rough.mp4`；還沒有 plan.json 時，存檔會新建一個只有 `version`（直式加 `format`）、`frame`（和構圖台調過的 `look`）的 plan.json。

開之前要有：

| 需要 | 沒有時 |
|---|---|
| `work/rough.mp4`（剪乾淨做完） | 頁面會顯示「還沒有影片可以剪」，先完成剪乾淨 |
| `work/hyperframes/plan.json`（分鏡定稿） | 可以看影片，但不能儲存；先寫好 plan.json |
| 跑過一次 build（建議） | 「成片預覽」不能用；使用者在頁面按「重新產生」也可以 |

`work/rough.srt`（字幕軌）和 `work/cutpoints.json`（剪接點）有就會顯示，沒有也能用。

### 2. 啟動、查狀態、關閉

指令一律在工作區根目錄執行：

```bash
node shared/template/tools/editor.mjs --project projects/example
```

- 在非互動的 shell 裡（AI 執行指令就是這種），它會**自己轉到背景**：印出網址就結束，不用加 `&` 或 `nohup`。在終端機裡手動執行則留在前景，按 Ctrl+C 關閉。
- 印出來像這樣，把第一行的網址給使用者，請他用 **Chrome 或 Edge** 打開：

  ```
  剪輯：http://127.0.0.1:4400/
  構圖：http://127.0.0.1:4400/framing
  專案：projects/example
  已在背景執行（log：projects/example/work/hyperframes/.editor/editor.log）。關閉：node shared/template/tools/editor.mjs --stop --project projects/example
  ```

- 已經開著且後端版本相同時不開第二個，會印「剪輯已經開著：網址」。程式已更新時會更新服務並以原 port 重新啟動，避免新版頁面連到舊 API。
- port 預設 4400，被佔用就自動往後找（最多 20 個），**以印出來的網址為準**。要指定就加 `--port 5400`。
- 只接受本機（127.0.0.1）的連線。加 `--open` 會順便用預設瀏覽器打開。

| 要做的事 | 指令 |
|---|---|
| 查剪輯台開著沒、網址是什麼 | `node shared/template/tools/editor.mjs --status --project projects/example` |
| 關掉剪輯台 | `node shared/template/tools/editor.mjs --stop --project projects/example` |
| 看出了什麼錯 | 讀 `projects/<專案>/work/hyperframes/.editor/editor.log` |

### 3. 剪輯台會寫哪些欄位

按「儲存」時只寫下面這些，`plan.json` 其他地方（包括你的排版）一個字都不動：

| 位置 | 欄位 | 內容 |
|---|---|---|
| 第一層 | `look` | 講者調光、瘦臉、美顏 `{ "color": 0–1, "slim": 0–1.2, "beauty": 0–1 }`，color、slim 都寫、beauty 有開才寫（剪輯台「講者」或構圖台下面都能調）；按「恢復預設」整個拿掉。改 `slim` 後按「重新產生」，剪輯台會先跑 `look.mjs run` 再 build；構圖台按「偵測臉部」只在背景跑 `look.mjs run` |
| 第一層 | `frame` | 構圖的裁切框 `[x, y, w, h]`（畫布座標，比例和畫布一樣，最多放大 2 倍）；拖回整個畫面＝拿掉。換框時已經有的 `speakerBox`、`pipCrop`（陣列）會換算成新框裡同一塊畫面（`pipCrop` 換算後出界就改回 `"auto"`），存檔回應的 `notes` 會列出來；已有成片時，儲存自動更新底片和剪輯預覽，不用再按「重新產生」 |
| 第一層 | `theme` | 主題 `"light"`（亮，預設）或 `"dark"`（暗）；屬性面板「主題」的亮／暗。原本沒寫又選亮＝不寫；原本有就原地換值。成片預覽切換時馬上換色看（改播放器裡 `<html data-theme>`），按「重新產生」才進成片 |
| 第一層 `edit` | `cuts` | 剪掉的範圍 `[[起點, 終點], …]`，**rough.mp4 的秒數**；片頭片尾的裁剪是 `[0, t]`、`[t, 影片長度]`；存檔時會排序、合併重疊的範圍 |
| | `fadeIn`／`fadeOut` | 開頭淡入、結尾淡出的秒數（0＝不淡） |
| | `volume.voice`／`.sfx`／`.media` | 人聲（主軌）、全部音效、插入素材原聲的增益，dB（−60～+12；−60＝靜音） |
| | `gains` | 人聲某一段的音量 `[{ "from": 12, "to": 14, "db": 5 }]`，rough.mp4 秒數，疊在 `volume.voice` 上，範圍不重疊 |
| | `joins` | 剪接點的轉場 `[{ "at": 秒, "type": "dip", "dur": 0.3 }, { "at": 秒, "type": "punch" }]`；選「無」的不寫 |
| 任何段（scene／fx／custom／media） | `sfxVolume` | 這段音效的音量（dB），0 就拿掉這個欄位 |
| | `sfx` | 只會寫 `null`（使用者按了靜音）；取消靜音時換回原本的值（記在 `.editor/memory.json`），原本沒寫就拿掉 |
| scene 的 `slots`、fx 的 `vars` | 文字值 | 改字（含清單項目的 `text`、QA 的 `{ "text", "at" }` 裡的 `text`；字數上限照情境的 `max`）；清單只能刪項目、不能加（剪輯台不顯示「新增一項」）。改了字的段，「重新產生」後自動跑 `audit.mjs --only <那幾段>`，✖／⚠ 列在剪輯台檢查清單（`[段] 版面：…`） |
| `work/feedback/editor-requests.md` | 修改單 | 「修改單」按「複製給 AI」時整份覆寫、只寫待改的段（剪貼簿只放一行指令「照剪輯台修改單改這 N 段（<這個檔>）：…」）：每段的 id、動畫是什麼、檔案（自訂動畫、錄影；路徑從工作區根目錄寫起，例 `projects/<專案>/work/hyperframes/compositions/x-….html`）、成片時間、plan.json 起訖、要改的標籤、描述、對應字幕（`#N 文字`）。使用者說「照修改單改」就照 `auto-edit-review` 流程 F 做 |
| `type: "media"` 的段 | `from`／`to`／`in`／`anchor` | 使用者拖邊緣裁剪或整段移動：對到字幕邊界寫 `"#N"`／`"#Ne"` 並把 `anchor` 換成那句的開頭；沒對到寫秒數並拿掉 `anchor`；拖左緣時 `in` 跟著變（畫面內容不跑）；寫了 `to` 就拿掉 `duration` |
| | `enter`／`exit`／`volume` | 進出場（`cut`／`fade`／`slide`／`zoom`）；原聲 `null`（靜音）或 dB |
| `work/rough.srt` | 字幕文字、起訖時間、新增／分割／合併／刪除 | 見下一節 |

- `edit` 每次都整個寫（沒調的欄位寫預設值）；原本沒有 `edit` 時，插在 `scenes` 前面。
- `look`、`theme` 原本沒有時，插在 `edit` 前面（沒有 `edit` 就插在 `scenes` 前面）；兩個都新插時順序是 `look`、`theme`。
- `joins` 的 `at`：使用者剪掉的範圍寫**起點**（`cuts` 的第一個數字）；剪乾淨時的剪接點寫 `work/cutpoints.json` 裡的 `at`。片頭、片尾的裁剪不算剪接點。
- 剪輯台會拒絕其他任何欄位（例如 media 段的 `src`、段落的 `scene`、slots 新增欄位、清單的 `at` 或圖示、第一層的 `format`）。這些請 AI 改；`format` 存檔時原封不動。
- 清單項目變多會被擋（「比原本多（原本 N 項）→ 剪輯台不能加項目」）：要加項目、換動畫、重新排版請使用者寫進修改單。字變長擠壞版面時，重新產生後的 audit 會列在檢查清單。

### 4. 字幕與句號

使用者可以在剪輯台改字幕的字和時間，也可以**新增、分割、合併、刪除**字幕（新增只能放在兩句之間 ≥ 0.5 秒的空檔；分割後兩半各 ≥ 0.3 秒）。句子數量一變：

- `rough.srt` 重新編號 1…N，保留原本的換行格式（CRLF／LF）和 BOM，沒改的句子原封不動。
- `plan.json` 裡**所有時間欄位**（任何物件的 `from`／`to`／`at`／`until`、`beats` 的值、清單項目的 `at`——包含字串寫法的 `｜at=#N`——以及 `#N±秒`）照新句號改寫；`slots`／`vars` 的文字不動（裡面寫了「#1」也一樣）：

  | 操作 | 句號怎麼改 |
  |---|---|
  | 分割第 k 句 | `#k` 不變、`#ke` → `#(k+1)e`、k 之後的全部 +1 |
  | 在第 k 句後新增 | k 之後的全部 +1 |
  | 合併第 k、k+1 句 | `#(k+1)` → `#k+（兩句起點差）`、`#ke` → `#k+（第 k 句長度）`、`#(k+1)e` → `#ke`、k+1 之後的全部 −1（時間點不變） |
  | 刪除第 k 句 | 有時間綁著它時，使用者先選改綁前一句（`#(k−1)`、`#(k−1)e`）或後一句；之後 k 之後的全部 −1 |

- 起點那句的 `anchor` 本來對得上、改完對不上時，換成新起點那句的開頭幾個字。
- `rough.srt` 和 `plan.json` **一起寫**（兩個都先寫暫存檔再改名）；任一個被改過就兩個都不寫。
- 增刪之後 `work/storyboard.md` 裡的句號會過期，**以 `plan.json` 為準**。

### 5. 跟剪輯台一起改 plan.json 與字幕

- 剪輯台存檔前會比對 `plan.json` 和 `work/rough.srt`：從頁面載入之後**任一個被改過**（通常是 AI 改的），就兩個都不存，跳出「檔案被改過了」讓使用者選「重新載入，保留我的調整」或「放棄我的調整」（字幕檔被改過時，還沒存的字幕修改要重做）。所以 AI 改的不會被剪輯台蓋掉。
- AI 要改 `plan.json` 或 `rough.srt` 之前**先重新讀檔**，不要用之前讀到的舊內容整份寫回去，否則會蓋掉使用者在剪輯台存的東西。
- AI 改完不用通知剪輯台：頁面每 2.5 秒檢查一次，使用者沒有未存的調整就自動重新載入，有的話會在上方提示。
- 使用者正在調的時候，AI 不要動 `edit` 和字幕。

### 6. 使用者說「調好了」之後

1. 重新讀 `plan.json`（`edit`、句號、文字可能都變了）和 `rough.srt`。
2. 跑 `node shared/template/tools/build.mjs --project projects/example`，有 ✖ 就照 → 後面的建議修好再跑（使用者在頁面按過「重新產生」而且沒有 ✖，可以略過這步）。
3. 照 `auto-edit-review` 流程 A 抽查（build、audit、`snapshot --review`），再回到停點 ④；使用者說可以才照 `auto-edit-deliver` 輸出。有裁剪時，成片長度＝初剪長度 − 剪掉的範圍。
4. 關掉剪輯台（`--stop`）。不關也沒關係，下次「打開剪輯台」會沿用同一個。

### 7. 兩種預覽與自動降級

| 模式 | 播什麼 | 什麼時候能用 |
|---|---|---|
| 即時模擬 | `work/hyperframes/assets/rough.mp4`（沒有就 `work/rough.mp4`），在瀏覽器裡即時套上目前的設定：跳過剪掉的範圍、各軌音量與人聲範圍音量、淡入淡出、過黑、放大、插入素材的進出場與原聲（示意）、音效（照檢查報告的時間播 `shared/sfx/`）、字幕文字 | 一律可以用（預設） |
| 成片預覽 | 用 HyperFrames 播放器 `<hyperframes-player>` 播 `work/hyperframes/index.html`＝上一次 build 的完整成片 | 找得到播放器，而且 build 過 |

直式專案（版式和 build 同一套判斷：plan.json `"format"` ＞ `work/製作進度.md`「版式」列 ＞ 主軌寬高比；`/api/state` 的 `canvas` 寫著結果與來源，數字都來自 `tools/lib/canvas.mjs`）：

- 預覽框是 9:16（`editor.css` 的 `--cw`／`--ch`）；講者框照 1080×1920 的座標畫，安全框照比例畫；即時模擬的講者小窗是下半的講者面板（`pip.box`），字幕高度照 `caption.bottom`，樣式照樣是 `kit/captions.css`。
- 字數提醒用 `caption.maxChars`：直式超過 10 字標紅（橫式 18 字）；縮圖條每格 90×160。
- 剪輯台不寫 `format`；要換版式請 AI 照 AGENTS.md「版式」改。
- **上半面板的 host 不要在 Studio 移動**：Studio 的 Inspector 顯示的是沒縮放的 1920×1080，拖動會寫 host 的 transform、蓋掉直式的舞台縮放；位置或內容要改，就改子合成（`compositions/…`）或 plan.json 再 build。

- 播放器的找法：用工作區 `node_modules/hyperframes` 那一份（根目錄 `package.json` 釘的版本，和 render 同一版），複製到 `work/hyperframes/.editor/player/`；版本換了（升級或降級）會重新複製。不去 npx 快取挑最新版，免得預覽和 render 出來的不一樣。
- **找不到播放器時自動退回「即時模擬」**：「成片預覽」按鈕變灰，滑鼠移上去會寫原因。要恢復：在工作區根目錄跑 `npm install`，再 `--stop` 後重新啟動剪輯台。
- 存檔後頁面會跑 `build.mjs --check --json` 取得段落位置、音效時間、只有聲音的區間、剪接點；跑不出 JSON 時退回讀文字報告（看得到段落位置，音效與只有聲音的區間要等報告恢復）。
- 即時模擬的調光是 CSS 濾鏡近似（`brightness`／`contrast`／`saturate`），和成片的 LUT 不完全一樣，臉部很接近、牆面偏差較大；以成片預覽或 `work/look-preview.jpg` 為準。瘦臉沒有即時預覽，看屬性面板的「前／後」兩張臉。

### 8. 常見問題

| 狀況 | 處理 |
|---|---|
| 使用者說網頁打不開 | `--status` 看有沒有開、網址對不對；沒開就重開；還是不行看 `.editor/editor.log` |
| 構圖動畫不出現，出現 `Unexpected token '找'` 或舊版服務提示 | 新頁面連到尚未更新的後端，`/api/design` 回純文字 404。重新跑 `node shared/template/tools/editor.mjs --project projects/<專案>`，工具會比對版本並更新服務；構圖按「重新連接」可保留拖好的框，舊頁面沒有按鈕時重新整理。 |
| 「port 4400–4419 都被佔用了」 | 加 `--port 5400`（或其他沒在用的數字） |
| 儲存時說檔案被改過 | 正常的保護。請使用者按「重新載入，保留我的調整」，再按一次儲存 |
| 儲存被拒絕（左下角檢查清單寫「沒有存成功」） | 通常是 AI 手寫的 `edit` 有超出範圍的值（例如音量 +20），或字幕時間重疊。照訊息改，請使用者重新整理頁面 |
| 成片預覽的說明列寫「⚠ 之後又改過」 | `plan.json` 在上次 build 之後改過，按「重新產生」 |
| 「重新產生」失敗，說 index.html 被手改過 | build 的手改保護。照訊息把改動搬進 `plan.json`，或確認可以覆寫後由 AI 加 `--force` 跑 build |
| 重新剪乾淨、換了 rough.mp4 | 重新整理頁面就好，波形與縮圖會重算 |
| 「重新產生」很久，訊息停在「偵測臉部」或「套用瘦臉」 | 改了瘦臉強度或 rough.mp4 換過，剪輯台先跑 `look.mjs run`（長片要幾分鐘）。等它跑完；想先看別的，請使用者把瘦臉關掉（`slim` 0）就不用等 |
| 「講者」的臉部對照寫「還沒偵測臉部」 | 跑 `node shared/template/tools/look.mjs run --project projects/<專案>`，跑完重新整理頁面 |
| `.editor/` 是什麼 | 剪輯台的快取：波形、縮圖、播放器複本、音效靜音前的值（`memory.json`）、狀態檔、log。在 `work/` 底下、不進 git，刪掉會自動重建（刪 `memory.json` 只會讓「取消靜音」改成恢復情境預設音效） |

剪輯台不會 render、不會改 `assets/` 和 `shared/`，也不會改上面表格以外的任何東西。

## 二、給使用者

### 怎麼打開

跟 AI 說「打開剪輯台」。AI 會給你一個網址（像 `http://127.0.0.1:4400/`），用 **Chrome 或 Edge** 打開。調好按「儲存」，回到 AI 那邊說「調好了」。第一次打開會有一張簡短的操作提示。

```
├ 時間軸（軌頭可以調音量、靜音 M、鎖定 🔒）                                              │
│   動畫　　　資訊卡（藍）、字卡動態（紫）                                                │
│   插入素材　螢幕錄影與圖片，黃線＝原聲音量                                              │
│   主軌畫面　縮圖、剪掉的範圍、剪接點的轉場（菱形）、只有聲音的區間（斜線）              │
│   字幕　　　每一句字幕                                                                  │
│   人聲　　　聲音波形，黃線＝人聲音量                                                    │
│   音效　　　每一顆音效                                                                  │
└ 狀態列：✖ 錯誤 ⚠ 提醒（點開看清單）｜成片長度｜縮放 ──────────────────────────────────┘
```

- **點時間軸上的東西**，右邊「屬性」就顯示它能改的地方；點空白處＝整支影片的設定（講者調光、瘦臉、美顏、淡入淡出、各軌音量、人聲標準化、轉場、剪掉的範圍）。
- **儲存狀態**：綠點「已儲存」；黃點「有修改還沒儲存」（沒按儲存就不會寫進去，關掉分頁前會提醒你）。
- **時間碼**：「時:分:秒:格」（一秒 30 格）。點一下可以打時間跳過去（例如 `1:23` 或 `00:01:23:10`）。後面的「成片」是扣掉剪掉的範圍之後的位置。

### 兩種預覽

- **即時模擬**（預設）：播初剪影片，把你現在的設定直接套上去看，還沒存也聽得到、看得到（剪掉的範圍會跳過、音量、音效、淡入淡出、轉場、插入素材的示意；插入素材放在和成片一樣的位置，橫式在字幕帶上方）。沒有資訊卡和字卡動態：只有聲音的段畫面中間會寫是哪一段，請切到成片預覽看。
- **成片預覽**：播上一次「重新產生」的完整成片。改了卡片文字，存檔後會自動重新產生，好了自動切過來停在那一段。上方說明列出現「⚠ 之後又改過」就表示要重新產生。
- 這個按鈕是灰的：滑鼠移上去會說原因（還沒產生過成片，或電腦裡找不到 HyperFrames 播放器）。只用「即時模擬」也能把剪輯調完。
- 「安全框」：重要的字放在黃框裡，手機、電視都不會被切到。「講者框」：卡片不要擋到藍色虛線框（講者的位置）。

### 裁剪

- **片頭、片尾**：把主軌畫面最左、最右的白色把手往裡拖，就裁掉開頭或結尾。
- **中間剪一段**：播放頭移到要剪的開頭按 **B**（切一刀），移到結尾再按 **B**，點中間那段按 **Delete**。也可以在主軌或人聲上**拖曳選範圍**（或用 **I**、**O** 設入點和出點），再按 **Delete**。
- 剪掉的範圍是紅色斜線，播放時會跳過。拖紅色範圍的左右邊緣可以微調；點一下紅色範圍再按 Delete＝恢復。
- **插入素材**（螢幕錄影、圖片）：滑到左右邊緣變成 ↔ 時拖曳＝裁剪（拖左緣時畫面內容不會跑掉），拖中間＝整段移動。拖到字幕的開頭或結尾會吸過去。拖的時候游標旁邊會寫新的時間和長度變化，預覽停在你拖的那一格。素材不夠長、或短於 1 秒時會拖不動。
- 剪錯了按 ⌘＋Z（Windows 是 Ctrl＋Z）復原。

### 聲音

- **整條軌**：軌頭的數字就是那條軌的音量（dB，0＝原本的音量），可以直接打數字；**M**＝靜音（成片也不會有這條軌的聲音）。
- **人聲**：人聲軌上的黃線上下拖＝整條人聲變大聲／變小聲。只想調某一段：先在人聲軌拖曳選範圍，再拖範圍裡的黃線（或按屬性裡的「調整這段人聲音量」）。
- **人聲標準化**：點時間軸空白處，按「人聲標準化（−14 LUFS）」，會量整支人聲的響度（剪掉的範圍不算），自動把人聲調到 YouTube 常用的音量，並寫出量到多少、調了多少。
- **音效**：音效軌上每一顆是一個音效。點一下看屬性；上下拖＝調這段的音效大小；雙擊或按 Delete＝靜音，再按一次＝還原成 AI 原本放的音效。
- **插入素材的原聲**：素材上的黃線，拖到最下面＝靜音；或在屬性勾「保留原聲」。
- **音量表**（預覽右邊）：播放時看音量，超過 0 dB 亮紅燈＝會爆音。人聲軌頭出現紅色「!」也是可能爆音的提醒。

### 講者（調光、瘦臉、美顏）

點時間軸空白處，右邊「屬性」最上面是「講者」：

- **調光**：開關＋強度（0–1，預設關；開了建議 0.80＝剪映 80）。拖的時候畫面馬上變（是近似效果，成片會更準）。
- **瘦臉**：開關＋強度（0–1.2，預設關；開了建議 0.60＝剪映 60）。下面兩張是「目前這一格」的臉，左邊原本、右邊套用後（瘦臉＋美顏），滑桿放開就更新；格子大小固定，新圖到之前留著上一張。臉太小或偵測不到時會寫原因。
- **美顏**：開關＋強度（0–1，預設關；開了建議 0.50）。磨皮、膚色提亮、淡化黑眼圈，越往右越明顯；即時模擬看不到，看下面「後」那張臉。
- **恢復預設**：回到每支影片共用的設定（`shared/template/kit/look.json`）。
- 改了瘦臉或美顏要按「重新產生」才會套進成片；長片第一次要幾分鐘（右下角會顯示「偵測臉部」「套用瘦臉」的進度）。只改調光很快。

### 構圖（講者要不要放大、往哪裡放）

上方的「構圖」會另開一個分頁（網址最後是 `/framing`）：

- **左邊**：沒裁切的初剪影片，上面一個鎖定比例的框（橫式 16:9、直式 9:16）。拖框移動、拖四個角縮放；方向鍵微調，按住 Shift 一次 20px。橘色虛線是講者的動作範圍（手勢會到的地方）。
- **右邊**：成片看起來的樣子，套上字幕、下方字卡、子母畫面小窗的位置；直式多兩條青線（頭頂要在中間）和一條洋紅線（下巴不超過）。
- **下面的數字**：放大幾倍、來源每個像素被放大幾倍（超過 3.5 倍會明顯變糊）、有沒有切到手勢；不合的會標紅。
- **建議的框**：工具算的，不切到手勢、不會太糊的倍率裡最大的。**原畫面**：不裁切。
- **下方動畫預覽**：目前播放頭的畫面（含裁切與調光）直接套進同頁動畫，不用先儲存或另開分頁。預設顯示六個範例，可依「情境動畫／版型／字卡」篩選、展開全部或點開同頁大預覽。直式只顯示已有直式版本的動畫。
- **主色與背景**：在構圖下方選主色、輸入色碼。背景按「全畫面／側邊欄／章節」分三張，同類動畫共用；每張都能上傳 JPG、PNG、WebP（12 MB 以內），自動裁切並放進動畫預覽。這些都是本集草稿，還沒改成片。
- 參考圖與背景圖都可拖拉圖片檔到上傳區，也可點選上傳；每次一張，JPG／PNG／WebP、12 MB 以內。拖入時會高亮，放開即上傳；鍵盤可用 Enter／空白鍵開啟選檔。
- **用 AI 生成背景**：選主色、放參考圖、選設計風格並補描述，按「複製生圖指令」。可依參考圖／描述，或選科技線稿、編輯平面、紙雕拼貼、幾何 3D、自然實景。A／B／C 在同一套風格中改變結構、造型或材質，各含全畫面、側邊欄、章節，共 9 張；不再以低對比、模糊光暈作預設。沒有指定方向或參考圖時，三組分別採科技線稿、編輯平面、立體幾何。頁面本身不呼叫 AI。剪貼簿不可用時展開指令供手動複製。
- **對應資料夾**：`work/design/requests/<需求編號>/` 保存 `request.md`、`request.json`、參考圖副本；AI 將三組圖片分別存進 `A/`、`B/`、`C/`，每組各有 `bg-fs.png`、`bg-side.png`、`bg-ch.png`（也接受 JPG／WebP）。原檔與歷次需求保留。
- 相同設定重複複製沿用原需求資料夾，改主色、參考圖或風格時才建立新一份。重開頁會還原風格描述，已保存的指令仍可查看、複製。
- **選圖替換**：背景區選全畫面／側邊欄／章節，再點「原本背景」或 A／B／C 圖片替換、立即預覽。「原本背景」固定保留，尚未生成時也能選；指目前風格包或共用模板的原背景，僅還原該類圖片，保留主色與其他類選圖。三類可分別混搭。切回頁面自動讀取新圖，也可按「載入圖片」。選擇記錄在該需求的 `selection.json`；最後按「儲存並套用」。缺圖或壞圖不取代原背景。
- **預覽播放**：構圖頁與完整情境庫預設顯示內容出齊、退場前的完成畫面；滑鼠移入時持續循環播放，移開回完成畫面。點擊構圖頁預覽可放大並播放，也可按「重播」。側邊欄使用實際資訊卡、字幕與右移講者的合成預覽。
- 可移除參考圖、還原已套用的設定。上方「儲存並套用」固定在頁首，捲到動畫區也能直接確認。
- **講者調光、瘦臉、美顏**（右邊下面，預設關閉）：勾選或拖滑桿，右邊的畫面馬上套調光（近似效果）。美顏＝磨皮＋膚色提亮＋淡化黑眼圈（建議 0.50）。瘦臉、美顏要先偵測整支影片的臉：勾選後按「偵測臉部（會先儲存）」，在背景跑（長片十幾分鐘，可以繼續拖框），跑完下面出現播放頭那一格的前後對照。
- **用這一格當預覽參考圖**（左邊下面）：把播放頭這一格（照框裁切、套調光）存成 `shared/template/preview/speaker-local.jpg`（直式 `speaker-v-local.jpg`），情境庫、風格預覽頁的講者改用它；換一格再按一次就更新。這張是你自己的畫面，不進版控、不上官網。
- 看過同頁動畫後，按「儲存並套用」確認構圖、主色和背景。frame／look 寫入 plan.json；本集風格與上傳／生成圖保存在 `work/design/`（`state.json`、`drafts/<id>/`、`uploads/`），`applied.json` 記錄確認的版本，build 讀這份使用本集設定。共用模板與原素材不改，歷次草稿保留。已有成片會自動更新剪輯預覽；還沒有成片只存設定。
- 流程是同頁調構圖、選主色／上傳或生成背景、看動畫 → 儲存並套用 → 分鏡／動畫製作 → 剪輯與成片預覽。需要讓每一集共用整套風格時，再用風格包流程。

### 字幕

- **改字**：雙擊字幕直接改，按 Enter 完成；或點一下在右邊改（會顯示字數，超過 18 字有 ⚠；直式影片是 10 字）。
- **改時間**：拖字幕的左右邊緣，或在右邊輸入開始、結束時間。字幕不能重疊。
- **分割**：播放頭移到要切開的地方，在右邊文字框把游標點在要切的字，按 **B**（或「分割」）。
- **合併**：「與下一句合併」。
- **新增**：只能放在兩句之間至少 0.5 秒的空檔：在字幕軌的空檔雙擊，或用「＋ 新增」。
- **刪除**：選字幕按 Delete。如果有卡片或插入素材綁在這句，會先問你要改綁到前一句還是後一句。
- 按鈕是灰的時候，滑鼠移上去會說為什麼不能用（例如「只有 0.20 秒空檔」）。
- **尋找與取代**（⌘／Ctrl＋F）：一次修正整集重複的錯字。
- 卡片和插入素材是跟著字幕句號出現的，增刪字幕時它們會自動跟著改，不會跑掉。

### 卡片上的文字

點資訊卡或字卡動態，右邊會列出它的文字欄位（每欄寫著字數／上限，超過上限顯示 ✖）。清單只能刪項目，不能新增。標「可強調」的欄位可以用 `**詞**` 套主色、用 `//` 換行。在成片預覽裡打字，畫面上那段的字會跟著換（播放頭不在那段就跳到它的完成態；還沒有逐字動畫，即時模擬沒有卡片看不到）。存檔後會自動重新產生、量那一段的版面，完成後切到成片預覽停在那一段；版面有問題會紅字列在左下角檢查清單（改短一點或改回原本的字）。要加項目、換動畫、重新排版，寫進修改單。

### 修改單（想讓 AI 重做哪幾段）

按上方「修改單」（或屬性面板的「✎ 寫進修改單」），最右邊會多一欄修改單（屬性面板還在，預覽變窄）：

1. 在時間軸點一段動畫或螢幕錄影，修改單上方會列出它的 id、動畫是什麼、成片時間和這段的字幕。
2. 點想怎麼改（例如「流程更細節」「以圖像展示為主」「文字少一點」「換一種動畫」；錄影段是「標註更清楚」「推近到操作區」「換成動畫」…），或在下面自己寫。點了、打了就存進修改單，不用按儲存；標籤和描述都清掉＝拿掉這段。
3. 換下一段，一直累積；下面的清單分「待改」「已改完」兩組，「↗」跳回那段、「✕」拿掉。時間軸上那段的右端會標 ✎（待改）或 ✓（已改完）。
4. 按「複製給 AI（N 段待改）」：只送待改的段，存到 `work/feedback/editor-requests.md`，剪貼簿放一行指令（「照剪輯台修改單改這 N 段（檔案路徑）：…」）。貼給 AI，或直接跟 AI 說「照修改單改」。AI 會直接改（每段一個子代理一起做），改好停在 Studio 預覽給你看。送出後清單上那段標「已送出」。
5. AI 改完（讀 `work/feedback/r<N>.md`「改了哪幾段」），那段移到「已改完」、列出 AI 做了什麼；按「▶ 看結果」切到成片預覽、跳到那段開頭。已改完的段再點標籤或改描述，就變回待改，下次複製會再送。

修改單存在這個瀏覽器裡，關掉分頁再打開還在；改完想重寫就按「清空修改單」（要按兩次）。

### 轉場

剪接點＝畫面跳接的地方：你剪掉的範圍，加上 AI 剪乾淨時剪掉 NG、停頓的地方（主軌上緣的菱形）。點菱形在右邊選：

- **無**：直接接。
- **過黑**：畫面很快變黑再亮起來，適合換段落；可以設長度（預設 0.3 秒）。
- **放大**：接點之後畫面放大一點（1.08 倍），到下一個剪接點恢復。講話中間的跳接用它比較不突兀。
- 點時間軸空白處，「轉場」可以一次全部設成無、全部過黑，或「交替放大」（一近一遠）。

### 儲存、重新產生、檢查

- **儲存**（⌘／Ctrl＋S）：寫進 `plan.json` 和字幕檔，存完會自動檢查。
- **重新產生**：讓成片預覽更新成最新的設定（沒存的會先存）。右下角會顯示進度，不會擋住你繼續看。
- **左下角 ✖／⚠**：檢查結果。點開看清單，點任一則會跳到那一段並選起來。✖ 錯誤要先改好才能產生成片；看不懂的直接整段貼給 AI。
- 如果跳出「檔案被改過了」：表示 AI 剛改了它。按「重新載入，保留我的調整」，再按一次儲存。

### 想改更多？

卡片的版型、位置、時間，插入素材換檔、運鏡、紅框，寫進修改單或直接跟 AI 說（例如「s05 的金句卡往左移」）。想逐格看卡片、或在畫面上點選某張卡請 AI 改，請 AI 開 HyperFrames Studio。
