# 剪輯

「剪輯」是一個在瀏覽器裡用的小工具：輸出完成影片之前，使用者自己裁剪、調聲音、改字幕和卡片上的文字、設轉場，不用一句一句跟 AI 講。結果寫回 `plan.json` 和 `work/rough.srt`，AI 之後重新產生完成影片。

- 程式：`shared/template/tools/editor.mjs`（頁面在 `shared/template/tools/editor/`）
- 只需要 Node.js 22、ffmpeg／ffprobe；「完成影片預覽」另外用到 `npx hyperframes` 已經下載過的播放器。不用安裝任何套件，也不連網路。
- `edit` 欄位的格式和 build 怎麼處理它，見 `shared/template/USAGE.md` 第 6 節。

---

## 一、給 AI

### 1. 什麼時候開

使用者說「打開剪輯台」時，是停點 ⑤（`AGENTS.md`「停點總表」）；流程照 `.agents/skills/auto-edit-review/SKILL.md` 流程 C。給網址時回覆最後兩行照停點 ⑤ 的固定格式。

停點 ①（剪輯清單 `…/cuts`）、②（構圖台 `…/framing`）、③（分鏡表 `…/storyboard`）、④（完成影片預覽 `…/?view=final`）和初剪完成的「字幕預覽」（不是停點）也是這個剪輯台的頁面：網址由工具印，照那一步的 Skill 貼給使用者，不用另外跑 `editor.mjs`（打不開才跑 `editor.mjs --status`）。檔案被 AI 改過時，頁面會擋下存檔並重新載入。

開之前要有：

| 需要 | 沒有時 |
|---|---|
| `work/rough.mp4`（剪乾淨做完） | 頁面會顯示「還沒有影片可以剪」，先完成剪乾淨 |
| `work/hyperframes/plan.json`（分鏡定稿） | 可以看影片，但不能儲存；先寫好 plan.json |
| 跑過一次 build（建議） | 「完成影片預覽」不能用；使用者在頁面按「更新預覽」也可以 |

`work/rough.srt`（字幕軌）和 `work/cutpoints.json`（剪接點）有就會顯示，沒有也能用。

### 2. 啟動、查狀態、關閉

指令一律在工作區根目錄執行：

```bash
node shared/template/tools/editor.mjs --project projects/<專案>
```

- 在非互動的 shell 裡（AI 執行指令就是這種），它會**自己轉到背景**：印出網址就結束，不用加 `&` 或 `nohup`。在終端機裡手動執行則留在前景，按 Ctrl+C 關閉。
- 印出來像這樣，把第一行的網址給使用者，請他用 **Chrome 或 Edge** 打開：

  ```
  剪輯：http://127.0.0.1:4400/
  剪輯清單：http://127.0.0.1:4400/cuts
  構圖：http://127.0.0.1:4400/framing
  分鏡表：http://127.0.0.1:4400/storyboard
  完成影片預覽：http://127.0.0.1:4400/?view=final
  專案：projects/<專案>
  已在背景執行（log：projects/<專案>/work/hyperframes/.editor/editor.log）。關閉：node shared/template/tools/editor.mjs --stop --project projects/<專案>
  ```

- 已經開著且後端版本相同時不開第二個，會印「剪輯已經開著：網址」。程式已更新時會更新服務並以原 port 重新啟動，避免新版頁面連到舊 API。
- port 預設 4400，被佔用就自動往後找（最多 20 個），**以印出來的網址為準**。要指定就加 `--port 5400`。
- 同時剪好幾支影片：每個專案各跑一次上面的指令，各開各的剪輯台、各佔一個 port。`projects/` 底下開著兩個以上時，每一頁（剪輯、剪輯清單、構圖、分鏡表）頁首的專案名稱自己變成「切換影片」的按鈕（右邊多一個小箭頭，點了在下面展開清單），不用另外設定；給使用者的網址照舊是那個專案印出來的那一個。
- 第一次打開的提示卡按掉後記在 `shared/setting.json` 的 `editor.seen`，這台機器所有專案共用。
- 只接受本機（127.0.0.1）的連線。加 `--open` 會順便用預設瀏覽器打開。

| 要做的事 | 指令 |
|---|---|
| 查剪輯台開著沒、網址是什麼 | `node shared/template/tools/editor.mjs --status --project projects/<專案>` |
| 關掉剪輯台 | `node shared/template/tools/editor.mjs --stop --project projects/<專案>` |
| 看出了什麼錯 | 讀 `projects/<專案>/work/hyperframes/.editor/editor.log` |

### 3. 剪輯台會寫哪些欄位

頁面停手一秒就自動存（切走分頁、關分頁時馬上存；⌘／Ctrl＋S 也可以），只寫下面這些，`plan.json` 其他地方（包括你的排版）一個字都不動：



| 位置 | 欄位 | 內容 |
|---|---|---|
| 第一層 | `look` | 講者調光、瘦臉、美顏、瘦小腹 `{ "color": 0–1, "slim": 0–1.2, "beauty": 0–1, "belly": 0–1 }`，color、slim 都寫、beauty 與 belly 有開才寫（剪輯台「講者」或構圖台下面都能調）；按「恢復預設」整個拿掉。改 `slim`、`beauty`、`belly` 後按「更新預覽」，剪輯台會先跑 `look.mjs run` 再 build；構圖台按「偵測臉部」只在背景跑 `look.mjs run` |
| 第一層 | `frame` | 構圖的裁切框 `[x, y, w, h]`（畫布座標，比例和畫布一樣，最多放大 2 倍）；拖回整個畫面＝拿掉。換框時已經有的 `speakerBox`、`pipCrop`（陣列）會換算成新框裡同一塊畫面（`pipCrop` 換算後出界就改回 `"auto"`），存檔回應的 `notes` 會列出來。構圖頁自動存檔（`/api/framing/save` 帶 `update: false`）不帶起更新，已有完成影片時頁面顯示「更新預覽」，按了才重新處理底片（`/api/framing/update`）；沒帶 `update: false` 的呼叫照舊自動更新 |
| 第一層 | `theme` | 主題 `"light"`（亮，預設）或 `"dark"`（暗）；屬性面板「主題」的亮／暗。原本沒寫又選亮＝不寫；原本有就原地換值。完成影片預覽切換時馬上換卡片的顏色看（改播放器裡 `<html data-theme>`）；背景圖（`bg-*-dark.jpg`）是 build 寫在 index.html 的，所以改了主題「更新預覽」照樣發光，按了才進完成影片 |
| 第一層 | `captionStyle` | 這一集的字幕樣式 `{ "look", "font", "size", "weight", "lift" }`（五個都寫）；屬性面板「整支 → 字幕」的樣式、字體、大小、粗細、上下位置，「回到原本的樣子」寫回深底白字、原位那一組（不拿掉，所以預設改了也不會套到這一集）。上下位置也可以在預覽畫面上直接拖字幕（`#capDrag`：2 px 一格、離原位 12 px 內吸回原位；方向鍵 ±2、Shift ±10；雙擊回原位；Esc 取消拖曳），放開才進復原清單。勾「之後的影片也用這個」（預設勾）時同時寫 `shared/setting.json` 的 `captions`（`/api/caption-default`，帶 `format`：位置只記這個版式的 `lift.landscape` 或 `lift.portrait`，另一個不動）。快速預覽、完成影片預覽馬上換（改字幕圖層的 `data-cap` 與 `--cap-*` 變數），不用按「更新預覽」（不發光），輸出時一起做進去 |
| 第一層 | `captionMarks` | 重點字幕的句號 `["#6", "#7", "#13"]`：這幾則字幕改用重點樣式（主色底、粗體），其他照整支的字幕樣式。在「字幕」分頁點每一句右邊的「重點」（實心＝重點，那一列左邊一條主色）、選到字幕時屬性面板的「重點字幕」，或按 H（選到的那一句；沒選就是播放頭所在的那一句）；上面的「重點 N 則」按下去只看重點字幕。每次整份重寫（照句號排），都取消就拿掉這個欄位；不在字幕裡的句號不寫。AI 寫的 `"#N@詞"`（只標那一則裡的幾個字）剪輯台不會動到：存檔時照留、增刪字幕時跟著換句號，但還不能在剪輯台新增或取消，要改請告訴 AI。快速試聽、完成影片預覽馬上換樣式（切換那一則的 `cg--em`），不用按「更新預覽」（不發光），輸出時一起做進去（上次 build 之後改過字的那幾則不動，改字本身就要更新預覽）；`"#N@詞"` 改了照樣要更新預覽；時間軸字幕軌上緣有一條主色的就是重點字幕 |
| 第一層 `bed` | `volume` | 背景音樂（底樂）的音量，dB（−40～+6，一格 1；0＝曲庫檔原本的音量，拿掉這個欄位；−40＝靜音，完成影片不放）：屬性面板「整支 → 聲音 → 背景音樂」、時間軸「背景音樂」軌的軌頭（數字、喇叭＝靜音），點這一軌也會跳到滑桿。檢查規則和 `build.mjs --set bed.volume` 一樣：plan.json 沒寫 `bed`（用工作區預設的底樂）時曲名一起寫進 `bed.music`；這一集沒有底樂或寫了 `"music": null` 時滑桿是灰的、不會寫。剪輯台不換曲子（換曲、不配請 AI 用 `--set bed.music`）。快速試聽、完成影片預覽拖的時候都馬上聽得到（只補現在和上一次 build 做進去的差），輸出時（或按「更新預覽」）才重混進 wav |
| 第一層 `ending` | `motion` | 片尾金句的文字動畫：打字機（`type`，預設）、淡入（`fade`）、逐行浮出（`rise`）、由左擦開（`wipe`）、直接出現（`none`）。點時間軸上的片尾卡，屬性面板的「文字動畫」下拉選單。原本寫的 `quote`、`subscribe` 照留；選的和工作區預設（`shared/setting.json` 的 `ending.motion`）一樣就不寫，`ending` 空了整個拿掉；這一集 `"ending": false` 時不能改 |
| 第一層 `ending` | `quote`、`x`、`y`、`size`、`w`、`lineSpacing`、`gap` | 082 片尾金句的字（屬性面板的文字框，照打的存：有換行＝一段一塊，標點照留，一段太長照框寬自動換行；清空＝`null`，這一集不放）、框寬（`w`，px；沒寫＝580 跟著字級等比例）、行間距（`lineSpacing`，剪映的單位：行高＝字級 ×（1.448＋行間距），預設 0.07＝73 px）、段落間距（`gap`：段與段之間空幾行，0–2，取到 0.05，預設 1 不寫）、金句框左上角（畫布 px）、字級（24–120 px，框寬和行距等比例跟著變）。位置、字級、框寬在預覽畫面上拖金句框（右邊＝框寬、右下角＝放大縮小）、方向鍵微調；和預設（1300、575、48）一樣的鍵不寫。位置、字級、框寬、段落間距直接套進完成影片預覽（不用更新預覽）；改字要更新預覽，文字動畫才照新的字排 |
| 第一層 `edit` | `cuts` | 剪掉的範圍 `[[起點, 終點], …]`，**rough.mp4 的秒數**；片頭片尾的裁剪是 `[0, t]`、`[t, 影片長度]`；存檔時會排序、合併重疊的範圍 |
| | `fadeIn`／`fadeOut` | 開頭淡入、結尾淡出的秒數（0＝不淡） |
| | `volume.voice`／`.sfx`／`.media` | 人聲（主軌）、全部音效、插入素材原聲的增益，dB（−60～+12；−60＝靜音） |
| | `gains` | 人聲某一段的音量 `[{ "from": 12, "to": 14, "db": 5 }]`，rough.mp4 秒數，疊在 `volume.voice` 上，範圍不重疊 |
| | `joins` | 剪接點的轉場 `[{ "at": 秒, "type": "dip", "dur": 0.3 }, { "at": 秒, "type": "punch" }]`；選「無」的不寫 |
| | `level` | 「整支 → 聲音」勾「拉平人聲大小聲」＝`true`，取消就拿掉；按「更新預覽」重新處理底片後才聽得到 |
| | `sfx` | 使用者自己加的音效 `[{ "at": 41.2, "sound": "ding", "db": -3 }]`：`at` 是 rough.mp4 的秒數（那一刻聽到，build 把峰值對齊那一刻）、`sound` 是音效名稱（`shared/sfx` 與 `shared/sfx-local` 裡這台機器有的，不含配樂和工具自動配的秒針）、`db` 是這一顆的音量（−60～+12，0 不寫）、`trimIn`／`trimOut` 是裁掉檔案前段／後段的秒數（拖方塊兩端；0 不寫，裁完至少留 0.1 秒）。照時間排；一顆都沒有就不寫這個欄位。AI 不要動它，也不要因為它去刪別的音效（它不受 3 秒間隔、每分鐘密度的規則限制） |
| | `sfxAdjust` | 使用者拖過、裁過的 AI 音效 `[{ "id": "s05", "shift": 0.4, "trimIn": 0.05, "trimOut": 0.2 }]`：`id` 指哪一顆（段落主音效＝段 id；同一段的其他音效＝`段:名稱`，同名第 2 顆起 `段:名稱:2`；情緒點＝`mood:N`，N 是 `moods` 的第幾個），`shift` 是比原本晚幾秒（rough.mp4 秒數，負的＝早），`trimIn`／`trimOut` 同上。只覆寫那一顆，段落、動畫、情緒點本身不動；全拿掉＝還原。段落的音效拖不出那一段、情緒點拖不出影片，對不到、拖出去、裁太短的 build 印 ⚠ 並略過。照 id 排；沒有就不寫。AI 不要動它；改了那段的動畫或音效之後 build 印「對不到」時告訴使用者 |
| 任何段（scene／fx／custom／media） | `sfxVolume` | 這段音效的音量（dB），0 就拿掉這個欄位 |
| | `sfx` | 使用者換了一顆＝寫音效名稱（那段原本是 `{ "name", "at" }` 就只換 `name`，落點不動）；按了靜音＝`null`；還原成原本的＝換回剪輯台動手之前的值（記在 `.editor/memory.json`），原本沒寫就拿掉。名稱不在這台機器的音效清單裡會被擋 |
| scene 的 `slots`、fx 的 `vars`、模板動畫（`type: "custom"`＋`template`）的 `slots` | 文字值 | 改字（含清單項目的 `text`、QA 的 `{ "text", "at" }` 裡的 `text`；字數上限照情境的 `max`）；清單只能刪項目、不能加（剪輯台不顯示「新增一項」）；模板動畫只能改 `custom/<模板>.fill.json` 標成文字的欄位，圖示、時間、結構和項目數都不能動。改了字的段，按「更新預覽」時自動跑 `audit.mjs --only <那幾段>`，✖／⚠ 列在剪輯台檢查清單（`[段] 版面：…`） |
| `work/feedback/editor-requests.md` | 修改單 | 「修改單」按「複製給 AI」時整份覆寫、只寫待改的段（剪貼簿只放一行指令「照剪輯台修改單改這 N 段（<這個檔>）：…」）：每段的 id、動畫是什麼、檔案（自訂動畫、錄影；路徑從工作區根目錄寫起，例 `projects/<專案>/work/hyperframes/compositions/x-….html`）、完成影片時間、plan.json 起訖、做法（動畫段才有：使用者沒勾「重新設計」＝在現有的動畫上改；勾了＝設計師照 `design.md` 從空白畫布重畫）、要改的標籤、描述、對應字幕（`#N 文字`）。使用者說「照修改單改」就照 `auto-edit-review` 流程 F 做 |
| `work/feedback/learn.md` | 這集的調整紀錄 | 輸出過完成影片之後按「整理這集的調整給 AI」（`POST /api/learn`）時整份重寫，內容和 `node shared/template/tools/versions.mjs learn --project projects/<專案>` 一樣（回饋輪的原話與建議改規則、剪輯台手改、字幕常改的字、改版紀錄）；剪貼簿只放一行指令「照這集的調整紀錄學我的習慣（<這個檔>）：…」。使用者貼上這行就照 `auto-edit-review` 流程 G 做 |
| `work/designs/<段>.md`、那段的動畫檔 | 句號 | 增刪字幕（分割、新增、合併、刪除）或改字時：拍點正本在 `work/designs/` 的段，鏡位腳本「講到」欄的 `#N` 和動畫檔 `P.at`／`P.sfx` 的句號照同一個操作重對，各自先備份 `<檔>.align-<時間>`（照 plan.json 產生的模板動畫不用，下次 build 會跟上）。復原、重做回到存檔前後的版本時，這些檔跟著換回去；存檔之後又被 AI 改過的檔不動，服務印 ⚠ 列出來 |
| `type: "media"` 的段 | `from`／`to`／`in`／`anchor` | 使用者拖邊緣裁剪或整段移動：對到字幕邊界寫 `"#N"`／`"#Ne"` 並把 `anchor` 換成那句的開頭；沒對到寫秒數並拿掉 `anchor`；拖左緣時 `in` 跟著變（畫面內容不跑；有變速、定格的段改寫 `retime`／`hold`，每一區的速度不變）；寫了 `to` 就拿掉 `duration` |
| | `speed`／`hold`／`retime`／`in`／`out` | 畫面速度（屬性的「畫面速度」）。整段同速寫 `in`＋`speed`（0.5–4）；整段定格寫 `hold`；分區或超過 4 倍寫 `retime`（`at` 是 `+秒`，時間沒動的點留原本的寫法，例 `#21@詞`）；互斥的欄位自動拿掉，`out` 只會被拿掉。你寫的 `retime` 也會顯示在這裡，使用者看得到、改得了 |
| | `enter`／`exit`／`volume` | 進出場（`cut`／`fade`／`slide`／`zoom`）；原聲 `null`（靜音）或 dB |
| `work/rough.srt` | 字幕文字、起訖時間、新增／分割／合併／刪除 | 見下一節 |

- `edit` 每次都整個寫（沒調的欄位寫預設值；`sfx`、`sfxAdjust` 一顆都沒有就不寫）；原本沒有 `edit` 時，插在 `scenes` 前面。
- `look`、`theme`、`captionStyle`、`captionMarks` 原本沒有時，插在 `edit` 前面（沒有 `edit` 就插在 `scenes` 前面）；都新插時順序是 `look`、`theme`、`captionStyle`、`captionMarks`。
- `joins` 的 `at`：使用者剪掉的範圍寫**起點**（`cuts` 的第一個數字）；剪乾淨時的剪接點寫 `work/cutpoints.json` 裡的 `at`。片頭、片尾的裁剪不算剪接點。
- 剪輯台會拒絕其他任何欄位（例如 media 段的 `src`、段落的 `scene`、slots 新增欄位、清單的 `at` 或圖示、第一層的 `format`）。這些請 AI 改；`format` 存檔時原封不動。
- 清單項目變多會被擋（「比原本多（原本 N 項）→ 剪輯台不能加項目」）：要加項目、換動畫、重新排版請使用者寫進修改單。字變長擠壞版面時，更新預覽後的 audit 會列在檢查清單。

### 4. 字幕與句號

使用者可以在剪輯台改字幕的字和時間，也可以**新增、分割、合併、刪除**字幕（新增只能放在兩句之間 ≥ 0.5 秒的空檔；分割後兩半各 ≥ 0.3 秒）。句子數量一變：

- `rough.srt` 重新編號 1…N，保留原本的換行格式（CRLF／LF）和 BOM，沒改的句子原封不動。
- `plan.json` 裡**所有時間欄位**（任何物件的 `from`／`to`／`at`／`until`、`beats` 的值、清單項目的 `at`——包含字串寫法的 `｜at=#N`——、整串都是句號的陣列如錄影段的 `clicks`、段落的 `sfx` 物件、第一層的 `outro`、`sections`，以及 `#N±秒`）照新句號改寫；`slots`／`vars` 的文字不動（裡面寫了「#1」也一樣）。使用者不用懂句號：剪輯台不會問改綁哪一句，畫面只說「跟著這句出現的畫面」有哪些段（085）：

  | 操作 | 句號怎麼改 |
  |---|---|
  | 分割第 k 句 | `#k` 不變、`#ke` → `#(k+1)e`、k 之後的全部 +1 |
  | 在第 k 句後新增 | k 之後的全部 +1 |
  | 合併第 k、k+1 句 | `#(k+1)` → `#k+（兩句起點差）`、`#ke` → `#k+（第 k 句長度）`、`#(k+1)e` → `#ke`、k+1 之後的全部 −1（時間點不變） |
  | 刪除第 k 句 | 綁著它的時間留在原本那一刻，寫成比較近的一邊：前一句結尾＋秒數（`#(k−1)e+0.5`）或後一句開頭−秒數；`#k@詞` 的詞在前一句或後一句也有，就改綁那一句（刪掉重複的字幕最常見）；之後 k 之後的全部 −1。`delete` 帶 `bind: "prev"／"next"` 是舊寫法，照舊整個改綁前／後一句 |

- 重點字幕（第一層 `captionMarks`）跟著句號走：分割第 k 句＝兩半都是重點；在第 k 句後新增＝後面的順延；合併第 k、k+1 句＝任一句是重點，合併後就是重點；刪除第 k 句＝標記拿掉（都刪光就拿掉整個欄位）。只標幾個字的（`"#N@詞"`）跟著那幾個字走：分割後留在有那幾個字的那一半，刪掉那一句就拿掉。
- `#N@詞` 跟著詞走：每做一步（分割、新增、合併、刪除、改字），第 N 句已經沒有這個詞、而前一句或後一句只有一句有，就改綁那一句（例：把「要你點頭」從第 25 句改字搬到第 26 句，`#25@要你點頭` → `#26@要你點頭`）。兩句都有就不動。都沒有（字改掉了）：那一句還留著詞的開頭幾個字（≥ 2 字）就綁那幾個字（`#435@剪輯的成` 改字成「剪輯的門檻」→ `#435@剪輯的`），再不行就綁在原本那一刻（`#N+秒`），build 不會因為找不到詞報 ✖。plan.json、鏡位腳本、動畫檔同一套（`editor/subtitles.mjs` 的 `stepRef`）；頁面上一個字一個字打和存檔時一次改完算出來一樣。
- 起點那句的 `anchor` 本來對得上、改完對不上時，換成新起點那句的開頭幾個字。
- `rough.srt` 和 `plan.json` **一起寫**（兩個都先寫暫存檔再改名）；任一個被改過就兩個都不寫。
- 拍點正本在 `work/designs/` 的段（內容設計動畫、手改過的模板動畫、手寫的動畫檔）：鏡位腳本「講到」欄和那支動畫檔的 `P.at` 照同一個操作一起重對（各自先備份 `.align-<時間>`）；`work/storyboard.md` 的動畫分鏡是副本，下次 `--review` 跟著更新。

### 5. 跟剪輯台一起改 plan.json 與字幕

- 剪輯台存檔前會比對 `plan.json` 和 `work/rough.srt`：從頁面載入之後**任一個被改過**（通常是 AI 改的），就兩個都不存，跳出「檔案被改過了」讓使用者選「重新載入，保留我的調整」或「放棄我的調整」（字幕檔被改過時，還沒存的字幕修改要重做）。所以 AI 改的不會被剪輯台蓋掉。檔案被別人改過之後，復原清單會清掉，不會復原回 AI 改之前。
- AI 改完不用通知剪輯台：頁面每 2.5 秒檢查一次，使用者沒有未存的調整就自動重新載入，有的話會在上方提示。
- 使用者正在調的時候，AI 不要動 `edit` 和字幕。

### 6. 兩種預覽與自動降級

| 模式 | 播什麼 | 什麼時候能用 |
|---|---|---|
| 完成影片預覽 | 用 HyperFrames 播放器 `<hyperframes-player>` 播 `work/hyperframes/index.html`＝上一次 build 的完整完成影片；聲音的設定改了直接改播放器裡的音量，其他修改要按「更新預覽」 | 找得到播放器，而且 build 過（這時是預設） |
| 快速試聽 | `work/hyperframes/assets/rough.mp4`（沒有就 `work/rough.mp4`），在瀏覽器裡即時套上目前的設定：跳過剪掉的範圍、各軌音量與人聲範圍音量、淡入淡出、過黑、放大、素材的進出場與原聲（示意）、音效（照檢查報告的時間播 `shared/sfx/`，使用者在 `shared/sfx-local/` 放了同名的就播他的；自己加的照 `edit.sfx`，剛換的那一顆馬上換）、背景音樂（上一次 build 混好的 wav，音量照滑桿補差；換了曲子要等更新預覽）、片尾配樂（上一次 build 烤好的那一段）、片尾卡的示意（影片播完接著走片尾卡那幾秒：黑底、圖、金句照實際時間出來）、字幕文字；沒有字卡和動畫 | 一律可以用（還沒有成品時是預設） |

直式專案（版式和 build 同一套判斷：plan.json `"format"` ＞ `work/製作進度.md`「版式」列 ＞ 主軌寬高比；`/api/state` 的 `canvas` 寫著結果與來源，數字都來自 `tools/lib/canvas.mjs`）：

- 預覽框是 9:16（`editor.css` 的 `--cw`／`--ch`）；講者框照 1080×1920 的座標畫，安全框照比例畫；快速試聽的講者小視窗是下半的講者面板（`pip.box`），字幕高度照 `caption.bottom`，樣式照樣是 `kit/captions.css`。
- 字數提醒用 `caption.maxChars`：直式超過 10 字標紅（橫式 18 字）；縮圖條每格 90×160。
- 剪輯台不寫 `format`；要換版式請 AI 照 `auto-edit-longform`「版式」改。
- **上半面板的位置或內容要改**：改子合成（`compositions/…`）或 plan.json 再 build，不要手改 host 的 transform（會蓋掉直式的舞台縮放）。

- **找不到播放器時自動退回「快速試聽」**：「完成影片預覽」按鈕變灰，滑鼠移上去會寫原因。要恢復：在工作區根目錄跑 `npm install`，再 `--stop` 後重新啟動剪輯台。
- 存檔後頁面會跑 `build.mjs --check --json` 取得段落位置、音效時間、只有聲音的區間、剪接點；跑不出 JSON 時退回讀文字報告（看得到段落位置，音效與只有聲音的區間要等報告恢復）。
- 快速試聽的調光是 CSS 濾鏡近似（`brightness`／`contrast`／`saturate`），和完成影片的 LUT 不完全一樣，臉部很接近、牆面偏差較大；以完成影片預覽或 `work/look-preview.jpg` 為準。瘦臉沒有即時預覽，看屬性面板的「前／後」兩張臉。
- 聲音（音量類的欄位）、字幕樣式、整則的重點字幕改了直接套進完成影片預覽，不用按「更新預覽」；剪段、加刪音效、換曲、`"#N@詞"`、主題、字卡文字照舊要更新預覽；輸出時一律用 plan.json 現在的值重新做。

### 7. 常見問題

| 狀況 | 處理 |
|---|---|
| 使用者說網頁打不開 | `--status` 看有沒有開、網址對不對；沒開就重開；還是不行看 `.editor/editor.log` |
| 構圖動畫不出現，出現 `Unexpected token '找'` 或舊版服務提示 | 新頁面連到尚未更新的後端，`/api/design` 回純文字 404。重新跑 `node shared/template/tools/editor.mjs --project projects/<專案>`，工具會比對版本並更新服務；構圖按「重新連接」可保留拖好的框，舊頁面沒有按鈕時重新整理。 |
| 提示卡按掉了，換一支影片又跳出來 | 那一支的剪輯台還是舊的服務（沒有 `/api/hints`），只能記在瀏覽器裡、一個 port 一份。重新跑 `node shared/template/tools/editor.mjs --project projects/<專案>`，工具會比對版本並更新服務，之後按掉一次就全部記住。`shared/setting.json` 不是合法的 JSON 時也會這樣（寫不進去，剪輯台不會蓋掉它）：告訴使用者那個檔壞了，修好才記得住 |
| 「port 4400–4419 都被佔用了」 | 加 `--port 5400`（或其他沒在用的數字） |
| 跳出「檔案被改過了」 | 正常的保護。請使用者按「重新載入，保留我的調整」，會自動再存 |
| 自動存檔被拒絕（「檢查」分頁寫「沒有存成功」） | 通常是 AI 手寫的 `edit` 有超出範圍的值（例如音量 +20），或字幕時間重疊。照訊息改，請使用者重新整理頁面 |
| 復原時說「更早的步驟回不去了」 | 復原要用的舊檔案版本只存在剪輯服務的記憶體：服務重開過、或改動太多（超過 80 MB）就回不去。不影響現在的檔案 |
| 完成影片預覽旁邊寫「有新修改」、「更新預覽」在發光 | `plan.json` 或字幕在上次 build 之後改過、而且不只聲音、字幕樣式、重點字幕，按「更新預覽」 |
| 完成影片預覽旁邊寫「已即時套用」 | 只改了聲音、字幕樣式或重點字幕，已經直接改了播放器，不用按「更新預覽」；輸出時會一起做進去 |
| 「更新預覽」失敗，說 index.html 被手改過 | build 的手改保護。照訊息把改動搬進 `plan.json`，或確認可以覆寫後由 AI 加 `--force` 跑 build |
| 重新剪乾淨、換了 rough.mp4 | 重新整理頁面就好，波形與縮圖會重算 |
| 「更新預覽」很久，訊息停在「偵測臉部」或「套用瘦臉」 | 改了瘦臉強度或 rough.mp4 換過，剪輯台先跑 `look.mjs run`（長片要幾分鐘）。等它跑完；想先看別的，請使用者把瘦臉關掉（`slim` 0）就不用等 |
| 「講者」的臉部對照寫「還沒偵測臉部」 | 跑 `node shared/template/tools/look.mjs run --project projects/<專案>`，跑完重新整理頁面 |
| 「講者」的瘦小腹對照寫「還沒偵測姿勢」 | 同上（`look.mjs run` 會一起偵測姿勢）。它印 `✖ …pose_landmarker_lite.task 不存在` 時，先告訴使用者要下載約 6 MB 的姿勢模型，同意才跑 `node shared/template/tools/look.mjs ensure --download` |
| 瘦小腹的對照寫「這一格不做瘦小腹」或「這支略過瘦小腹」 | 那一格髖部在畫面外、側身、彎腰或沒偵測到人；整支有兩成以上的格這樣就整支不做（USAGE.md 第 7 節）。換一格看，或告訴使用者這支不適用 |
| `.editor/` 是什麼 | 剪輯台的快取：波形、縮圖、播放器複本、音效靜音或換一顆之前的值（`memory.json`）、「判斷錯了，隱藏」的檢查（`hidden-checks.json`）、狀態檔、log。在 `work/` 底下、不進 git，刪掉會自動重建（刪 `memory.json` 只會讓「取消靜音」改成恢復情境預設音效、換過的音效不能再「還原成原本的」；刪 `hidden-checks.json` 藏起來的檢查會再出現） |

除了使用者按「輸出完成影片」（寫 `output/final.mp4`、`output/test-clips/`、`output/qc/`、`work/render.log`，並在 `work/製作進度.md` 的停點紀錄加一列），剪輯台不會 render；也不會改 `assets/` 和 `shared/`（例外：使用者在確認卡或分鏡表頂端填講者、按掉第一次的提示卡時寫 `shared/setting.json`），或上面表格以外的任何東西。

## 二、給使用者

### 怎麼打開

跟 AI 說「打開剪輯台」。AI 會給你一個網址（像 `http://127.0.0.1:4400/`），用 **Chrome 或 Edge** 打開。每個修改都會自動存，調好回到 AI 那邊說「調好了」。第一次打開會有一張簡短的操作提示，按掉之後就不再出現（開別支影片也一樣）。

### 初剪預覽（字幕疊在畫面上）

初剪完成時，AI 會給你一個「字幕預覽」網址。不用另外輸出影片，打開就能看字幕疊在畫面上；只有聲音的地方是黑屏，字幕一樣看得到，適合一邊聽一邊校對。頁面會開在「字幕」分頁、跟著播放捲動；看到錯字點那一句直接改，按 Enter 就好，會自動存，你改過的 AI 不會改回去。校完不用回報，AI 會接著做。

影片剛做好時可能會看到「影片處理中」，等一下會自動接上，這段時間字幕可以先改。

### 剪輯清單（要剪哪幾段）

剪乾淨列好清單後，AI 會給你網址最後是 `/cuts` 的那一個。每一列是一段 AI 認為要剪掉的地方（重講、卡住），附時間、內容和原因：

- 按 **▶** 聽那一段，前後會多播一點，紅色是會剪掉的部分。按 **聽接起來** 聽剪掉之後順不順（前後各 2 秒）。空白鍵暫停、接著播。
- **勾＝剪掉，取消＝保留**，一勾就存檔，不用按儲存。黃色的列是 AI 不確定的，建議先聽再決定；清單很長時按「只看 AI 不確定的」。沒存到（連不到服務）勾選會還原並提醒。
- 最上面的「需要你決定」是 AI 拿不準的地方，勾選下面的清單就能決定；想改時間或有別的想法，回對話跟 AI 說。勾好回到對話說「可以」（頂列一直寫著）。

### 分鏡表（每段怎麼呈現）

列好分鏡表後，AI 會給你網址最後是 `/storyboard` 的那一個。8 段以上先看**總覽**：每段一張截圖，寫時間和在講什麼，照章分組，一屏看十幾段；點一張打開那一段（有上一段、下一段，按 `[`、`]` 也可以，Esc 回總覽）。想一路捲下去就按「逐段捲動」。

每一段有截圖、呈現方式、畫面文字。每段的截圖就是現在會用的模板畫面；值得專門設計的段會多一行「可以改做內容設計動畫：…」，在「要你決定的事」的「內容設計動畫候選」表打勾才做（每段要多花一些時間），不勾就用截圖上的模板：

- **橘底的字直接改**：那是畫面上會出現的文字，停手就自動存（離開欄位、按 Enter 也會存），按 Esc 取消這次修改。頁首的儲存狀態捲到哪都看得到；沒存到（連不到服務、檔案剛被 AI 改過）時文字留在欄位裡、右下角會提醒，連上後自動補存，還有沒存的字就關分頁會先問。技術細節（綁句、動畫參數、插圖清單）不顯示，一樣留在檔案裡給 AI 用；AI 的備註預設收起來。
- **呈現方式、音效用下拉選單選**：按「看範例」可以先看長什麼樣子。選了別的呈現方式，截圖還是現在的樣子，AI 會在你說「可以」之後照這個重做那一段。
- **不滿意整段**：寫在每段下面的補充說明，例如「這段不要放字卡，想看到兩個畫面對比」。不用懂任何格式。
- **要你決定的事**：同樣的問題合併成一項、白話講，一項一個回答欄（回答了會打勾，你說「可以」時 AI 會照做），也可以在對話裡回覆。「補錄：…」「…待補」這類是提醒，收在「待補的素材和提醒」，不算要決定的事。AI 自己能決定的收在「給 AI 的備註」，不用回答。金句候選打勾才會上，每集最多 6 則。
- **長片怎麼看**：左邊目錄照章分組，目前這一章會打開。上方任務列寫要你決定幾件、金句勾了幾則（超過上限會變紅）、你改了幾段、看過幾段（停留一下才算，只記在這個瀏覽器），還有「接著看」。搜尋可以打段號、字幕、畫面文字或時間（例 `12:30`），按「/」直接跳到搜尋框；也可以只看動畫、字卡、素材、我改過的、還沒看的。
- 都看完回到對話說「可以」。有選擇或補充說明的段，AI 會先重做再給你確認一次；都沒有就開始製作。確認之後這一頁只能看：選單變成文字、待辦拿掉，要改就跟 AI 說段號。

### 流程列

每一頁的頁首都有：① 剪輯清單 › ② 構圖 › ③ 分鏡表 › ④ 完成影片。✓＝已確認，有內容的步驟點了就過去；還沒走到的是灰的。初剪預覽時多一格「字幕預覽」。視窗窄的時候其他步驟只留符號，旁邊寫「第 4／4 步」。

流程列旁邊是**這一頁的下一步**（例如「看完回對話說『可以』」），一直都在，不用捲到底找。第一次打開會有一張卡片講這一頁怎麼用（字幕預覽、完成影片預覽、剪輯台各一張）；按掉就記在這台電腦，之後開哪一支影片都不再跳，想再看操作說明按右上角的「?」。

### 同時剪好幾支影片

每支影片有自己的剪輯台（網址最後的數字不一樣）。同時開著兩支以上時，每一頁左上角的專案名稱右邊會多一個小箭頭：點專案名稱，下面展開**切換影片**的清單（現在這一支有勾），選另一支就到那支影片的同一頁（在完成影片預覽就到它的完成影片預覽，在分鏡表就到它的分鏡表）。用鍵盤也可以：按 Tab 移到專案名稱後按 Enter 展開，↑ ↓ 選、Enter 確定、Esc 收起來。別支影片的剪輯台新開或關掉，清單過幾秒會跟著更新；只開一支時專案名稱就只是字，沒有箭頭。

- **點時間軸上的東西**，右邊「屬性」就顯示它能改的地方；點空白處＝整支影片的設定（講者調光、瘦臉、美顏、瘦小腹、音量、主題、淡入淡出、轉場、剪掉的範圍、字幕），一項一區可以收起來，標題帶現在的值。
- **在時間軸上按右鍵**：先選到那個東西，旁邊跳出它能做的事（下面「右鍵選單」）；在空白處按右鍵是那一軌的選單。
- **右邊五個分頁**：屬性、段落、字幕、修改單、檢查，同一欄切換，打開不會把預覽擠小、也不會蓋住畫面。
- **找一段（長片）**：「段落」分頁照章列出每一段的時間和在講什麼（段號在後面），打字就能搜段號、文字、時間（`12:30`），點一下跳過去，時間軸會放大到前後約 30 秒。「字幕」分頁列出每一句，搜字或句號（`#120`），點一下就能直接改字。按 `[`、`]` 上一段、下一段；點時間也能打段號。
- **時間軸**：打開時一屏三分鐘，放不下的字不硬塞（滑上去看整句）；按「看整支」看全片。最上面那條細細的總覽可以點、可以拖。預覽和時間軸中間那條線上下拖可以調大小，雙擊回到預設。軌道比放得下的高（字卡分好幾排、把軌道拉高、視窗比較矮）時，時間軸自己上下捲，右邊的捲軸一直在；預覽不會被擠到不見。在軌道上往下滾＝捲軌道，按住 Shift 滾（或左右滑）＝前後移動時間。
- **右側面板的寬度**：預覽和右側面板中間那條線左右拖可以調（280–720 px，預覽至少留 480 px），雙擊回到預設；選到那條線按 ← → 也可以。寬度記在這個瀏覽器。
- **現在這段**：播放鍵旁邊寫現在播到哪一段、在講什麼，按「✎ 這段想改」直接開修改單；播到只有講者的地方（時間軸的灰色斜線，點得到）寫「這裡想加畫面」。
- **網址跳段**：`?seg=x0410` 或 `?t=12:30`（可以和 `view=final` 一起用）打開就停在那裡，分鏡表每段的「在預覽看」就是這個。
- **存檔狀態**：沒有儲存按鈕，改了停手一秒就自動存；綠點「已自動存檔」。連不到服務時會寫出來，修改留在頁面上，連回來自動補存。改完馬上關頁、剛好那一下檔案被 AI 或構圖頁改過而沒存進去時，下次打開頁首會問「要套回去嗎？」，按「套回去」就照常自動存。
- **時間**：平常看「分:秒」，旁邊小字是格數（一秒 30 格）。點一下可以打時間或段號跳過去（例如 `1:23`、`00:01:23:10`、`x0410`）。有剪掉東西時，後面多一個「完成影片」的位置。

### 兩種預覽

- **完成影片預覽**（有成品就開這個）：看完整的成品，字卡、動畫、字幕、音效都有。聲音（人聲、音效、素材原聲、背景音樂、範圍音量、各段音量）、字幕樣式、重點字幕改了馬上聽得到、看得到，旁邊寫「已即時套用」，輸出時會一起做進去。其他修改旁邊會寫「有新修改」，「更新預覽」變成主色、外面一圈光慢慢呼吸（＝還有修改沒做進預覽），按了才會做進去；改過字的段會量版面，好了停在那一段。
- **快速試聽**：調聲音、裁剪時用。播初剪影片，把你現在的設定直接套上去，改了馬上聽得到（剪掉的範圍會跳過、音量、音效、淡入淡出、轉場、素材的示意；素材放在和完成影片一樣的位置，橫式在字幕帶上方）。沒有字卡和動畫：播到那裡畫面角落會講一聲；選到那一段，右邊會放分鏡表的截圖。
- 不能按的按鈕是灰的：滑鼠移上去、或點一下，會說為什麼（例如還沒做過成品、分鏡還沒做好）。只用「快速試聽」也能把剪輯調完。
- 「安全框」：重要的字放在黃框裡，手機、電視都不會被切到。「講者框」：字卡不要擋到藍色虛線框（講者的位置）。

### 看得到做了什麼

AI 寫的、工具自動決定的、你自己改的，都畫在同一個地方：

- **畫面速度**：錄影段底下的色帶，快轉橘、減速藍、定格灰，夠寬會寫倍速。「段落」分頁那一段也會寫（例「3 秒 原速、2 秒 定格」）。
- **轉場**：片段兩端的白色斜角＝有轉場，滑鼠移上去寫是哪一種（淡入、擦入、換卡…）。點一段，屬性有「進場／出場」；錄影段可以直接改，動畫段是工具照前後段決定的，想換寫進修改單。
- **開頭淡入、結尾淡出**：主軌兩端的深色斜角，長度就是秒數。
- **剪接點轉場**：主軌上緣的菱形，點一下更改。

### 裁剪

- **片頭、片尾**：把主軌畫面最左、最右的白色把手往裡拖，就裁掉開頭或結尾。
- **中間剪一段**：播放頭移到要剪的開頭按 **B**（切一刀），移到結尾再按 **B**，點中間那段按 **Delete**。也可以在主軌或人聲上**拖曳選範圍**（或用 **I**、**O** 設入點和出點），再按 **Delete**。
- 剪掉的範圍是紅色斜線，播放時會跳過。拖紅色範圍的左右邊緣可以微調；點一下紅色範圍再按 Delete＝恢復。
- **素材**（螢幕錄影、圖片）：滑到左右邊緣變成 ↔ 時拖曳＝裁剪（拖左緣時畫面內容不會跑掉），拖中間＝整段移動。拖到字幕的開頭或結尾會吸過去。拖的時候游標旁邊會寫新的時間和長度變化，預覽停在你拖的那一格。素材不夠長、或短於 1 秒時會拖不動。
- 剪錯了按 ⌘＋Z（Windows 是 Ctrl＋Z）復原。

### 聲音

- **整條軌**：軌頭的數字就是那條軌的音量（dB，0＝原本的音量），可以直接打數字或上下拖；喇叭圖示＝靜音（完成影片也不會有這條軌的聲音）。背景音樂軌也一樣（0＝歌曲原本的音量，−40～+6，一格 1 dB；靜音時整條變灰）。
- **背景音樂**：點背景音樂軌＝右邊「整支 → 聲音 → 背景音樂」滑桿亮起來，和軌頭的數字是同一個值。講話時會自動壓低 6 dB（有剪段的集數整段固定音量）。換曲子、不要配樂請跟 AI 說。
- **片尾**：有設定片尾卡時，時間軸最後多一段黑色的「片尾卡」（影片講完後接的圖和金句，錄影裡沒有這幾秒），時間和「完成影片」的長度都算到它結束；播放頭可以走進去，兩種預覽都看得到（快速試聽放的是示意）。片尾配樂是背景音樂軌上橘色那一條，從起播那一句畫到片尾卡結束，頭尾的斜坡是淡入淡出。點片尾卡，右邊「屬性」可以用下拉選單選片尾金句的**文字動畫**：打字機（預設，一個字一個字打出來）、淡入、逐行浮出、由左擦開、直接出現；選了會自動存進這一集，「快速試聽」馬上照新的示意，「完成影片預覽」要按「更新預覽」才會換。**金句的字**在屬性面板的文字框改（按 Enter 換一段，逗號、句號照留，一段太長照框寬自動換行；清空＝這一集不放），**字號**、**固定寬度**、**行間距**、**段落間距**（段與段之間空幾行，0–2 行，預設一行）用滑桿調，數字照剪映的單位寫（括號裡是畫面上的 px；你的剪映設定：字號 7、固定寬度 290、行間距 0.07、段與段之間空一行）；**位置、大小**：播放頭停在片尾卡，預覽畫面上的金句有虛線框，拖框移動、拖右邊改框寬、拖右下角放大縮小、方向鍵微調（Shift 一次 10 px）、雙擊回原位，兩種預覽都即時跟著（完成影片預覽改字時先放整段新的字，文字動畫要按「更新預覽」才照新的字排）。其他的在剪輯台只能看：滑上去會寫在哪裡、多長，要換圖、換曲子、改從哪一句起播、調音量、每一集都用同一種文字動畫，請跟 AI 說（例：「片尾配樂從第 457 句起播」「這集不要片尾」「以後片尾金句都用淡入」）。
- **人聲**：人聲軌上的黃線上下拖＝整條人聲變大聲／變小聲。只想調某一段：先在人聲軌拖曳選範圍，再拖範圍裡的黃線（或按屬性裡的「調整這段人聲音量」）。
- **把人聲調到 YouTube 標準音量**：點時間軸空白處，按這個按鈕，會量整支人聲的音量（剪掉的範圍不算），自動調到 YouTube 常用的標準（−14 LUFS），並寫出量到多少、調了多少。
- **音效**：音效軌上每一顆是一個音效。點一下看屬性；上下拖＝調這段的音效大小；雙擊或按 Delete＝靜音，再按一次＝還原成 AI 原本放的音效。方塊的寬度就是這顆響多久。音效軌上的菱形是情緒點（實心＝出聲、空心＝不出聲或讓位、外圈＝講者推近）；出聲的情緒點下面有它的音效方塊（情緒點的顏色），要不要這顆在分鏡表的「情緒點」勾選表改，或跟 AI 說。
- **拖曳音效、裁前後**：左右拖方塊＝換位置（段落的音效拖不出那一段，其他拖不出影片）；滑到方塊左右邊緣出現 ↔ 時拖＝裁掉這顆的開頭／結尾（至少留 0.1 秒，裁過的那一端有一條亮邊；方塊太窄先放大時間軸）。拖的時候會吸附字幕、段落、播放頭（照「吸附」開關），提示寫幾秒開始響、比原本早或晚多少、剩幾秒。⌘＋Z 復原；AI 配的那一顆按右鍵「還原這一顆的位置和長度」，自己加的「不裁（放回整顆）」。要按「更新預覽」才進完成影片預覽，快速試聽馬上聽得到。
- **換一顆音效**：對音效（或那一段字卡、動畫）按右鍵 →「換一顆音效」，清單是這台電腦有的音效，每一顆右邊的 ▶ 可以先聽；選了馬上換，落點不變。「還原成原本的」回到 AI 原本放的那一顆（換過好幾次、靜音過也一樣）。屬性面板的「換一顆音效…」是同一份清單。
- **自己加一顆音效**：在音效軌的空白處按右鍵 →「在這裡加音效」→ 選一顆，那一刻就會響。自己加的是白色虛線框（AI 配的是綠色）：左右拖＝改時間、上下拖＝調這一顆的音量、按右鍵可以換一顆、Delete 移除；屬性裡也能打時間、拉音量。它不受「相距 3 秒」「每分鐘幾顆」的規則限制，AI 不會動它；落在剪掉的範圍裡就不出聲。
- **素材的原聲**：素材上的黃線，拖到最下面＝靜音；或在屬性按「保留原聲」。
- **音量表**（預覽右邊）：播放時看音量，超過 0 dB 亮紅燈＝會爆音。人聲軌頭出現紅色「!」也是可能爆音的提醒。

### 右鍵選單

在時間軸上按右鍵，會先選到指標下的那個東西（播放頭也移過去），再跳出它能做的事。每一項做的事和原本的按鈕、快捷鍵一模一樣（一樣自動存、一樣可以復原），右邊寫著快捷鍵；現在不能做的是灰的，滑過去（或點一下）會說為什麼，例如那條軌鎖住了。

| 在哪裡按 | 選單 |
|---|---|
| 字幕 | 改字、在播放頭分割、與下一句合併、在後面／前面新增一句、重點字幕（開著會打勾）、播這句、刪除 |
| 字卡／動畫 | 改這段的文字（跳到屬性）、寫進修改單、播這段；這段的音效：換一顆、靜音、還原成原本的；換一種動畫、拿掉這一段（這兩項是把要求帶進修改單，給 AI 改） |
| 素材 | 看屬性、寫進修改單、播這段；換一段錄影、拿掉這一段（帶進修改單） |
| 主軌畫面 | 在這裡分割、剪掉這一段、調整這段人聲音量、播放；剪掉的範圍：恢復這一段、接點轉場（無／過黑／放大）；菱形：直接選轉場 |
| 人聲 | 先拖曳選一段範圍，在範圍裡按右鍵：剪掉這段、調整這段人聲音量；調過的那一段：調整音量、清掉這段的調整 |
| 音效 | 換一顆音效、靜音、還原成原本的、調整這段音量、試聽（拖過、裁過的多一項「還原這一顆的位置和長度」）；自己加的：換一顆、調整音量、試聽（裁過的多一項「不裁」）、移除。情緒點的音效：試聽、還原位置和長度；菱形只能看，選單會寫要去哪裡改 |
| 空白處 | 那一軌的選單：字幕軌「在這裡新增一句」「尋找與取代」、主軌「在這裡分割」、人聲軌「把人聲調到 YouTube 標準音量」、音效軌「在這裡加音效」、背景音樂軌「調整背景音樂音量」、只有講者的地方「這裡想加畫面（寫進修改單）」，以及靜音、鎖定這一軌 |

- 用鍵盤：先點（選到）一個東西，按 **Shift＋F10** 或鍵盤上的選單鍵；↑ ↓ 選、Enter 執行、→ 打開子選單、← 回上一層、Esc 關掉。音效清單裡按空白鍵＝試聽。
- 按 Esc、點選單外面、在時間軸上滾動、切到別的視窗，選單都會關掉。選單開著的時候，空白鍵、Delete 這些快捷鍵不會動到影片。
- 直接刪掉一段字卡、換一段素材這類事剪輯台做不了：選單上寫著「（寫進修改單）」的項目會把要求放進修改單，照「修改單」那一節複製給 AI。
- 還在初剪預覽（分鏡還沒做好）時，字幕的項目都能用；加音效、寫修改單要等排了段落。


### 講者（調光、瘦臉、美顏、瘦小腹）

點時間軸空白處，右邊「屬性」最上面是「講者」：

- **調光**：勾選開關＋拖強度（0–1，預設關；開了建議 0.80＝剪映 80）。拖的時候畫面馬上變（是近似效果，完成影片會更準）。
- **瘦臉**：勾選開關＋拖強度（0–1.2，預設關；開了建議 0.60＝剪映 60）。下面兩張是「目前這一格」的臉，左邊原本、右邊套用後（瘦臉＋美顏），滑桿放開就更新；格子大小固定，新圖到之前留著上一張。臉太小或偵測不到時會寫原因。
- **美顏**：勾選開關＋拖強度（0–1，預設關；開了建議 0.50）。磨皮、膚色提亮、淡化黑眼圈，越往右越明顯；快速試聽看不到，看下面「後」那張臉。
- **瘦小腹**：勾選開關＋拖強度（0–1，預設關；開了建議 0.50）。腰（肋骨下緣到髖）往身體中線收；下面多兩張「目前這一格」的軀幹，左邊原本、右邊收了之後，滑桿放開就更新。還沒偵測姿勢時會寫「先到構圖頁按偵測臉部」（會一起偵測姿勢）；這支不能做（半身取景、常側身、人太小）時寫原因。手擺在肚子前面會跟著窄一點、腰旁邊的東西會微微變形，太明顯就調低。
- **恢復預設**：回到每支影片共用的設定（`shared/template/kit/look.json`）。
- 改了瘦臉、美顏或瘦小腹要按「更新預覽」才會做進去；長片第一次要幾分鐘（右下角會顯示「偵測臉部」「套用瘦臉」的進度）。只改調光很快。
- 調光、瘦臉、美顏、瘦小腹跟上次做進完成影片預覽的不一樣時，滑桿下面多一行提示（哪幾項、要重新處理底片、大概多久）和一顆發光的小「更新預覽」，和右上角那顆做同一件事。比的是上次 build 處理底片時記下的值（`/api/state` 的 `look.baked`）；這一支略過瘦臉或瘦小腹（臉太小、偵測不到）時，那幾項不算。

### 構圖（講者要不要放大、往哪裡放）

流程列的「構圖」（網址最後是 `/framing`）：

- **左邊**：沒裁切的初剪影片，上面一個鎖定比例的框（橫式 16:9、直式 9:16）。拖框移動、拖四個角縮放；方向鍵微調，按住 Shift 一次 20px。黃色虛線是講者的動作範圍（手勢會到的地方），底下有圖例。拖好就自動存；還沒調過時框就是建議的框，也已經存好了，不滿意再拖。
- **右邊**：完成影片看起來的樣子，套上字幕、下方字卡、子母畫面小視窗的位置；直式多兩條青線（頭頂要在中間）和一條洋紅線（下巴不超過）。
- **下面的結果**：放大幾倍、畫質清不清楚、有沒有切到手勢；不合的會標紅，也會講怎麼調。
- **建議的框**：工具算的，不切到手勢、不會太糊的倍率裡最大的。**原畫面**：不裁切。
- **「想換主色、背景，或看動畫套上去的樣子？」**：這一區預設收起，不換就跳過。下面這幾項都在裡面。
- **動畫預覽**：目前播放頭的畫面（含裁切與調光）直接套進同頁動畫，不用另開分頁。預設顯示六個範例，可依「情境動畫／版型／字卡」篩選、展開全部或點開同頁大預覽。直式只顯示已有直式版本的動畫。
- **主色與背景**：在構圖下方選主色、輸入色碼。背景按「全畫面／側邊欄／章節」分三張，同類動畫共用；每張都能上傳 JPG、PNG、WebP（12 MB 以內），自動裁切並放進動畫預覽。選了就自動套用到這一集。
- 參考圖與背景圖都可拖拉圖片檔到上傳區，也可點選上傳；每次一張，JPG／PNG／WebP、12 MB 以內。拖入時會高亮，放開即上傳；鍵盤可用 Enter／空白鍵開啟選檔。
- **用 AI 生成背景**：選主色、放參考圖、選設計風格並補描述，按「複製生圖指令」。可依參考圖／描述，或選科技線稿、編輯平面、紙雕拼貼、幾何 3D、自然實景。A／B／C 在同一套風格中改變結構、造型或材質，各含全畫面、側邊欄、章節，共 9 張；不再以低對比、模糊光暈作預設。沒有指定方向或參考圖時，三組分別採科技線稿、編輯平面、立體幾何。頁面本身不呼叫 AI；生圖指令會請 AI 先跑 `caps.mjs`，照「這次生圖走」那條路生成（`shared/setting.json` 的 `image`）。剪貼簿不可用時展開指令供手動複製。
- **對應資料夾**：`work/design/requests/<需求編號>/` 儲存 `request.md`、`request.json`、參考圖副本；AI 將三組圖片分別存進 `A/`、`B/`、`C/`，每組各有 `bg-fs.png`、`bg-side.png`、`bg-ch.png`（也接受 JPG／WebP）。原檔與歷次需求保留。
- 相同設定重複複製沿用原需求資料夾，改主色、參考圖或風格時才建立新一份。重開頁會還原風格描述，已儲存的指令仍可查看、複製。
- **參考影片摘要**：「參考這支影片的重點摘要」預設勾選，生圖指令會帶上 `work/摘要.md` 的內文（初剪完成後 AI 寫的 300 字內摘要：一到兩句描述＋列點），讓背景的意象和氛圍呼應這支影片；可以展開看內容，取消勾選就不帶。還沒有摘要或格式不對時不能勾，下面會說明原因。
- **同時生成**：生圖指令要求 AI 一次派出 3 個子代理，A、B、C 各生成自己那組三張，主代理只收件與回報狀態；同一組由同一個子代理生成，造型才一致。某組失敗只重派那一組；沒有子代理或子代理沒有生圖工具時，才由主代理依序生成。
- **生圖進度**：複製成功只顯示「已複製，請貼給 AI」。AI 按生圖指令回報開始後才顯示「生成中」，並列出已存檔張數；完成顯示「生成完成」，失敗顯示原因。頁面每 2.5 秒自動更新，重開仍保留狀態。剪貼簿失敗時顯示手動複製提示。
- **生圖狀態 API／CLI**：`GET /api/design/request/status` 讀取目前需求；`POST /api/design/request/status` 傳 `{ "requestId": "需求 id", "state": "generating", "message": "目前進度（選填）" }`。state 可用 `generating`、`done`、`failed`；九張圖未全部存檔時 `done` 回 409，舊需求或已更換的背景設定也回 409。AI 可在根目錄執行 `node shared/template/tools/editor.mjs --project projects/<專案> --design-request <需求 id> --design-state generating`，完成改用 `done`，失敗改用 `failed --message "原因"`；查詢用 `--design-state status`。生圖指令內已附可執行的回報指令；紀錄位於該需求目錄的 `progress.json`。
- **選圖替換**：背景區選全畫面／側邊欄／章節，再點「原本背景」或 A／B／C 圖片替換、立即預覽。「原本背景」固定保留，尚未生成時也能選；指目前風格包或共用模板的原背景，僅還原該類圖片，保留主色與其他類選圖。三類可分別混搭。切回頁面自動讀取新圖，也可按「載入圖片」。選擇記錄在該需求的 `selection.json`，自動套用。缺圖或壞圖不取代原背景。
- **預覽播放**：構圖頁與完整情境庫預設顯示內容出齊、退場前的完成畫面；滑鼠移入時持續循環播放，移開回完成畫面。點擊構圖頁預覽可放大並播放，也可按「重播」。側邊欄使用實際資訊卡、字幕與右移講者的合成預覽。
- 可移除參考圖。
- **講者調光、瘦臉、美顏、瘦小腹**（右邊下面，預設收起）：勾選或拖滑桿，上面的畫面馬上套調光（近似效果）。美顏＝磨皮＋膚色提亮＋淡化黑眼圈（建議 0.50）。瘦小腹＝腰往身體中線收（建議 0.50）。瘦臉、美顏要先偵測整支影片的臉、瘦小腹要偵測姿勢：勾選後按「偵測臉部」（一次做完），在背景跑（長片二、三十分鐘，可以繼續拖框），跑完下面出現播放頭那一格的前後對照（臉一組、開了瘦小腹再多軀幹一組）。
- **情境庫裡的講者換成你**（右邊下面，預設收起）：按「用這一格當預覽參考圖」，把播放頭這一格（照框裁切、套調光）存成 `shared/template/preview/speaker-local.jpg`（直式 `speaker-v-local.jpg`），情境庫、風格預覽頁的講者改用它；換一格再按一次就更新。這張是你自己的畫面，不進版控、不上官網。
- 構圖、調光、主色和背景都會自動存。frame／look 寫入 plan.json；本集風格與上傳／生成圖儲存在 `work/design/`（`state.json`、`drafts/<id>/`、`uploads/`），`applied.json` 記錄套用的版本，build 讀這份使用本集設定。共用模板與原素材不改，歷次草稿保留。
- **已經有完成影片時**：新的構圖要更新預覽才看得到，頁面會出現「更新預覽」按鈕（底片要重新處理，長片要十幾分鐘，所以不會自己開始）；也可以回剪輯台再按。還沒有完成影片就不用管。
- 流程是同頁調構圖、選主色／上傳或生成背景、看動畫 → 回對話說「調好了」 → 分鏡／動畫製作 → 剪輯與完成影片預覽。需要讓每一集共用整套風格時，再用風格包流程。

### 字幕

- **改字**：雙擊字幕直接改，按 Enter 完成；或點一下在右邊改（會顯示字數，超過 18 字有 ⚠；直式影片是 10 字）。「字幕」分頁點一句也能直接改。
- **改時間**：拖字幕的左右邊緣，或在右邊輸入開始、結束時間。字幕不能重疊。
- **分割**：播放頭移到要切開的地方，在右邊文字框把游標點在要切的字，按 **B**（或「分割」）。
- **合併**：「與下一句合併」。
- **新增**：只能放在兩句之間至少 0.5 秒的空檔：在字幕軌的空檔雙擊，或用「字幕」分頁的「＋ 新增一句」。
- **刪除**：選字幕按 Delete，直接刪；跟著這句出現的字卡、動畫、音效留在原本的時間。按 ⌘／Ctrl＋Z 可以復原（連增刪字幕也可以）。
- 按鈕是灰的時候，滑鼠移上去會說為什麼不能用（例如「只有 0.20 秒空檔」）。
- **尋找與取代**（⌘／Ctrl＋F，或「字幕」分頁的按鈕）：一次修正整集重複的錯字。
- **重點字幕**：想讓某一句特別顯眼（主色底、粗體，其他字幕不變），在「字幕」分頁點那一句右邊的「重點」，再點一次取消；或選到那一句按 **H**（沒選字幕時是播放頭所在的那一句，可以邊播邊標）。標了的那一列左邊有一條主色、開關是實心，時間軸字幕軌那一句的上緣也有一條；預覽畫面上馬上看得到。上面的「重點 N 則」按下去只看標了的。短影片（直式）建議一支標 3–6 則、不要連續超過 2 則，標太多左下角會有 ⚠。分割重點字幕兩半都是重點，合併後也是，刪掉就沒有了。
- 字卡、動畫和素材是跟著字幕句號出現的，增刪字幕時它們會自動跟著改，不會跑掉。

### 字卡和動畫上的文字

點字卡或模板動畫，右邊會列出它的文字欄位（每欄寫著字數／上限，超過上限顯示 ✖）。模板動畫只列畫面上的字，圖示、時間和項目數不能在這裡改；為這段設計的動畫，字畫在動畫裡，要改寫進修改單。清單只能刪項目，不能新增。標「可強調」的欄位可以用 `**詞**` 套主色、用 `//` 換行：選字按欄位旁的「重點」（或 ⌘B／Ctrl+B）就會包好，游標放在重點裡再按一次取消；清單、條列每項最多標 1 個。在完成影片預覽裡打字，畫面上那段的字會跟著換（播放頭不在那段就跳到它的完成態；還沒有逐字動畫，快速試聽沒有字卡看不到）。按「更新預覽」才會做進去並量版面，好了停在那一段；版面有問題會紅字列在「檢查」分頁（改短一點或改回原本的字）。要加項目、換動畫、重新排版，寫進修改單。

### 修改單（想讓 AI 重做哪幾段）

按上方「修改單」（或屬性面板的「✎ 寫進修改單」、現在這段的「✎ 這段想改」），右邊會切到修改單分頁：

1. 在時間軸或「段落」分頁點一段動畫或螢幕錄影，修改單上方會列出它在講什麼、動畫是什麼、完成影片時間和段號，這段的字幕收在下面。只有講者的地方也可以寫（段號是 `t`＋起點秒數，例 `t1095`，描述想加什麼畫面）。
2. 點想怎麼改（例如「流程更細節」「以圖像展示為主」「文字少一點」「換一種動畫」；錄影段是「標註更清楚」「推近到操作區」「換成動畫」…），或在下面自己寫。點了、打了就存進修改單，不用按儲存；標籤和描述都清掉＝拿掉這段。
3. 換下一段，一直累積。修改單最上面是「待改」「生成中」「已改完」三個分頁（三格等寬、貼齊上緣、不跟著捲；分頁上有段數；重開記得上次看哪一頁）。上面那一區「這段想改」只在待改分頁；從「✎ 寫進修改單」「✎ 這段想改」進來會切回待改。清單裡「↗」跳回那段、「✕」拿掉。時間軸上那段的右端會標 ✎（待改）或 ✓（已改完）。
4. 按「複製給 AI（N 段待改）」：把待改的段存到 `work/feedback/editor-requests.md`，並複製一行指令。成功後標「已複製」，請貼給 AI；若剪貼簿失敗，只標「已存檔」。複製本身不會啟動 AI。
5. AI 回報開始後，對應的段才標「生成中」，移到「生成中」分頁：AI 已經在改，「複製給 AI」不算它、不會再送一次（這時再加別段、再複製，只送新的待改段；生成中的段照樣顯示、AI 改完照樣標已改完）。改了生成中那段的標籤或描述，它就回到待改。失敗時標「生成失敗」，提示原因，算回待改。AI 每改好一段就回報那一段（`versions.mjs done`，預覽同時換新），那段馬上移到「已改完」，右下角跳「s05 改好了」提示，按「▶ 看結果」直接跳到那段；不用等整張修改單改完。失敗的段也會跳提示、寫原因。已改完的段再點標籤或改描述，就變回待改。
6. 「已改完」分頁只列**最近一輪回饋**（`work/feedback/r<N>.md`「改了哪幾段」）改了哪些段、各做了什麼，不是歷來全部：照修改單改的、AI 自己全片優化的都算；比這一輪舊的已改完會從修改單拿掉（紀錄還在 r<N>.md）。按「▶ 看結果」切到完成影片預覽、跳到那段開頭。
7. 不採納某段：按「↩ 用上一版」（按兩次確認）換回這一輪改之前那一版。剪輯台在背景跑 `versions.mjs use`（自己開一輪、備份、build、audit、停點 ④，約 1 分鐘），好了會通知、預覽自動更新；現在的樣子會先存成一版，所以那一列會變成「已退回 vN」，可以按「↪ 改回 r<N> 的版本」再換回來。這種退回開的回饋輪記在 `work/feedback/editor-reverts.json`，「已改完」不會因此換成那一輪。換了之後檢查沒過（例：和前後段時間重疊），會換回原本那一版並列出 ✖，這時把那段寫進修改單請 AI 一起調整前後段。新增的段、拿掉的段、全片的情緒點不能單段換回，只列紀錄。AI 正在改（回饋輪還沒收尾）時不能換。

修改單存在專案裡（`work/feedback/editor-requests-list.json`），換瀏覽器、關掉分頁再打開、剪輯台重開都還在；改完想重寫就按「清空修改單」（要按兩次）。

不在電腦前也能寫：跟 AI 說「手機確認頁」，它會把每一段的最後一格做成一頁網頁（發布後用手機打開）。每段的選項和這裡同一套，填好按最下面「複製提示詞」，複製的是整份修改單（格式和這裡一樣），貼給 AI 就照修改單改。

AI 回報狀態：`GET /api/requests/status` 讀取 `requests.revision`；`POST /api/requests/status` 傳 JSON `{ "revision": "讀到的版本", "ids": ["s01"], "state": "generating" }`。狀態可用 `generating`、`done`、`failed`，可加 `message` 與 `round`；`done` 只在 build、audit 通過後回報。版本不符回 409，整批不寫；不在修改單的 id 或格式錯誤回 400。狀態存於 `work/feedback/editor-requests-status.json`，重新啟動剪輯仍保留；重新複製後舊版本狀態不再套用。

照修改單改時，`versions.mjs begin --requests` 會標「生成中」、`versions.mjs done --seg <段>` 每回來一段標那段「已改完」、`versions.mjs finish` 收尾時再標一次「已改完」或「失敗」，AI 不用另外回報。要手動補報才從工作區根目錄跑下面這幾行（剪輯未開啟仍可回報，與 API 寫同一份狀態）：

```sh
node shared/template/tools/editor.mjs --project projects/<專案> --requests-state status
node shared/template/tools/editor.mjs --project projects/<專案> --requests-state generating --request-revision <revision> --ids s01,x02
node shared/template/tools/editor.mjs --project projects/<專案> --requests-state done --request-revision <revision> --ids s01 --round r1 --message "已完成修改並通過 build、audit"
node shared/template/tools/editor.mjs --project projects/<專案> --requests-state failed --request-revision <revision> --ids x02 --message "生成失敗原因"
```

### 轉場

剪接點＝畫面跳接的地方：你剪掉的範圍，加上 AI 剪乾淨時剪掉 NG、停頓的地方（主軌上緣的菱形）。點菱形在右邊選：

- **無**：直接接。
- **過黑**：畫面很快變黑再亮起來，適合換段落；可以設長度（預設 0.3 秒）。
- **放大**：接點之後畫面放大一點（1.08 倍），到下一個剪接點恢復。講話中間的跳接用它比較不突兀。
- 點時間軸空白處，「轉場」可以一次全部設成無、全部過黑，或「交替放大」（一近一遠）。

### 自動存檔、更新預覽、檢查

- **自動存檔**：改了什麼，停手一秒就存（拖曳中、中文選字中會等一下）；切回對話、關分頁時馬上存。⌘／Ctrl＋S 也可以，但不用按。檢查在背景跑，左下角寫「檢查中」時可以繼續改。存完還能復原和重做（⌘／Ctrl＋Z），連增刪字幕也可以，檔案會跟著回去。
- **更新預覽**：把修改做進完成影片預覽。還有修改沒做進預覽時按鈕變主色、外面一圈光慢慢呼吸（系統設定「減少動態效果」時是固定的光圈），旁邊寫上次花多久；只改了聲音、字幕樣式、重點字幕不會發光（完成影片預覽已經直接改了）。右下角寫現在做哪一步、已經多久；要重新處理影片底片時（換構圖框、瘦臉、換 rough.mp4）長片要十幾分鐘。不會擋住你繼續看，但更新中（包含別的分頁、構圖頁按的）不能再按更新預覽和輸出。
- **左下角 ✖／⚠、右邊「檢查」分頁**：檢查結果。⚠ 是要你看一眼的事（同類合併，例如「3 段的字停留太短」；工具自己改得好的在產生時就改掉了，不會出現在這裡），點段號跳到那一段，播放器切到完成影片預覽，清單不會蓋住畫面；段落清單和時間軸上的 ⚠ 也只標這些。工具給 AI 的技術細節收在「給 AI 的細節」（工具自己改得好的已經改掉，剩下的要 AI 看；想處理就按「複製原文給 AI」貼給 AI）。✖ 錯誤要先改好才能更新預覽。每則下面有「判斷錯了，隱藏」：藏起來的不算進 ✖／⚠ 數、也不會複製給 AI，收在最下面「已隱藏」，按「還原」放回來；同一類只差數字的一起藏（例如同一張卡的好幾個數字），改字後數字變了也還藏著。改字後量的版面錯誤寫白話（不列程式選擇器），寫給 AI 的改法收在「給 AI 的改法」。字卡動態和插入素材改字後不量版面（字卡會刻意飛出畫面、裁一半，版面由模板保證）。
- 如果跳出「檔案被改過了」：表示 AI 剛改了它。按「重新載入，保留我的調整」，會自動再存。

### 輸出完成影片

看完完成影片預覽，按上方「輸出完成影片」，先選畫素（1080p／4K）和字幕（燒進影片／不燒、另存 `output/final.srt`），按「開始輸出」。預設 1080p、燒進影片；選了別的就不接手背景先算的、也不只重畫改到的段，整支重新輸出，4K 磁碟不夠會先擋下來。它會依序更新預覽、做 4 秒測試片段確認有畫面和聲音、輸出整支、跑驗收，順序和判準都和 `auto-edit-deliver` 相同。背景已經先 render 好、內容又沒變時會直接接手，只跑驗收。AI 正在輸出時按鈕會說「已經在輸出了」。

- **講者還是示範人物時會先問**：沒有 `shared/setting.json`、段落也沒寫姓名時，14 講者介紹會顯示 `scenes/14-speaker/scene.json` 的預設值（示範人物林大寶）。頂端會有紅色「⚠ 講者還沒設定」，按輸出會跳確認卡：填姓名與頭銜（寫 `shared/setting.json`，每一集共用）、照樣輸出（結果會寫明影片裡是示範人物），或先不要。分鏡表頂端也能直接填。

- **等待時**：對話框有整體進度條（四步合起來的百分比，只往上走），寫已經多久、還要多久（走到 1% 後照實際速度算），按鈕和分頁標題也有同一個百分比；可以關掉視窗繼續看別的，點按鈕再打開，輸出好了瀏覽器會通知（要先允許）。輸出中改的東西等輸出完才會存，也不能更新預覽；不要關閉剪輯服務（關閉會取消輸出）。
- **背景先算**（要你說「先在背景算」才開）：AI 在背景先輸出時，按鈕會寫「背景已算 62%」或「已先算好」；這時按下去不用重等。存檔只改幾段，它跑完會自動補上；改動大（換主題、片長變了…）背景那份才不能用，頁面會提醒，按輸出時才重新算。
- **取消、失敗**：上一支 `output/final.mp4` 不會被動到；整支是先輸出到 `work/final-rendering.mp4`，成功才換上去。
- **驗收**：通過會顯示檔案位置、大小和選項，主要按鈕是「打開資料夾」（在 Finder／檔案總管選好 final.mp4），旁邊有「播放完成影片」「看驗收截圖」，並列出 ⚠；有 ✖ 時影片留著，把 ✖ 貼給 AI 或修改後再輸出。
- **整理這集的調整給 AI**：輸出過完成影片之後，驗收那一頁和預覽上方「已輸出過」那一行都有這個按鈕。按了會把這集你改過的地方（回饋時說的話、剪輯台的手改、字幕改的字、換過的動畫）整理成 `work/feedback/learn.md`，並複製一行指令；貼給 AI，它會整理成以後每一集都照做的規則，做成一頁讓你勾，勾了「照做」的才寫進 `shared/偏好.md`。
- **不做**：`qc.mjs observe` 觀影總表是給 AI 判讀的；想讓 AI 看過再交，改跟 AI 說「可以了，輸出完成影片」。AI 正在照修改單修改時不能輸出。

### 想改更多？

字卡的版型、位置、時間，素材換檔、運鏡、紅框，寫進修改單或直接跟 AI 說（例如「s05 的金句卡往左移」）。錄影段的屬性會列出它有哪些標註（點一則跳到那個時間）。

錄影的畫面速度自己改就好：點一段錄影，屬性的「畫面速度」有一條色條，每一區一個速度（快轉橘、減速藍、定格灰）。把播放頭移到要改的地方，按「在這裡切開」，再選定格、×0.5、×0.75、原速、×1.5、×2、×4、×8；「定格 2 秒」直接停在播放頭這一格；「併掉切點」「恢復原速」可以回頭。講話的時間不變，只改畫面走多快；素材用完會停在最後一格。變速、定格的段不保留原聲。變速後紅框、說明卡的時間不會跟著動，看一下還對不對得上畫面。
