# 情境對照（給 AI 查）

分鏡時查：講解在講什麼 → 用哪個版面、哪個情境、做什麼動態、配什麼音效。這份**不定義任何數字**：秒數、字數、張數一律照 `shared/style.md`（節名寫在格子裡）；情境的 slots 上限與預設長度跑 `node shared/template/tools/build.mjs --list`。和 `USAGE-reference.md` 同一層（優先序見 `AGENTS.md`「怎麼用這份檔」）。

## 1. 怎麼用

這張表是**模板**的對照表。值得專門為內容設計畫面的段（故事、比喻、因果轉折、抽象道理、最想讓人記住的畫面）走內容設計動畫，不用查這張表（`shared/style.md`「內容設計動畫」）。

1. 分鏡表每一段先照順序問四題定大類（前一題是「是」就停，不往下問），再到 §3 找那一類最像的列、看「次選／條件」：
   ① 有對得上講解的螢幕錄影或圖片？→ media 段（`auto-edit-screen`）。
   ② 講解裡有**看得見的東西在動或在變**？裝置（手機、腳架、電腦、雲端）、人（走過去、說話、揮手）、檔案（上傳、下載、傳過去）、畫面（錄影、播放、晃動）、時間（計時、花了多久）→ 示意動畫 `x-scene`（§3 第一列，拍型 S；挑元件和拍看 `BEATS.md` §5.4 那張表）。句型像流程、條列、痛點也一樣：「試錄→正式拍→跑去手機旁看」「上傳雲端再下載到電腦」都是 ②，不是 04c、12。
   ③ 抽象的結構：先後步驟、對比、數字變化、組成、2–4 個並列項目？→ 結構型情境動畫（§3「首選」是 custom `x-*` 的列）。並列項目都在講同一個主體（一個 App、產品、裝置、工具的功能、特色、毛病）→ `x-callout`，主體用插圖元件畫在中間；`x-checklist` 只給「要確認／完成的事」，`x-warnings` 只給警告。畫出來只剩一列列「圖示＋一行字」的，回頭換成有主體圖和引線、箭頭的情境（`shared/style.md`「情境動畫優先」：畫面主角是圖）。
   ④ 只有一個名詞、一句重點、一個提醒？→ 字卡（06／07／10／12…）。
2. 分鏡表的「版面」欄只用 §2 的四個名稱（疊加、半畫面、子母畫面、全幕）。
3. 「首選」是情境動畫（custom `x-*`）的列就做動畫；只有不符合 style.md「情境動畫優先」的三條判準才退到「次選」的字卡。連續 2 段以上都是 06／07／12／13 字卡，就回頭查本表有沒有動畫列。
4. 相鄰兩段的版面怎麼接，查 §4；不確定能不能做，查 §5。
5. 模板動畫（`x-*`、04 家族）的拍由模板內建，分鏡表由工具產生：不寫動畫分鏡、插圖清單，也不改 HTML。示意動畫 `x-scene` 照 `node shared/template/tools/build.mjs --project projects/<專案> --spec x-scene` 填 parts 和 beats：parts 先用畫廊元件；畫廊沒有的物件查圖庫（`node shared/template/tools/build.mjs --project projects/<專案> --pics 甲,乙`，印出 id 和使用時機），寫 `"pic": "<id>"`；圖庫也沒有才寫 `icon`（lucide 名稱，用 `--icons 甲,乙` 查），不新畫 SVG。鏡位腳本和新畫 SVG 只有內容設計動畫的設計師會做（`auto-edit-motion`）。

### 語意類型

分鏡的第一回合先畫語意地圖（`work/drafts/<份>.map.md`）：一組句子一行，標它是哪一種語意，再從 §3 最後一欄是這個語意的幾列挑模板（一列可以掛好幾個語意，用「、」隔開）。「預設級」是沒有特別理由時的分級（A 亮點、B 結構、C 串場，見 `work/分鏡素材/語意.md`）。

| 語意 | 什麼樣的句子 | 預設級 |
|---|---|---|
| 轉場 | 換大主題、章節開頭、「重點來了」這類情緒轉場句 | C |

| 定義／比喻 | 「所謂 X」「X 就是…」「可以把 X 想成…」 | B |

| 流程／傳遞 | 東西經過幾站、做完又回到開頭、分岔、傳給好幾個人、由下往上的組成 | B |

- build 的 `--check --json` 每段的 `layoutZh` 就是這四個名稱（`overlay`→疊加、`side`→半畫面、`pip`→子母畫面、`full`→全幕）。
- 直式（plan.json `"format": "portrait"`）只有三種：疊加、上下分割、全幕；`layoutZh` 印「上下分割」的就是橫式的子母畫面。數字見 `shared/style.md`「直式」。
- 不要在講者臉上加黑底壓暗；要強調就換版面或用子母畫面。

### 轉場語彙表（動畫分鏡第 0 拍寫這裡的名稱）

版面切換不用淡入淡出，一種接法一個做法；名稱都在 `shared/template/BEATS.md` §2 語彙表。「build 自動」的只寫進分鏡，程式不用寫。
