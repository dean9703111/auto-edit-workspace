# 情境對照（給 AI 查）

分鏡時查：口播在講什麼 → 用哪個版面、哪個情境、做什麼動態、配什麼音效。這份**不定義任何數字**：秒數、字數、張數一律照 `shared/style.md`（節名寫在格子裡）；情境的 slots 上限與預設長度跑 `node shared/template/tools/build.mjs --list`。和 `USAGE-reference.md` 同一層（優先序見 `AGENTS.md`「怎麼用這份檔」）。

## 1. 怎麼用

1. 分鏡表每一段查一次 §3：先找「句子長這樣」最像的那一列，再看「次選／條件」。
2. 分鏡表的「版面」欄只用 §2 的四個名稱（疊加、半畫面、子母畫面、全幕）。
3. 「首選」是情境動畫（custom `x-*`）的列就做動畫；只有不符合 style.md「情境動畫優先」的三條判準才退到「次選」的字卡。連續 2 段以上都是 06／07／12／13 字卡，就回頭查本表有沒有動畫列。
4. 相鄰兩段的版面怎麼接，查 §4；不確定能不能做，查 §5。
5. 用的是情境動畫（`x-*`）或 04 家族：看那一列的「拍型」欄（A–I），到 `shared/template/BEATS.md` §3 抄那個拍型，寫成分鏡表那段的動畫分鏡（`#### 動畫分鏡 <段 id>`）；用的是次選，就看次選自己那一列的拍型。「拍型」是「—」或 F 的（字卡、07、模板）不用寫。拍型是「S 示意」的（示意動畫 `x-scene`）照 BEATS.md §5：分鏡表多「插圖元件（狀態）」「位置」兩欄，下面再寫一張插圖清單（畫廊 → 圖示組合 → 新建 SVG）。

| 全幕 | 不透明整張蓋住，沒有小窗 | 01 chapter | — | `dark`、`light`、`accent` | 看不到 | 換大主題、情緒爆點 | 全幕：01、fx 置中，四周補底色 |

- build 的 `--check --json` 每段的 `layoutZh` 就是這四個名稱（`overlay`→疊加、`side`→半畫面、`pip`→子母畫面、`full`→全幕）。
- 直式（plan.json `"format": "portrait"`）只有三種：疊加、上下分割、全幕；`layoutZh` 印「上下分割」的就是橫式的子母畫面。數字見 `shared/style.md`「直式」。
- 不要在講者臉上加黑底壓暗；要強調就換版面或用子母畫面。

## 4. 版面怎麼接

| 前 → 後 | build 自動做什麼 | AI 要做什麼 |
|---|---|---|
| 疊加 → 疊加（兩張下方字卡） | 前一張延到後一張進場，退場和進場同時 | 前一段的 `to` 寫成後一段的 `from`（0 秒相接） |
| 疊加 → 子母畫面 | 講者從滿版縮到右下角小窗 | 子母畫面的裁切框要框住臉（`pipCrop`，USAGE-reference R4） |
| 子母畫面 → 子母畫面（相鄰 media 段） | 疊化 | 兩段 0 秒相接，不要留空 |
| 子母畫面 → 疊加 | 小窗放大回滿版 | — |
| 任何 → 半畫面 | 講者推到右半邊、面板推入 | 03 前後不要接 05 兩側（講者位置會跳） |
| 任何 → 全幕（01 章節） | 前一段停在完成態、墊在章節底下；章節期間不放字幕 | 剪乾淨時章節第一句前要留停頓（`ng-snap` 會保留） |
| 段與段之間有空檔 | `--check` 報「沒有畫面的區間」、空太短報「講者會閃一下」 | 照 → 改成 0 秒相接，或補一段（style.md「節奏」的連續覆蓋） |

### 轉場語彙表（動畫分鏡第 0 拍寫這裡的名稱）

版面切換不用淡入淡出，一種接法一個做法；名稱都在 `shared/template/BEATS.md` §2 語彙表。「build 自動」的只寫進分鏡，程式不用寫。

| 前 → 後 | 轉場（語彙名稱） | 畫面長什麼樣 | 誰做 |
|---|---|---|---|
| 講者 → 疊加卡 | 擦開；滑入 | 卡片從左擦開並滑入，標籤、徽章彈出，前句逐字上浮；講者開始慢推 | 模板＋build 自動 |
| 疊加卡 → 講者 | 抽屜收回；擦掉 | 重點條先收回，卡片再向左擦掉；講者推回原大小 | 模板＋build 自動 |
| 講者／疊加卡 → 子母畫面（全畫面卡） | 色帶擦開；子母畫面飛入；長出（主卡） | 主色寬帶帶路擦開新畫面，講者從臉的位置飛進右下角小窗，主卡從小窗長出；前一張疊加卡提早擦掉 | build 自動＋段內 `P.grow` |
| 子母畫面 → 子母畫面（同背景） | 換卡不換景 | 背景不動；舊卡擦掉，新卡稍晚由下擦開、上浮 | 新卡在段內；舊卡退場 build 自動 |
| 子母畫面 → 講者 | 色帶收回 | 色帶反向收、小窗淡出 | build 自動 |
| 任何 → 01 章節 | 章節色塊擦入；章號重拍 | 主色色塊從左下斜擦滿版 → 章號從大砸下 → 章名逐字 | 01 模板＋build 自動 |
| 任何 → 02 章節角標 | 章節色塊擦入；章號重拍 | 角標色塊橫向長出 → 號碼彈出 → 名稱逐字 | 02 模板＋build 自動 |
| 講者 → 半畫面（03） | —（03 模板自動：講者右移、面板推入） | 面板內容錯拍逐字 | 03 模板 |
| 講者 → 錄影（media 段） | 長出 | 錄影從小窗（或主卡的位置）長出 | build 自動 |

**旁白段**（只有聲音、沒有講者畫面）：每一秒都要被螢幕錄影、圖片或不透明的全幕蓋住；沒蓋住 build 會 ⚠ 或 ✖（門檻照 build 的訊息）。旁白段沒有子母畫面小窗。

## 5. 不要做

| 不要 | 改用 |
|---|---|
| 「一大堆、越來越多」做成一整片小徽章連彈 | `x-numbers.html` 的計數器＋量條 |
| 自己描述的動作（「閃一下」「放大很多」）、抖動、碎裂、旋轉 | 只用 `shared/template/BEATS.md` 語彙表的具名動作；過衝（彈出、逐字彈出、重拍）只用在強調拍（style.md「節奏」） |
| 疊在講者實拍上的光暈、發光、漸層、大片模糊陰影 | 硬邊、實心錯位底板＋一層淡落影；光暈、柔影、漸層只在不透明幕上、只用 `--v2-*` token（style.md「動畫視覺」） |
| 自己在情境動畫裡寫背景漂移、光暈球 | 不用寫：`P.end()` 自動帶背景環境（BEATS.md「背景環境」） |
| 在講者臉上加黑底壓暗 | 換版面或子母畫面 |
| 條列整組同時出現 | 逐條進場（style.md「節奏」） |
| 流程圖的站打勾 | 講到的站「聚焦」、走過的站「走過」（留細框）；打勾只用在總結 |
| 主軌放大當轉場 | 剪輯台的 `joins`（使用者主動選的才保留） |
| 影片裡的示意圖用生圖 | HTML／SVG 情境動畫（`kit/icons.json` 圖示）；custom 裡不放 `<img>`（USAGE-reference R10） |
