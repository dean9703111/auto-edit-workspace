                  剪輯台怎麼用
                  
  
                  
    
                  
      
                  基本流程
                  
      
                    
        
                  1. 點時間軸上的東西（字幕、卡片、插入素材、剪接點、音效），右邊「屬性」就會顯示能改的地方；什麼都沒選＝整支影片的設定。長片用右邊的「段落」「字幕」分頁找，打字就能搜尋。
                    2. 
        
                  2. 改好按「儲存」；要在完成影片預覽看，再按「重新產生」。
                    3. 
        
                  3. 講者調光、瘦臉：點時間軸空白處，右邊「屬性」最上面的「講者」。調光拖了馬上看得到；瘦臉看下面的前後兩張臉，按「重新產生」才會套進完成影片。
                    4. 
        
                  4. 改了卡片文字，存檔後會自動重新產生，完成後切到「完成影片預覽」停在那一段。
                    5. 
        
                  5. 在「構圖」儲存後，已有完成影片會自動更新，完成後這一頁直接套用新預覽，尚未儲存的調整會保留。
                    6. 
        
                  6. 調好回到 AI 那邊說「調好了」。
                    7. 
      
                  
      
                  時間軸（由上到下＝畫面疊放順序）
                  
      
                    
        
                  • 動畫：資訊卡（藍）、字卡動態（紫）。時間和版型請 AI 改。
                    • 
        
                  • 插入素材：拖左右邊緣裁剪、拖中間移動；黃線是原聲音量，上下拖。
                    • 
        
                  • 主軌畫面：拖頭尾的白色把手直接裁掉片頭片尾；按 B 在播放頭切開，點選切出的那段按 Delete 刪掉。菱形＝剪接點的轉場。
                    • 
        
                  • 字幕：雙擊改字、拖邊緣改時間；空檔夠大（≥ 0.5 秒）才能新增。
                    • 
        
                  • 人聲：黃線是音量，上下拖整條；先拖曳選一段範圍，再拖範圍裡的黃線＝只調那一段。
                    • 
        
                  • 音效：點一下看屬性，上下拖調音量，雙擊或 Delete 靜音。
                    •

                  第一次用剪輯台？
                  
    
                    
      
                  1. 點時間軸上的字幕、卡片、插入素材，右邊會出現能改的地方。
                    2. 
      
                  2. 拖插入素材的左右邊緣就能裁剪；主軌頭尾的白色把手拖進來＝裁掉片頭片尾。
                    3. 
      
                  3. 按 B 在播放頭切開，選切出來的那段按 Delete 就剪掉。
                    4. 
      
                  4. 雙擊字幕直接改字；改完記得按儲存（⌘／Ctrl＋S）。
                    5. 
    
                  
    
                  隨時按 ? 看全部快捷鍵。
                  
    
                  
  
                  

                  


                  
  
                  
    
                  這裡是完成影片預覽
                  
    
                    
      
                  1. 看片：按 空白鍵 播放，點時間軸或時間碼跳到想看的地方。
                    2. 
      
                  2. 想改：點時間軸上那一段，右邊按「寫進修改單」；或直接在對話跟 AI 說段號和想怎麼改。
                    3. 
      
                  3. 沒問題：按右上的「輸出完成影片」，或在對話說「可以了，輸出完成影片」。
                    4. 
    
                  
    
                  要自己剪、調聲音、改字幕也在這一頁，隨時按 ? 看說明。
