          剪輯台怎麼用
          
  
          
    
          
      
          基本流程
          
      
            
        
          1. 點時間軸上的東西（字幕、卡片、插入素材、剪接點、音效），右邊「屬性」就會顯示能改的地方；什麼都沒選＝整支影片的設定。
            2. 
        
          2. 改好按「儲存」寫進 plan.json（字幕寫進 work/rough.srt）。
            3. 
        
          3. 講者調光、瘦臉：點時間軸空白處，右邊「屬性」最上面的「講者」。調光拖了馬上看得到；瘦臉看下面的前後兩張臉，按「重新產生」才會套進成片。
            4. 
        
          4. 改了卡片文字，存檔後會自動重新產生，完成後切到「成片預覽」停在那一段。
            5. 
        
          5. 調好回到 AI 那邊說「調好了」。
            6. 
      
          
      
          時間軸（由上到下＝畫面疊放順序）
          
      
            
        
          • 動畫：資訊卡（藍）、字卡動態（紫）。時間和版型請 AI 改。
            • 
        
          • 插入素材：拖左右邊緣裁剪、拖中間移動；黃線是原聲音量，上下拖。
            • 
        
          • 主軌畫面：拖頭尾的白色把手直接裁掉片頭片尾；按 B 在播放頭切開，點選切出的那段按 Delete 刪掉。菱形＝剪接點的轉場。
            • 
        
          • 字幕：雙擊改字、拖邊緣改時間；空檔夠大（≥ 0.5 秒）才能新增。
            • 
        
          • 人聲：黃線是音量，上下拖整條；先拖曳選一段範圍，再拖範圍裡的黃線＝只調那一段。
            • 
        
          • 音效：點一下看屬性，上下拖調音量，雙擊或 Delete 靜音。
            •

          快捷鍵
          
      
          
        
          空白鍵／K播放／暫停
          
        
          J L倒退／往前播放（再按加速）
          
        
          ← →退／進 1 格（加 Shift＝1 秒）
          
        
          ↑ ↓上一個／下一個剪接點
          
        
          Home End跳到開頭／結尾
          
        
          I O設入點／出點（選範圍）
          
        
          V選取工具
          
        
          B／⌘／Ctrl＋B分割：在播放頭切開主軌；選著字幕時＝分割字幕
          
        
          Delete刪除選到的東西（主軌片段／範圍＝剪掉；剪掉的範圍＝恢復；字幕＝刪除；音效＝靜音）
          
        
          Enter編輯選到的字幕
          
        
          Esc取消選取
          
        
          S吸附開／關（拖曳時按住 Alt 暫時不吸）
          
        
          ＋ −時間軸放大／縮小
          
        
          Shift＋Z整支放進視窗
          
        
          F全螢幕預覽
          
        
          ⌘／Ctrl＋F尋找與取代字幕
          
        
          ⌘／Ctrl＋S儲存
          
        
          ⌘／Ctrl＋Z復原（加 Shift＝重做）
          
        
          ?這個說明
          
        
          滾輪／⌘／Ctrl＋滾輪時間軸左右捲動／縮放
          
      
          
    
          
  
          
  
          
          


          
  
          
    
          第一次用剪輯台？
          
    
            
      
          1. 點時間軸上的字幕、卡片、插入素材，右邊會出現能改的地方。
            2. 
      
          2. 拖插入素材的左右邊緣就能裁剪；主軌頭尾的白色把手拖進來＝裁掉片頭片尾。
            3. 
      
          3. 按 B 在播放頭切開，選切出來的那段按 Delete 就剪掉。
            4. 
      
          4. 雙擊字幕直接改字；改完記得按儲存（⌘／Ctrl＋S）。
            5. 
    
          
    
          隨時按 ? 看全部快捷鍵。
