                  剪輯台怎麼用
                  
  
                  
    
                  
      
                  基本流程
                  
      
                    
        
                  1. 點時間軸上的東西（字幕、字卡、動畫、素材、剪接點、音效），右邊「屬性」就會顯示能改的地方；什麼都沒選＝整支影片的設定。長片用右邊的「段落」「字幕」分頁找，打字就能搜尋。
                    2. 
        
                  2. 每個修改都會自動存，不用按儲存；頂列左邊會寫「已自動存檔」。
                    3. 
        
                  3. 完成影片預覽看完整的成品；有新修改時按「更新預覽」才會做進去。快速試聽調聲音、裁剪時用，改了馬上聽得到，但沒有字卡和動畫。
                    4. 
        
                  4. 講者調光、瘦臉：點時間軸空白處，右邊「屬性」最上面的「講者」。調光拖了馬上看得到；瘦臉看下面的前後兩張臉，按「更新預覽」才會做進去。
                    5. 
        
                  5. 想換動畫、加字、重新排版：按「這段想改」寫進修改單，再複製給 AI。
                    6. 
        
                  6. 調好回到對話說「調好了」；不用再改就按「輸出完成影片」。
                    7. 
      
                  
      
                  時間軸（由上到下＝畫面疊放順序）
                  
      
                    
        
                  • 字卡／動畫：字卡（藍、紫）、動畫（綠）。時間和版型寫進修改單給 AI 改；灰色斜線＝這裡只有講者，想加畫面可以點它。
                    • 
        
                  • 素材：螢幕錄影和圖片。拖左右邊緣裁剪、拖中間移動；黃線是原聲音量，上下拖。
                    • 
        
                  • 主軌畫面：拖頭尾的白色把手直接裁掉片頭片尾；按 B 在播放頭切開，點選切出的那段按 Delete 刪掉。菱形＝剪接點的轉場。變暗標「只有聲音」的地方沒有講者畫面；紅色斜線＝沒有畫面蓋住，要處理。
                    • 
        
                  • 字幕：雙擊改字、拖邊緣改時間；空檔夠大（≥ 0.5 秒）才能新增。
                    • 
        
                  • 人聲：黃線是音量，上下拖整條；先拖曳選一段範圍，再拖範圍裡的黃線＝只調那一段。
                    • 
        
                  • 音效：點一下看屬性，上下拖調音量，雙擊或 Delete 靜音。
                    •

                  第一次用剪輯台？
                  
    
                    
      
                  1. 看哪裡：「完成影片預覽」看成品；「快速試聽」調聲音、裁剪時用，改了馬上聽得到，但沒有字卡和動畫。
                    2. 
      
                  2. 怎麼改：點時間軸上的東西，右邊會出現能改的地方。想換動畫、重新排版，按「這段想改」寫給 AI。
                    3. 
      
                  3. 怎麼生效：每個修改都會自動存。要在完成影片預覽看到，按「更新預覽」。
                    4. 
      
                  4. 怎麼結束：調好回對話說「調好了」；不用再改就按「輸出完成影片」。
                    5. 
    
                  
    
                  隨時按 ? 看全部操作和快捷鍵。
                  
    
                  
  
                  

                  


                  
  
                  
    
                  這裡是完成影片預覽
                  
    
                    
      
                  1. 看片：按 空白鍵 播放，點時間軸或時間碼跳到想看的地方。
                    2. 
      
                  2. 想改：點時間軸上那一段，右邊按「寫進修改單」；或直接在對話跟 AI 說段號和想怎麼改。
                    3. 
      
                  3. 沒問題：按右上的「輸出完成影片」，或在對話說「可以了，輸出完成影片」。
                    4. 
    
                  
    
                  要自己剪、調聲音、改字幕也在這一頁，都會自動存；隨時按 ? 看說明。
                  
    
                  
  
                  

                  


                  
  
                  
    
                  這裡是字幕預覽
                  
    
                    
      
                  1. 看：影片配上初剪的字幕，一邊聽一邊校對；只有聲音的地方是黑畫面，字幕一樣看得到。
                    2. 
      
                  2. 改：看到錯字，點右邊那一句直接改，按 Enter 就好，會自動存。AI 不會改回去。
                    3. 
      
                  3. 之後：字卡和動畫要等分鏡做好才會出現。校完不用回報，AI 會接著做。
