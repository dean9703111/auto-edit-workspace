五類共 40 種字卡

怎麼用在影片裡
每張卡都是 HyperFrames 子合成，變數決定文字、主色與底色（dark／light／accent／none 透明）。
在 work/hyperframes/plan.json 加一段 { "type": "fx", "fx": 3, "from": "#N", "to": "#Ne", "vars": { "text": "…" } }，由 node shared/template/tools/build.mjs 產生。參數名稱見每張卡下方的 vars。
